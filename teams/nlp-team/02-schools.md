# NLP Team · 流派：共识与分歧

## 流派地图

| 流派 | 核心思想 | 代表 | 理论货币 |
|------|---------|------|---------|
| 一阶确定性 | 梯度步 + 加速（动量/外推） | Polyak [NLP-S7]、Nesterov [NLP-S1, S8] | 速率 + 与下界 [NLP-S13] 的匹配 |
| 二阶/拟牛顿 | 曲率信息：Newton、BFGS/L-BFGS | Nocedal 谱系 [NLP-S5, S10] | 局部快速收敛 + 全局化策略 |
| 信赖域 | 局部模型 + 可信半径管理 | Conn-Gould-Toint [NLP-S6] | 强全局收敛理论 |
| 约束 NLP / 内点 | KKT 体系、障碍/滤波方法 | [NLP-S11, S12, S18] | 可行性+稳定性条件、求解器鲁棒性 |
| 随机梯度 | 采样梯度 + 方差权衡 | Robbins-Monro [NLP-S15]、Bottou-Curtis-Nocedal [NLP-S16]、Duchi（几何自适应+下界文化，见 researchers/john-duchi.md）[NLP-S19, S20, S21]、Scheinberg（经典全局化的概率化改造，见 researchers/katya-scheinberg.md）[NLP-S23] | 期望/高概率复杂度；Duchi 支线：资源-统计权衡、上界必配下界；Scheinberg 支线：高概率精度 oracle 下保留线搜索与确定性速率 |
| 算法分析统一派 | 把算法当动力系统/用 IQC 统一证明 | Lessard-Recht-Packard [NLP-S14] | 可机检的收敛证书 |

## 共识（蒸馏进「框架概览」）

1. **速率体系分层**：凸 L-光滑下 GD 是 O(1/k)（目标间隙），加速到 O(1/k²)
   且与一阶下界匹配 [NLP-S1 机器区, NLP-S13]；强凸下线性速率，加速改善对
   条件数的依赖 [NLP-S8]。全部是目标间隙/特定度量意义，声明度量是义务。
2. **全局化 + 局部快速是两件事**：Newton 型方法的局部快速收敛需要线搜索
   [NLP-S17] 或信赖域 [NLP-S6] 全局化护航；谈「牛顿法收敛快」必须声明是
   局部性质。
3. **约束问题的最优性语言是 KKT + 约束资格**：没有 CQ 的 KKT 断言不成立
   [NLP-S12, S18, S5]。
4. **随机 ≠ 确定性换个噪声**：随机情形的速率、步长策略、momentum 的价值
   都要重新推导，不能从确定性结论外推 [NLP-S16, S3, S4]。
5. **加速是调度的产物，不是更贵的迭代**：Nesterov 加速每步成本与 GD 同阶
   [NLP-S1 机器区 per_iteration_cost]。

## 分歧（保留原样，蒸馏进「流派对比」）

1. **momentum 在随机情形有没有用**：实践派（深度学习）视 momentum 为标配
   且效果依赖初始化/调度 [NLP-S2]；理论派证明在若干随机设定下 heavy ball /
   加速并不改进调好的 SGD 的采样复杂度 [NLP-S3, S4]。语料立场：两者都对，
   分歧在「优化几何+实现效应」与「最坏情形复杂度」是不同问题——
   这正是用户研究 [NLP-L2] 的出发点。
2. **heavy ball vs Nesterov**：二者常被混为「momentum」，但保证不同——
   heavy ball 的经典分析是二次函数局部的，存在光滑强凸函数上不全局收敛的
   反例 [NLP-S14]；Nesterov 构造有全局凸保证 [NLP-S1]。
3. **线搜索 vs 信赖域**：工程效果常接近，文化不同：线搜索派以 Wolfe 条件 +
   拟牛顿配合为主 [NLP-S5, S17]，信赖域派以更干净的全局收敛理论立论 [NLP-S6]。
4. **凸分析派 vs 求解器派**：前者以速率与下界立论 [NLP-S8, S13]，
   后者以 KKT 残差、鲁棒性与大规模实测立论 [NLP-S11, S5]。同一个「好方法」
   在两套评价体系下排名可以不同。
