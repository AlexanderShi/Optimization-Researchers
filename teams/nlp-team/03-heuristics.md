# NLP Team · 决策启发式

## H1 选型速查

| 情形 | 建议 | 依据 |
|------|------|------|
| 光滑无约束、n 中小、梯度可得 | L-BFGS（默认强基线） | [NLP-S10, S5] |
| 凸、可承受精确调参、要最优速率 | 加速梯度 | [NLP-S1, S8] |
| 非凸、要稳健全局化 | 信赖域 Newton/拟牛顿 | [NLP-S6] |
| 光滑约束 NLP | 内点（IPOPT 类）或 SQP | [NLP-S11, S5] |
| 随机/大规模有限和 | SGD 族；momentum 按 H4 的分寸谈 | [NLP-S16] |

## H2 先检查问题，再怪算法

- 先做尺度/条件数检查（变量量纲归一），病态问题先预条件再换算法 [NLP-S5]。
- 调试前用有限差分核对解析梯度（梯度错是「算法不收敛」的头号原因；
  差分区间的噪声注意事项见 DFO Team [DFO-R7]）。
- 一律写成 min f(x)；约束写标准形式再谈 KKT。

## H3 收敛声明的分寸

- 说「收敛」必须带四件套：什么量收敛（目标间隙/梯度范数/迭代点距离）、
  什么速率、什么假设、proved-vs-cited。模板见 04-results。
- 宣称某速率「最优」必须能给出匹配下界的出处（Duchi 准则——他的分布式与
  零阶论文均自带下界 [NLP-S20, DFO-S21]）。
- 局部结果（Newton 二次收敛）与全局结果（信赖域 lim‖∇f‖→0）分开说 [NLP-S6]。
- L 已知是加速方法的安静假设——没有线搜索时低估 L 直接破坏保证
  [NLP-S1 机器区 assumptions]。

## H4 momentum 的三句话分寸（用户研究主题，最易胡说处）

1. 确定性凸情形：Nesterov 加速有可证的阶级改进 [NLP-S1]。
2. heavy ball：二次函数上有局部加速；一般光滑强凸**没有**全局保证且有反例
   [NLP-S14, S7]。
3. 随机情形：momentum 不必然改进调好的 SGD 的采样复杂度 [NLP-S3, S4]；
   实践收益与初始化/调度耦合 [NLP-S2]。
   —— 三句话都要带 ID 说全，只说其中一句就是误导。

## H5 KKT 使用规则

写 KKT 之前先声明约束资格（LICQ/MFCQ 之一或其替代）；无 CQ 的乘子断言
不写 [NLP-S12, S18]。

## H6 与 DFO 对比时的口径

momentum-vs-DFO 类比较必须统一信息计费（梯度调用 vs 函数值调用不是等价
信息 [DFO-S4 content]），并声明 (d+1) 口径 [DFO-L1]。跨队问题两队语料都查。

## H7 报告规范（用户固定约定）

- min 形式；伪代码 + 五步手算；比较报告固定顺序：文献综述 → 算法推演 →
  收敛证明（定理+推导+逐步证明，proved-vs-cited）→ 数值表现。
- 数值部分先描述统计，再配对推断（bootstrap + Wilcoxon + Holm），
  再 profiles，最后理论-实践一致性对账（autoresearch-optimization 的
  CLAUDE.md 固定顺序）。

## H8 几何与结构优先（Duchi 支线）

- 梯度稀疏/特征出现频率差异大 → 按坐标自适应步长（AdaGrad 线），
  让算法自己学 proximal 几何，而非手调全局学习率 [NLP-S19]。
- 非凸但有结构（非光滑凸∘光滑复合、弱凸）→ 用 prox-linear /
  广义次梯度这类带稳定点保证的方法，不盲目上 SGD [NLP-S21]。
- 分布式/通信受限场景 → 把「优化收敛」与「网络/通信效应」分开分析与
  报告（迭代数随谱隙反比缩放）[NLP-S20]。
