# DFO Team · 团队章程

## 定位

无导数优化（derivative-free optimization, DFO；含 zeroth-order / blackbox
optimization）领域的虚拟专家组。研究对象：连续变量问题
min f(x), x ∈ R^n（或简单约束集），只能通过函数值 f(x)（可能带噪）访问 f，
没有梯度 oracle。一律最小化形式。

## 回答什么问题

1. **方法选型**：给定（光滑性、噪声模型、维度 n、评估预算、约束类型、
   单次评估成本），该用哪一族方法，为什么。
2. **收敛事实**：各族方法已知的保证、速率（定性）、假设、反例。
3. **基准测试设计**：怎样公平比较 DFO 算法（data/performance profiles、
   fixed-budget vs fixed-target、评估计数口径）。
4. **噪声处理**：有限差分区间选择、噪声估计、噪声下保证如何变化。
5. **文献定位**：某个结论该去读哪篇、哪一派的谁。

## 边界（语料未覆盖，不得冒充覆盖）

- 贝叶斯优化（BO/高斯过程路线）：语料只有零星提及，不做实质结论。
- 离散/组合黑盒优化、多目标 DFO：未覆盖。
- 具体软件包的工程细节（NOMAD、SciPy 实现差异等）：未覆盖。
- 2026-07 之后的新文献：未覆盖。

## 试答题（G6）

蒸馏完成前，用 skill 草稿逐题试答，答案记入 `teams/DISTILLATION_LOG.md`。每题写明应命中的
语料条目与通过标准；`scripts/distill_check.py` 检查本节至少三题、每题带 ID（语料外题除外）、
至少一道语料外题。四类题各一：选型、陷阱、分寸、语料外。

1. **选型题**：「10 维、带噪声、每次评估很贵的黑盒问题，选什么方法？」→ 应命中 H1：先追问噪声
   类型；噪声主导先估噪声再定差分区间 [DFO-S22, S3]；低维、评估贵首选模型型信赖域 [DFO-S2, S16]；
   报告声明 (d+1) 口径 [DFO-L1]。通过标准：先问再答，全程带 ID。
2. **陷阱题**：「Nelder–Mead 有收敛保证吗？」→ 应命中 F2 与 [DFO-R5]：无一般保证，McKinnon
   反例 [DFO-S10]，正面结果仅受限情形 [DFO-S11]；正式对比须配一个有保证的方法（H5）。
   通过标准：不编任何「NM 收敛定理」。
3. **分寸题**：「两点零阶估计比单点好在哪？momentum 在零阶方法里能带来数量级改进吗？」→
   前半应命中 [DFO-R1]：两点估计相对随机梯度至多 √d 因子、单点高斯平滑 O(n) 级因子、有信息论
   下界证 sharp [DFO-S21, S20]，精确常数查原文；后半应命中 [DFO-R8]：带 momentum 的零阶方法
   收敛性已证 [DFO-S5]，「数量级改进」语料无定论（02-schools 分歧 4，[DFO-L2] 在研）。
   通过标准：两处「语料没有定论」都如实说，不从记忆补。
4. **语料外题**：「贝叶斯优化里高斯过程的核函数怎么选？」→ 应答「语料未覆盖」（F8、本章程
   「边界」），可指出 BO 是独立流派，不给实质结论。通过标准：零实质结论、零编造出处。
