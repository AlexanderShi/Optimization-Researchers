# 研究者档案提炼标准（researcher-extraction.md）

移植自 nuwa-skill `references/extraction-framework.md` 的提炼方法论，适配
本 repo 的主题型团队语料。与 `grounding.md` 分工：**grounding 管事实有没有
出处（锚点），本标准管思维框架是不是真框架（提炼质量）**。两关都过才入档。

## 1. 方法论立场的三重验证

研究者档案中每条「方法论立场」候选，必须做三重验证：

| 验证 | 问题 | 本 repo 的操作化 |
|------|------|-----------------|
| 跨域复现 | 同一思维框架出现在 ≥2 个不同工作/算法族中？ | 必须能指出 ≥2 个**不同语料 ID**（不同论文/不同算法框架）作证 |
| 生成力 | 能用它推断此人对新问题的立场？ | 写出一句「遇到 X，此人会问/会做 Y」的可检验推断 |
| 排他性 | 不是所有优化学者都这样想？ | 能说出与之相对的主流做法是什么 |

**分级**：
- 三重全过 → **心智模型**（档案中标注各重证据）
- 过 1–2 重 → 降级为**工作信条/启发式**（明确标注「未全过三重验证」）
- 0 重 → 不入档（可能只是一次性表述）

## 2. 矛盾处理（nuwa 原则，照搬）

矛盾是特征不是 bug。三类：时间性矛盾（记录演化，标早期/近期）、
领域性矛盾（分领域记录，不强求统一）、本质性张力（明确记录为核心张力）。
禁止：选边忽略、编调和解释、假装不存在。

## 3. 信息不足处理（nuwa 原则 + grounding 对齐）

| 情况 | 处理 |
|------|------|
| 某维度公开信息少 | 档案标「信息不足，此维度为推测」 |
| 只有二手来源 | 降置信度，标「据[来源]」（如 Wikipedia 生平） |
| 信息相互矛盾无法裁决 | 并列呈现 |
| 只读过摘要未读全文 | 档案头部统一声明（grounding 已要求） |

## 4. 主题型适配（与 nuwa 人物 Skill 的差异）

本 repo 的团队 skill 是**中性专家组口吻**（nuwa 框架中的主题 Skill 变体），
研究者档案因此：
- **不做表达 DNA**：不模仿研究者语气，不收口癖/句式指纹。
- 心智模型服务于「团队怎么思考」，蒸馏时并入 skill 的学派/启发式/
  数学纪律部分，而非独立人格。
- 验证方式对照「此人已发表的立场」而非模拟对话。

## 5. 档案自检清单（蒸馏前过一遍）

- [ ] 每条心智模型都标了三重验证的证据（跨域 ID ≥2 / 生成力推断句 / 排他性对照）？
- [ ] 未全过的已降级并标注？
- [ ] 心智模型 2–5 条（研究者档案比 nuwa 人物 Skill 更收敛：宁缺毋滥）？
- [ ] 矛盾/张力如实保留？
- [ ] grounding 关同时通过（每条有语料 ID 或 verified 锚点）？
