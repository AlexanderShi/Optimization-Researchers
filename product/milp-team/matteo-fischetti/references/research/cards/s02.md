### S028 · A polyhedral study of the asymmetric traveling salesman problem with time windows (Networks 2000, DOI 10.1002/1097-0037(200009)36:2<69::aid-net1>3.0.co;2-q)
**Read level**: full (all 21 file pages; the file is ZIB Preprint SC 97–11 of February 1997, not the Networks printing; figures are extraction debris). First-page check: title and authors Ascheuer, Fischetti, Grötschel match (pp. 1–2); Fischetti is listed at the University of Udine (p. 2).
**Role**: supplement · **Coauthors**: Norbert Ascheuer, Martin Grötschel · **Position in trajectory**: the polyhedral half of a ZIB project with industry; the branch-and-cut and all computation are in a companion paper then "in preparation" (pp. 2, 6, 18–19); its tournament constraints return as the path elimination constraints (PECs) of S057 (S057 p. 9).

- **D1 Problem and entry point**: ATSP-TW in its open-path form, a basic model for single-machine scheduling with sequence-dependent set-ups, motivated by a joint industry project on the unloaded moves of a stacker crane in an automated warehouse (pp. 2–3); finding a feasible solution is already strongly NP-complete (p. 3). Since polyhedral methods worked for the ATSP and the precedence-constrained ATSP, the authors extend them to time windows (p. 3). Entry: the standard model links arc and time variables by big-M generalized Miller–Tucker–Zemlin constraints, "known to cause computational problems", and the van Eijl and Maffioli–Sciomachen model adds |A| variables (p. 5).
- **D2 Core idea**: Keep only 0-1 arc variables and impose time windows implicitly through infeasible path elimination constraints x(P) ≤ |P| − 1 (model (2.2)–(2.7), p. 6); the model stays valid even if infeasibility is checked only by the easy deadline test of Lemma 2.1(i) (pp. 5–6). Strengthenings: tournament constraints on the transitive closure [P] (Lemma 4.1, p. 12); set versions valid when every path through a set is infeasible (Theorems 4.3 and 4.5, p. 13), with easy sufficient conditions (Lemma 4.7, pp. 13–14); clique-lifted generalized tournaments (Theorem 4.8, p. 14); concatenation inequalities (Theorem 4.9, p. 15); four further lifted path forms (Theorem 4.10, pp. 15–16); V-lifting (pp. 16–17); and the (π, σ)-inequalities of Balas, Fischetti and Pulleyblank, strengthened by time windows (Theorem 4.12, pp. 17–18).
- **D3 Problem class and data model**: Complete digraph with integer costs, set-up and processing times, release dates and deadlines, waiting allowed, d_i = +∞ allowed (pp. 2–3); the triangle inequality on ϑ is assumed in Lemma 2.1(ii), Section 3 and Theorems 4.9 and 4.12 (pp. 5, 7, 15, 18); the polyhedral analysis covers only the case of one active time window (p. 7); objectives such as makespan or waiting time "cannot be incorporated easily" (p. 6).
- **D4 Algorithm and implementation (brief)**: With one active time window, equations (3.1)–(3.3) form a minimal equation system and dim(P_TW) = |A| − (|Q| + m + μ) (Theorem 3.6, pp. 9–10), proved by validity by contradiction (Lemma 3.4, p. 8), linear independence through one point violating each equation alone (Lemma 3.5, p. 9) and affinely independent vertices built from the closed-tour ATSP face plus an arborescence scan (p. 10); deciding the dimension is strongly NP-complete by a reduction from the bounded Hamiltonian path problem (Theorem 3.7, pp. 10–11). Facetness is not proved; the authors prove validity only and checked with PORTA that the inequalities define facets "for most instances" with n ≤ 5 (p. 11). V-lifting adds two valid inequalities and x_uh + x_hw + 2x_uw ≤ 2 with weight 1/2 and rounds down (pp. 16–17).
- **D5 Computational evaluation**: none in this paper (deferred to the companion paper, pp. 2, 6, 19).
- **D8 Contributions and limits**: An arc-only model, lifted infeasible-path families and the first study of this polytope (pp. 18–19). Limits stated: no makespan or waiting-time objectives (p. 18); small changes in a set-up time can reshape the polytope, so facet proofs look "very difficult" (pp. 11, 19). The conclusion reports the companion paper's outcome: better than earlier LP-based methods on loosely constrained instance classes (p. 19).

**Method links**:
- Method 1 ✅ evidence (steps 1–2, joint, 1997): the time variables and their big-M links are dropped; only arc variables remain and time windows become cuts, a model expected to be "superior to alternative ones, at least for some problem classes" (pp. 2, 5–6), and the companion result is stated per instance class (loosely constrained, p. 19).
- new-pattern candidate: Infeasible-path cuts for side constraints (side constraints of any kind enter an arc model only as no-good path constraints that are then lifted; "capacity constraints, e.g., might be modelled as well in a similar vein", p. 5; pp. 6, 12; reused in S057 and S125).
- new-pattern candidate: Chvátal–Gomory derivation as validity proof and separation handle (V-lifting is a 1/2-weighted combination followed by rounding, pp. 16–17).
- new-pattern candidate: Substructure harvest (every inequality valid for the ATSP polytope or the precedence-constrained ATSP has a version valid for P_TW, p. 12).

**Transferable techniques**:
- Replace big-M time linking by path no-goods on arc variables; validity needs only a cheap sufficient infeasibility test, so separation can start with the deadline check (pp. 5–6).
- Lift a path no-good to the transitive closure of the path (tournament form) using only the degree constraints (p. 12).
- When facet proofs are out of reach, prove validity and check facetness computationally on tiny instances (PORTA, n ≤ 5), and say so (p. 11).
- To show that a structural question about a polytope (its dimension) is hard, encode a Hamiltonian path question in a single active time window (Theorem 3.7, pp. 10–11).

**Quotes**:

### S058 · On the separation of maximally violated mod-k cuts (Mathematical Programming 2000, DOI 10.1007/s101079900107)
**Read level**: full (all 20 file pages; figure debris on pp. 6, 8, 10–11, 13–14 skipped). First-page check: title and authors Caprara, Fischetti, Letchford match (p. 1); received May 29, 1997, revised May 10, 1999 (p. 1).
**Role**: supplement · **Coauthors**: Alberto Caprara, Adam N. Letchford · **Position in trajectory**: the journal version of the IPCO 1999 paper carded as S139 (batch s01). Beyond S139 it gives the proofs S139 left out (one domino per necklace, pp. 8–9; extended combs as mod-2 cuts, p. 12) and the whole ATSP half (pp. 9–10, 14–19).

- **D1 Problem and entry point**: Exact polynomial separation is known for few TSP facet classes and for no comb class; Carr's exact method needs O(n^{2t+3}) time for combs with t teeth (p. 1). Applegate, Bixby, Chvátal and Cook proposed separating only maximally violated combs, which Fleischer and Tardos made exact for planar support (p. 2). {0, 1/2}-cut separation is a minimum-weight binary clutter problem, NP-hard, but with zero weights, the maximally violated case, it is a system of mod-2 congruences (Letchford's observation, p. 2). Entry: carry this from mod 2 to mod k for general ILPs (p. 2).
- **D2 Core idea**: Mod-k cuts λᵀAx ≤ ⌊λᵀb⌋ with λ ∈ {0, 1/k, …, (k − 1)/k}^m; every Chvátal–Gomory cut is a mod-k cut for some k (p. 3). The separation problem (1)–(5) is written in integer multipliers μ (p. 3); violation cannot exceed (k − 1)/k, and a maximally violated cut is any solution of the congruence system on the tight rows with θ = k − 1, found by Gaussian elimination in GF(k) in O(mn min{m, n}) time (Theorem 1, p. 4). Tight bound constraints and rows with slack ≥ θ can be dropped; for prime k basic solutions are minimal, which matters for facets; a heuristic adds rows by increasing slack until the system becomes solvable (p. 5). For the STSP only beads and dominoes of the necklace family are needed (Theorem 4, p. 7), one domino per necklace (Theorem 6, pp. 8–9), giving O(|E*||V|²) separation (Theorem 5, p. 7); the ATSP case symmetrizes x* into y* (Theorems 7–9, pp. 9–10).
- **D3 Problem class and data model**: Any ILP min{cᵀx : Ax ≤ b, x integer} with integer A and b and P_I ≠ P (pp. 1, 3); a known prime factorization when k is not prime (Theorem 1, p. 4); STSP constraints (6)–(8) and ATSP constraints (9)–(12) (pp. 6, 9).
- **D4 Algorithm and implementation (brief)**: Proof devices: scaling the multipliers in GF(k) (Theorem 2, p. 4); reduction modulo a prime factor (Theorem 3, p. 5); replacing a tight SEC by a combination of tight rows whose coefficients agree mod k (Theorem 4, p. 7), with an induction over dominoes (Theorem 6, pp. 8–9); clique lifting keeps the mod-k property when the multipliers λ_v defined from loop coefficients are nonnegative (Theorem 11, p. 15); a mod-k derivation gives an easily checked sufficient condition for the validity of 2-cycle cloning, whose validity check is NP-complete in general (Theorem 12, p. 16). Extended combs (Theorem 10, p. 12), extended SD-inequalities (Theorem 13, p. 17), extended C3 and NEW1 inequalities (Theorems 14–15, p. 18) and D⁺/D⁻ inequalities (Theorem 16, p. 19) are shown to be mod-2, mod-3 and mod-k cuts by explicit multipliers; a mod-2 facet with nesting level above 2 for |V| ≥ 12 and the facetness of NEW1 were checked by computer (pp. 13, 18). Nothing is implemented.
- **D5 Computational evaluation**: none (the practical use is left open, p. 19).
- **D8 Contributions and limits**: Separation theory for maximally violated mod-k cuts, and several known STSP and ATSP facet families recognized as mod-k cuts (pp. 11–19). Limits: general mod-k separation stays NP-hard even for k = 2 (pp. 4, 19); for nonprime k the algorithm does not guarantee a minimal solution, and Theorem 2 does not extend (p. 5). Future: the structure of undominated mod-k TSP cuts, other combinatorial problems, and the practical use of the separation (p. 19).

**Method links**:
- Method 6 ⚠ variant (as in S139): the separation sub-decision is written as its own integer program ((1)–(5), p. 3) but solved, in its maximally violated case only, by linear algebra in GF(k) (p. 4), not by a general-purpose solver; with no implementation (p. 19) the paper is also a counter-case to the skill's taste warning against an algorithm without implementation and test.
- new-pattern candidate: Restrict separation to maximally violated cuts (pp. 2, 4).
- new-pattern candidate: Chvátal–Gomory derivation as validity proof and separation handle (explicit multipliers prove extended combs, SD, C3, NEW1 and D⁺/D⁻ families to be mod-k cuts, and a derivation certifies 2-cycle cloning, pp. 12, 15–19).

**Transferable techniques**:
- To show that a lifting operation keeps an inequality inside a cut class, extend its Chvátal–Gomory multipliers to the lifted graph (λ_v from the loop coefficients, Theorem 11, p. 15).
- Use a known rank-1 derivation as a cheap sufficient validity test for an operation whose exact validity check is NP-complete (2-cycle cloning, Theorem 12, p. 16).
- Before solving the congruence system, drop the tight bound constraints (complement the upper bounds) and every row with slack ≥ θ (p. 5).
- For cuts that need not be maximally violated, add rows in order of increasing slack until the congruence system becomes solvable (p. 5).

**Quotes**:
- "Theorem 5 puts comb separation in a different light, in that it allows for efficient exact separation of maximally violated members of the family of mod-2 cuts which contains, among others, comb inequalities." (p. 11)
- "Interestingly, at least for the case of extended comb inequalities both operations do not increase the Chvátal rank [29] of the starting inequality, and also preserve the property of being a mod-2 cut." (p. 12)

### S073 · Models and algorithms for optimizing cell suppression in tabular data with linear constraints (Journal of the American Statistical Association 2000, DOI 10.1080/01621459.2000.10474282)

First-page check: title and authors Fischetti and Salazar González match (p. 1).
**Role**: supplement · **Coauthors**: Juan José Salazar González · **Position in trajectory**: the generalization of the 2-D cell suppression work (S069, batch s01) inside the EU ESPRIT project on statistical disclosure control (from 1996, coordinated at CBS Voorburg), whose preliminary code for 2-, 3- and 4-D tables went into a CBS prototype package (named "r-ARGUS" in the OCR layer, p. 1); the same results appear in S072.

- **D1 Problem and entry point**: An agency must protect sensitive cells while publishing as much as possible (p. 1); suppressing a sensitive cell is not enough, since an attacker recomputes it from the marginals, and the attacker's range for a cell comes from two LPs (p. 1). - **D2 Core idea**: The classical model keeps two attacker tables f^k, g^k per sensitive cell with x-dependent bounds (p. 3), more than 10,000,000 variables for a 100 × 100 table with 5% sensitive cells (p. 3). Branch-and-cut: for each sensitive cell the attacker LP is solved at the master point and its optimal dual gives a violated capacity cut (pp. 4–5); strengthened capacity constraints (coefficients capped at the right-hand side), cover and bridgeless inequalities (p. 5); strong branching over the 10 variables closest to 0.5 (pp. 5–6); a constraint pool (p. 6); preprocessing that drops self-protected sensitive cells, and reduced-cost fixing (p. 6); an incremental attacker heuristic, also run after each node with costs biased by the LP solution (pp. 6–7).
- **D3 Problem class and data model**: A table vector with linear relations My = b and attacker bounds lb ≤ y ≤ ub (p. 2); for k-D tables with marginals M has entries 0 and ±1 and b = 0, a network only for k = 2 (p. 2); lower, upper and sliding protection levels per sensitive cell; weights w_i ≥ 0, typically proportional to a_i or log(a_i) (pp. 2–3); the attacker solves continuous LPs (Appendix, p. 12).
- **D4 Algorithm and implementation (brief)**: LP duality on the attacker subproblems, where only finitely many extreme dual solutions give undominated constraints (pp. 4, 12–13); the LP relaxation is solvable in polynomial time by the equivalence of separation and optimization (p. 5); the capacity cuts needed explicitly number about as many as the sensitive cells (p. 4).
- **D5 Computational evaluation**: ANSI C, CPLEX 3.0 as LP solver, Pentium II/266 with 32 MB (p. 7); 10 real tables from statistical offices (three 2-D, two 3-D, one 4-D, four linked), all solved (pp. 7–8); 1,160 random 3- and 4-D tables, 10 per class, a 3-hour limit on a Pentium II/400 and a count of solved instances per class (pp. 8–10); time grows exponentially with table size (Figure 2, p. 11) while the root gap stays moderate (Figure 3, pp. 11–12); no other method is run as a baseline.
- **D8 Contributions and limits**: The general model and the first proven optima for a 4-D table with marginals and for linked tables (pp. 1, 12). Limits printed: the initial heuristic is "rather poor" against the optimum (p. 7); the 4-D instance is much harder (more links, more nonzero protection levels, more fractional LPs) (p. 8); running time may grow exponentially (p. 11). Future: CSP-lib, a public library of real and synthetic instances with their solutions (p. 12).

**Method links**:
- Method 1 ✅ evidence (step 3, joint): the per-cell attacker tables are projected out by LP duality into capacity cuts on the suppression variables, and the move is named Benders (pp. 3–4, 12–13); the S069 card noted that the 1999 2-D paper did not use the word. It also fits Research Taste 4 (a classical method that fits).
- Method 6 ⚠ variant: the classical model is dismissed by a size count ("a size that cannot be handled explicitly", p. 3), not by a solver run on it.
- Method 4 ✗ contradiction (dated lapse, 2000): the authors state, as their opinion, that the initial heuristic is at least comparable to the suppression procedures practitioners use, without running any of them (p. 7).
- Method 4 ✅ evidence (step 6): losses are printed: the poor initial heuristic, the hard 4-D case and the exponential growth (pp. 7–8, 11).
- new-pattern candidate: Exact method as a yardstick for heuristics (proven optima and reliable lower bounds show the information loss of common heuristics, p. 7).
- new-pattern candidate: LP-guided heuristic costs (cell costs biased by x* in the incremental attacker heuristic after each node, pp. 6–7; also S072, S057, S125).
- new-pattern candidate: release solver, instances and optimal values (here instances only: random instances with optimal or best-known values from the second author, and a planned CSP-lib, pp. 10, 12; no code).

**Transferable techniques**:
- When a requirement must hold for an adversary's continuous LP (an attacker, a recourse, a follower), dualize that LP and impose the requirement as cuts on the master's binaries; separate by solving the LP at the master point and reading its dual (pp. 3–5, 12–13).

- Forbid redundant choices with a tiny fictitious requirement on every chosen nonessential item (bridgeless inequalities for suppressed nonsensitive cells, p. 5).
- Report the root-node upper and lower gaps, so that stopping after the root becomes a heuristic with a certified bound (pp. 8, 11–12).

- **D1 Problem and entry point**: NS Reizigers' project "Destination: Customer" sets new duty rules for punctuality: train teams of a driver and a conductor, variation within each duty, and train series assigned only to depots on their route (pp. 1, 4–6); NS needed an a priori estimate of the rules' effect on depot capacities (pp. 2, 6). The existing systems fall short: VPT only checks manual duties (p. 6); the automatic mode of CREWS is an A* search that is greedy, backtracks little, cannot check per-depot constraints and leaves many passenger trips (pp. 6–7). TURNI was the alternative (p. 7).
- **D2 Core idea**: A set covering model with extra per-depot constraints, trips as rows and feasible duties as columns, plus optional "suggested" and "inadvisable" trips (pp. 7–8). TURNI: dynamic column generation by a dynamic-programming duty generator priced with Lagrangian duals from subgradient optimization, in the vein of the Caprara–Fischetti–Toth set covering heuristic; a selection heuristic driven by the same duals; passes in which efficient duties are fixed by a score of Lagrangian cost and duty efficiency, the rest is re-solved, trips are exchanged among duties, and some fixed duties are released for the next pass (pp. 8–9). The rules are modelled through data: allowed depots per trip (p. 10); recoded train-series indicators, a bound on series transfers, penalties for one-series long duties and a filter against "artificial variation" (p. 10); First/Last trip attributes to bound underway train changes (p. 11); recoded train numbers for splitting and combining trains (pp. 11–12); deadheading plus timetabled inadvisable trips to make the second-conductor instances feasible (p. 12).
- **D3 Problem class and data model**: Duty rules are handled in generation (at most 9:30 hours, a meal break in duties longer than 5:30 hours, a 25-minute minimum connection) (p. 3); per-depot rules are side constraints (3) (pp. 3, 8); the cost is mainly the number of duties, plus penalties (p. 8); weekly cyclic data split into Tuesday, Saturday and Sunday instances, 8,000–10,000 train-team trips and 1,200–1,500 second-conductor trips per day (pp. 13–14).
- **D4 Algorithm and implementation (brief)**: no proofs; the Lagrangian lower bound is shown to the user during the run (p. 9).
- **D5 Computational evaluation**: Pentium II at 450 MHz with 128 MB (p. 12); single train series of up to about 400 trips in seconds to minutes; combined instances of up to 1,000 trips (satellite areas) and about 2,500 trips (large depots), little gain after the second pass, under one hour (pp. 13–14); the evaluation is qualitative, by the planners and against manual schedules built in parallel (pp. 13–14); no tables, no solver baseline.
- **D8 Contributions and limits**: Practical outcome: enough drivers but badly distributed over the depots, and extra conductors needed (p. 14); the rules will first be relaxed, and a perfect depot match was impossible under the strict assignment rule (p. 14); whether the rules improve robustness "will have to be proved in practice", with a simulation model planned (p. 14). Future: depot-dependent variation rules (p. 10) and whole-day instances of about 8,000 trips (pp. 7, 14).

**Method links**:
- Method 6 ⚠ variant: the model, not a constructive rule, is the kernel: the Lagrangian duals of the set covering relaxation drive both duty generation and selection (pp. 8–9), and the conclusion rejects greedy duty-by-duty construction for this class (p. 15); but the solver is TURNI's own Lagrangian heuristic, not a general-purpose MIP solver.
- Method 4 ⚠ variant: the baseline is the planners' practice (manual results obtained "in parallel", p. 14; solutions "comparable or better than the best manual ones", p. 9), but no numbers are given (pp. 9, 13–14).
- new-pattern candidate: Lagrangian fix-and-release (passes that fix efficient columns by a Lagrangian score and release some of them in the next pass, p. 9; the same scheme in S081, p. 9).
- H4 (heuristic, not a method) ✅: application first: a railway operator's planning question drives the code (pp. 2, 6–7).

**Transferable techniques**:
- Enforce new organisational rules by recoding data attributes the generator already reads (series indicators, train numbers, First/Last flags) instead of writing new constraints (pp. 10–12).
- When an instance is infeasible, let a deadheading generator find the missing moves, then add timetabled optional trips close to them and re-solve (p. 12).
- Solve the separable pieces first (one train series at a time) to learn their peculiarities, then compose the combined instances (p. 13).
- Show the running incumbent together with a Lagrangian lower bound, so the user can decide when to stop (p. 9).

**Quotes**:
- "already after the first fixings, the solutions are typically comparable or better than the best manual ones" (p. 9)
- "A more or less greedy heuristic that successively builds up the individual duties and that has only limited backtracking facilities is deemed to be incapable of capturing the complexities of scheduling drivers and conductors." (p. 15)

### S081 · Solution of real-world train timetabling problems (Proceedings of the 34th Hawaii International Conference on System Sciences 2001, DOI 10.1109/hicss.2001.926325)
**Read level**: full (all 24 file pages of an OCR text of a preprint; the prose is readable, but formulas are partly garbled and the numeric bodies of Tables 1–9 are mostly lost, so no table value is reported). First-page check: title and authors Caprara, Monaci, Toth, Fischetti, Guida, Sacco match (p. 1).
**Role**: supplement · **Coauthors**: Alberto Caprara, Pier Luigi Guida (FS), Michele Monaci, Giuseppe Sacco (FS), Paolo Toth · **Position in trajectory**: the real-world extension of the basic timetabling model of Caprara, Fischetti and Toth (cited as DEIS report OR-00-5, p. 24; the Operations Research 2002 paper is carded as S002 in batch c03), built as the TCM module of the EU TRIS project (pp. 2–3).

- **D1 Problem and entry point**: EU rail reform separates infrastructure managers from train operators and creates the access-to-infrastructure problem; TCM collects the operators' path requests and allocates capacity, with access fees (pp. 2–3). Entry: the basic TTP of [3] on a single one-way corridor lacks real-world features: manual signaling, station capacities, prescribed timetables, maintenance, periodic trains and two parallel lines (pp. 1, 3).
- **D2 Core idea**: Basic model: for each train a time-expanded acyclic multigraph whose source-to-sink paths are its feasible timetables; arc profits penalize shift and stretch; incompatible arc pairs, or clique constraints, enforce headways and forbid overtaking between stations (pp. 5–8). Relaxing the cliques in a Lagrangian way leaves one longest-path problem per train; [3] moves the capacity constraints to node variables to keep the multipliers manageable; the heuristic ranks trains by Lagrangian profit, schedules them one by one, re-optimizes on actual profits, fixes paths and unfixes them when the bound shows that the incumbent cannot be improved (pp. 8–9). The extensions mostly change the heuristic: forbidden nodes and arcs for manual signaling (p. 10) and maintenance (p. 12), interval lists searched by binary search for station capacities (p. 11), permanent fixing for prescribed trains (p. 11), a penalty against a running reference path for periodic families (pp. 12–14), and generalized successor lists with a redefined arc stretch for two parallel lines (pp. 14–16).
- **D3 Problem class and data model**: Minutes 1–1440 and a timetable repeated every day, constant speed on a segment, minimum headways a_i and d_i, time windows, and a profit per train from its priority, a nondecreasing shift penalty and a linear stretch penalty (pp. 4–5); maintenance is assumed to occupy a segment much longer than any travel time (p. 12); nonnegative stretch is imposed on alternative routes (p. 16).
- **D4 Algorithm and implementation (brief)**: no proofs; the Lagrangian upper bound (12) (p. 9).
- **D5 Computational evaluation**: C code on a Digital workstation at 533 MHz, 1,000 subgradient iterations (pp. 16–17); 8 corridor instances from FS (EU TRIS simulations of operator requests) and Ansaldo (actual FS requests), a_i = 4 and d_i = 2 minutes, linear shift penalties (pp. 16–17); the baseline is a priority greedy said to approximate manual practice (pp. 17–18); gains over it are small when the ideal timetable is nearly feasible and above 20% on the congested MU-VR instance (p. 18); each extension is priced by the change in profit and scheduled trains on the instances it concerns (pp. 18–22); no bound or gap is reported in the text.
- **D8 Contributions and limits**: Claims: solutions within limited resources on long, heavily loaded lines; technical and economic factors; real-life features; residual capacity and possible real-time use; TCM is being implemented in FS's capacity allocation system (pp. 22–23). Limits: the equivalence of the greedy baseline with manual practice is asserted, not measured (p. 18); manual signaling, station capacities and periodicity enter the heuristic only (pp. 10–11, 13), so the relaxation does not see them (my reading).

**Method links**:
- Method 4 ⚠ variant: the practitioner baseline is a proxy, a greedy said to match manual planning (p. 18), not the planners' own timetables.
- Method 1 ⚠ variant: [3]'s switch from arc incompatibilities to node-based capacity variables is chosen for multiplier storage and update speed (p. 9), a model choice driven by the algorithm rather than by the instance class.
- new-pattern candidate: Lagrangian fix-and-release (fix the most profitable paths, restart the subgradient, unfix when the bound certifies no improvement, p. 9; S061 p. 9).
- new-pattern candidate: Side constraints in the heuristic only (new operational rules enter as forbidden nodes, arcs or penalties inside the constructive heuristic, pp. 10–13).

**Transferable techniques**:
- Put each unit's feasibility into its own time-expanded acyclic graph, so that the relaxed problem per unit is a longest path and only the coupling constraints are dualized (pp. 6, 8–9).
- Add a new operational rule first as forbidden nodes or arcs inside the constructive heuristic, and measure its price on the instances it concerns before building it into the relaxation (pp. 10–12, 18–22).
- Make periodicity soft: penalize each train's deviation from a running average path of its family instead of forcing identical shifts (pp. 13–14).

**Quotes**:
- "methods proceed in a similar way, therefore the quality of the solution provided by the FS practitioners is close to the value given in this entry." (p. 18)
- "Typically, if the ideal timetable on input is almost feasible, the best solution found is not much better than the greedy one" (p. 18)

### S125 · A branch-and-cut algorithm for the multiple depot vehicle scheduling problem (author manuscript, no venue; Scholar year 2001; no DOI)
**Read level**: full (all 25 file pages of the author PDF, undated, citing a 1999 oral communication, p. 24; the text layer drops ligatures). First-page check: title and authors Fischetti, Lodi, Toth match (p. 1).
**Role**: supplement · **Coauthors**: Andrea Lodi, Paolo Toth · **Position in trajectory**: the MD-VSP manuscript whose results S057 reprints (S057 Tables 1–3, pp. 24–26); its PECs (7) are the depot case of S057's EPECs (S057 p. 11).

- **D1 Problem and entry point**: MD-VSP is NP-hard, polynomial for one depot or for depot-independent costs (p. 2); exact approaches are additive branch-and-bound, column generation, a three-index model, and the BMR set-partitioning scheme, "heuristic in nature" (p. 2). Entry: branch-and-cut on the arc model of Carpaneto et al., whose LP relaxation "typically yields poor lower bounds" (pp. 3–4).
- **D2 Core idea**: Model (1)–(5) with infeasible path constraints (4) (p. 4); PECs (6)/(7) for every trip set S and depot subset Q, dominating (4), with complement symmetry halving their number (pp. 4–5). Separation: one max-flow per Q over the 2^{m−1} − 1 subsets containing depot 1, polynomial for fixed m and practical up to m = 5 (otherwise |Q| ≤ 5), then a greedy refit of Q (p. 6); more cuts per round by splitting a merged PEC into the connected components of its support, by enumerating infeasible paths of the sparse support, and by nested PECs through shrinking with random capacity perturbation (pp. 6–8); LPIs (9), rank-1 Chvátal–Gomory cuts, separated by enumerating triples after shrinking 1-paths (pp. 8–10). Branch-and-cut: at most 15 new cuts per round, hashing, tailing-off and node-pausing rules (pp. 10–11); "aggressive" separation of points between x* and the two best incumbents, credited to Reinelt (pp. 11–12); transportation-problem pricing after Fischetti–Toth with a pricing frequency alternating between 1 and 10 (p. 12); lexicographic branching with fractionality persistency and heuristic recurrence (p. 13); the Dell'Amico–Fischetti–Toth heuristic on costs c̄ − 100x* (p. 14).
- **D3 Problem class and data model**: n trips, m ≤ n depots with r_k identical vehicles, start and end times, travel times, transition and depot costs (pp. 1–2); a complete graph with +∞ arcs, acyclic once the depot vertices are removed (p. 3); the random generator of Carpaneto et al.: relief points in a 60 × 60 square, 40% short and 60% long trips, depots at the corners, and 5,000 added to every depot arc so that the number of vehicles is minimized first (pp. 14–15).
- **D4 Algorithm and implementation (brief)**: PEC dominance over (4) by coefficientwise comparison (p. 5); a minimum cut gives the most violated PEC for a fixed Q (p. 6); LPI validity by a 1/3, 2/3 combination of PECs, SECs and cut constraints (pp. 9–10).
- **D5 Computational evaluation**: FORTRAN 77, CPLEX 6.0, Digital Alpha 533 MHz (p. 14); 120 random instances (m = 2, 3, 5; n up to 500, 400, 300; 10 per class) with per-instance tables of LB0 and root gaps, nodes, cut counts and the time to a 1% gap, on line and off line (pp. 15–18); BMR's published times with an assumed speed factor and caveats (other instances, 4 instead of 10 per class for n ≥ 200, a heuristic column set) (p. 19); an ablation of three devices plus a basic version, 10,000 s limit, averages over all 10 instances with unsolved runs at the limit (pp. 19–20); root lower-bound curves per variant on instance 2-500-01 (pp. 20–21); 15 real-world instances, one unsolved in 10,000 s with its bound printed (p. 22); all 135 instances public, with their file format (pp. 3, 24–25).
- **D8 Contributions and limits**: Two cut families with separation, generic speed-ups (nested cuts, deeper fractional points, persistency branching), an LP-driven heuristic and a public test bed (p. 23). Limits printed: performance deteriorates with several depots because of the many cuts (pp. 18, 23); the BMR comparison "is not immediate" (p. 19). Future: trip objections (p. 23).

**Method links**:
- Method 2 ✅ evidence (precursor, practice, joint): the loop separates points between x* and the two best incumbents before x* itself, an idea credited to Reinelt (pp. 11–12); without it the final root bound on 2-500-01 takes 1,400 s instead of 800 s (pp. 20–21), and class averages worsen (Table 5, p. 20). - Method 4 ✗ contradiction (dated lapse, mitigated): BMR's times come from a PC 80486/33 on other instances; the paper states the machine factor it assumes and the caveats (p. 19).
- new-pattern candidate: Infeasible-path cuts for side constraints (constraints (4) and their PEC strengthening, pp. 4–5).
- new-pattern candidate: History-based branching scores (fractionality persistency, "a completely general criterion", and heuristic recurrence, pp. 1, 3, 13).
- new-pattern candidate: Separate for cut patterns, not single cuts (nested PECs, because the joint action of a set of cuts matters more than each cut's violation, pp. 7–8; also S057 pp. 17–18).

**Transferable techniques**:
- For cuts indexed by a subset of a small set (depots), enumerate only the subsets containing a fixed element (complement symmetry), solve one max-flow per subset, and refit the subset greedily once a cut is found (pp. 5–6).

- Pause a node whose bound exceeds the best active bound by more than a fixed margin and put it back in the queue (p. 11).
- When comparing with published times from another machine, state the speed factor you assume and every difference in instances and counts (p. 19).
- Release the instances with a documented file format in an appendix (pp. 24–25).
