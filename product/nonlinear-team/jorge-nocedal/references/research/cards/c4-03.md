### S008 · An interior point algorithm for large-scale nonlinear programming (SIAM Journal on Optimization 9(4), 877–900, 1999, doi:10.1137/S1052623497325107)
**Read level**: full (second read, round 4). All 28 file pages of the OCR text were read: pp. 1–24 (abstract, §§1–5, Tables 1–5, with the table cells taken from the page images of pp. 21, 22, 24) and the references pp. 25–28 for the [7], [8] and [24] entries. Round-1 card: c03 (its numerals came from a `pdftotext -layout` extraction; these cards confirm them against the images and fill the cells it could not read).
**Role**: core · **Co-authors**: Richard H. Byrd (Colorado), Mary E. Hribar (Rice CAAM), Jorge Nocedal (Northwestern ECE) (p. 1) · **Place in the trajectory**: NITRO. Its theory, reference [8], is cited as "Report OTC 96/02 … 1996" and [7] (Byrd, Liu, Nocedal) as the future efficiency paper (p. 25). [24], Gould–Hribar–Nocedal "to appear", is S021 (p. 26).

- **D1 Problem and entry point**: unchanged from round 1 (c03 S008 D1; pp. 2–3). The OCR adds no numbers to the entry; the only quantified claims are in §4.
- **D2 Core idea and algorithm design (now with the equations and constants)**:
  - Outer loop: each barrier problem (2.1), min f − μ Σ ln sᵢ subject to h = 0, g + s = 0 (p. 3), is solved until E(x, s; μ) ≤ ε_μ. E is the maximum of the ∞-norms of the four perturbed-KKT residuals: stationarity, Sλ_g − μe, h and g + s, with least-squares λ (pp. 3–4). Then μ and ε_μ are both multiplied by θ; the run stops when E(x, s; 0) ≤ ε_TOL (p. 4).
  - Printed defaults: η = 10⁻⁸, τ = 0.995, θ = 0.2, ζ = 0.8, ε_TOL = 10⁻⁷; initial ε_μ = 0.1, μ = 0.1, Δ0 = 1 (p. 19). Between barrier problems ν_{k−1} and Δ_k are "adjusted", without a rule (p. 19). So μ falls by a factor of 5 per barrier problem: linear by design (pp. 4, 23).
  - Slack Hessian: μS⁻² (primal, (3.1)) or S⁻¹Λ (primal-dual, (3.11)) (p. 7). In the clipped form (3.14), μ/s² replaces an entry whose multiplier is negative, and the previous μ is used at the start of a new barrier problem (p. 9).
  - Trust region (3.18): ‖(d_x, S⁻¹d_s)‖₂ ≤ Δ and d_s ≥ −τs (pp. 9–10).
  - Vertical step (3.19): minimise the linearized constraint residual within ζΔ, with ζ = 0.8 (p. 10). The dogleg uses the Cauchy point (3.23), which needs only matrix-vector products, and the minimum-norm Newton step (3.24). It is compared with the truncated Newton step, and the one with the lower model value is taken (pp. 11–12).
  - Horizontal step, Algorithm III: projected CG with tol = 0.01‖g‖₂, at most 2(n − t) iterations, Steihaug's tests, and the slack bound applied by a final truncation (p. 15).
  - Penalty parameter: ρ = 0.3 in (3.50), pred ≥ ρν√(−m(ṽ)) (p. 16). Procedure I sets ν_k = max{ν_{k−1}, q(ṽ + w̃)/((1 − ρ)√(−m(ṽ)))} (p. 17, image). There is no growth factor.
  - Step acceptance: ared ≥ η·pred (3.53) (p. 17).
  - Radius update (3.54): Δ becomes max{7‖d‖, Δ} if r ≥ 0.9, max{2‖d‖, Δ} if 0.3 ≤ r < 0.9, and stays Δ if η ≤ r < 0.3, where r = ared/pred. After a rejection, Δ is at most one half and at least one tenth of the step length, by interpolation (p. 17); the complete algorithm writes this as Δ_{k+1} ∈ [0.1Δ_k, 0.5Δ_k] (p. 19).
  - Second-order correction: only when ‖v_k‖ ≤ 0.1‖w_k‖ (p. 18), accepted if ared(d + y) ≥ η·pred(d) and the printed slack test s_k + d_x + y_s ≥ τs_k holds (p. 19).
  - An accepted step sets s_{k+1} = s_k + d_s, with no slack reset (p. 19).
  - One MA27 factorization of the augmented matrix serves all three systems (p. 18).
  - Transferable: print the code's defaults as one list next to the algorithm statement (p. 19), so that every constant in the text has a value.
- **D3 Assumptions and model**:
  - As in round 1: smooth f, h and g with first and second derivatives (p. 2). No theorem in this paper; the trust region (3.18) differs from the analysed model, and the extension is "not difficult" (p. 10).

### S009 · A trust region method based on interior point techniques for nonlinear programming (Mathematical Programming 89(1), 149–185, 2000, doi:10.1007/pl00011391)
**Read level**: full (second read, round 4). All 37 file pages of the OCR text: pp. 1–35 read, with every lemma and proof followed; references pp. 35–37 skimmed. OCR garbles displayed formulas, so Lemma 2.1, Lemma 2.2 and step 3 of Algorithm I were checked on the page images (pp. 12, 17). Round-1 card: c04.
**Role**: core · **Co-authors**: Richard H. Byrd (Colorado), Jean Charles Gilbert (INRIA Rocquencourt) (p. 1) · **Place in the trajectory**: preprint dated August 10, 1998 (p. 1). It cites NITRO as Report OTC-97/04 (p. 35), while NITRO's July 1997 preprint cites this theory as Report OTC 96/02, 1996 [S008 p. 25]. The order is theory report, then code paper, then the revised theory read here (dates from the two texts).

- **D1 Problem and entry point**: unchanged from round 1 (c04 S009 D1; pp. 2, 6, 33). For simplicity of exposition the paper treats inequality constraints only; equalities are handled in [4] = NITRO (pp. 2, 6).
- **D2 Core idea and algorithm design (now with the equations and constants)**:
  - Barrier problem (1.2), min f(x) − μ Σ ln s⁽ⁱ⁾ subject to g(x) + s = 0 (p. 2), rewritten as min φ(z) subject to c(z) = 0 (1.10) (p. 3).
  - Subproblem (1.16): min ∇φᵀd + ½dᵀWd subject to Âᵀd + c = 0, ‖(d_x, S⁻¹d_s)‖ ≤ Δ and d_s ≥ −τs, with τ ∈ (0, 1) "chosen close to 1" (p. 4).
  - Normal subproblem (1.17): least-squares linearized feasibility within ξΔ, with d_s ≥ −ξτs, "say ξ = 0.8" (p. 5).
  - Merit function (1.19): φ(z) + ν‖c(z)‖, with the Euclidean norm unsquared (p. 5).
  - Algorithm I takes four constants ξ, τ, ρ, η ∈ (0, 1) and ν₋₁ > 0 (p. 16).
    - Step 3: ν̃_k is the smallest ν with pred ≥ ρν·vpred (2.36). If ν̃_k ≤ ν_{k−1}, ν is kept; otherwise ν_k = max(ν̃_k, 1.5ν_{k−1}) (p. 17, image).
    - Step 4: the step is rejected if φ(x + d) > φ(x) − η·pred, and Δ is cut by a constant factor (p. 17), "e.g." Δ_k/2 (p. 10).
    - Step 5: s_{k+1} = max(s_k + d_s, −g_{k+1}) and Δ_{k+1} ≥ Δ_k (p. 17).
  - Decomposition (2.37)–(2.38): pred = ν·vpred + hpred + χ, where χ (the normal step's effect on the objective) can have either sign. (2.36) holds once ν ≥ −χ/((1 − ρ)·vpred) (p. 17, image).
  - Primal and primal-dual SQP steps differ only in the slack block: μS⁻² (1.13) against S⁻¹Λ (1.27) (p. 8).
- **D3 Assumptions and model**:
  - Assumptions 4.1 (p. 20): (a) f and g are differentiable on an open convex set containing the iterates, with ∇f, g and A Lipschitz there; (b) {f_k} is bounded below and {∇f_k}, {g_k}, {A_k}, {B_k} are bounded. No full-rank assumption (p. 20).
  - Inexact steps: the range-space condition (2.11) (p. 11); the normal Cauchy decrease condition (2.15) with γ_v > 0 (p. 10), which an exact solution satisfies with γ_v ≤ 1 (p. 12); the tangential Cauchy decrease condition (2.31) with γ_h > 0 (p. 15). Null-space bases need a bounded norm and a smallest singular value bounded away from zero (2.28) (pp. 14–15).
  - New from comparing the two texts in this batch: the analysed algorithm is not NITRO.
    - NITRO's penalty rule has no growth factor [S008 p. 17].
    - Its accepted step has no slack reset [S008 p. 19].
    - Its radius update uses 7‖d‖ and 2‖d‖ expansions with interpolated contraction [S008 p. 17], against "this simple rule" here (p. 10).
    - It runs the primal-dual version, found superior [S008 pp. 2, 21], against the primal version analysed here "because of its simplicity" (p. 8).
  - The factor 1.5 and the slack reset are not cosmetic. "Increased infinitely often … at least by a constant factor" gives ν → ∞ in Lemmas 4.7 and 4.8 (pp. 26–27); the reset gives g_k + s_k ≥ g_k⁺ (4.13) (p. 26) and is controlled in Lemma 4.5 (p. 23).
- **D4 Analysis and proof devices (statements now readable)**:
  - Lemma 2.1 (p. 12), generalizing a one-dimensional result of Powell: for min over z ≥ 0 of ψ(z) = ½az² − bz subject to z ≤ t, with b ≥ 0 and t > 0, the optimal value is ψ* ≤ −(b/2)·min{t, b/|a|}.
  - Lemma 2.2 (p. 12): ‖g_k + s_k‖·vpred_k ≥ (γ_v/2)·‖(A_k; S_k)(g_k + s_k)‖·min(Δ̃_k, ξτ, ‖(A_k; S_k)(g_k + s_k)‖/‖(A_kᵀ S_k)‖²).
  - Lemma 2.3 (p. 16) is the tangential analogue, a bound proportional to the steepest-descent vector p_k^c.
  - Lemma 3.1 (p. 18): |pred_k(d) − ared_k(d)| ≤ γ_L((1 + ν_k)‖d_x‖² + ‖S_k⁻¹d_s‖²).
  - Proposition 3.2 (p. 19): at a non-stationary point some Δ⁰ > 0 exists such that every Δ_k ∈ (0, Δ⁰) is accepted.
  - Lemmas 4.4–4.11:
    - 4.4: the slacks are bounded (p. 22).
    - 4.5: steps are ≤ γ_s·Δ_k despite the reset (p. 23).
    - 4.6: (A_k; S_k)(g_k + s_k) → 0 (p. 24).
    - 4.7: A_k g_k⁺ → 0, and ν_k → ∞ if the iterates are not asymptotically feasible (p. 26).
    - 4.8: either σ_min((A_kᵀ S_k)) ≥ σ̂ > 0 for all k, or a limit point fails LICQ and ν_k → ∞ (p. 27).
    - 4.9: ‖(v_x, S⁻¹v_s)‖ ≤ γ₃·vpred near feasibility (p. 27).
    - 4.10: ν_k is eventually constant, because once ν > γ′/(1 − ρ) it is never raised again, and pred ≥ γ₄·hpred (pp. 29–30).
    - 4.11: the slacks are bounded away from zero, g_k < 0 eventually, and ∇f_k + μA_kS_k⁻¹e → 0 (p. 30).
  - Theorem 4.3, restated as 4.12 (pp. 21, 32–33):
    - (1) the slacks are bounded;
    - (2) A_k(g_k + s_k) → 0 and S_k(g_k + s_k) → 0;
    - then one of three outcomes: (i) not asymptotically feasible, A_kg_k⁺ → 0 and ν_k → ∞; (ii) asymptotically feasible with a limit point failing LICQ, ν_k → ∞; (iii) LICQ at all limit points, ν constant, s bounded away from zero, stationarity with λ_k = μS_k⁻¹e.
  - Algorithm II and Theorem 5.1 (pp. 33–34):
    - Barrier update: μ_{l+1} ∈ (0, αμ_l). Inner stops: (5.1) ‖g + s‖ ≤ ε_l and (5.2) ‖∇f + Aλ‖ ≤ ε_l, with λ = μ_l S⁻¹e.
    - Outcome (A): some inner problem never stops, which means stationarity of ‖g(x)⁺‖ or a limit point failing LICQ.
    - Outcome (B): all limit points are feasible and satisfy the KKT conditions with λ ≥ 0 and gᵀλ = 0 wherever LICQ holds.
  - Proof template, used twice (pp. 24–26, 31–32): take a ball of radius θ_l/(2γ_θ) around a non-stationary iterate. Inside it small steps are accepted (4.9). The iterates must leave the ball, or the merit function would go to −∞. Leaving costs a fixed merit decrease ((4.10), (4.12)), and a merit function bounded below gives the contradiction.

**Transferable techniques**:
- If a growth factor in a parameter update (ν ← max(ν̃, 1.5ν)) is what makes "raised infinitely often ⇒ unbounded" true, put it in the algorithm statement, and say whether the code has it (pp. 17, 26).
- Reset the slacks of satisfied constraints, s ← max(s + d_s, −g), so that g + s ≥ g⁺ (4.13). This turns non-convergence into a statement about the infeasibility measure ‖g(x)⁺‖ (pp. 17, 26).

### S021 · On the solution of equality constrained quadratic programming problems arising in optimization (SIAM Journal on Scientific Computing 23(4), 1376–1395, 2001, doi:10.1137/s1064827598345667)
**Read level**: full (second read, round 4). All 30 file pages of the OCR text: pp. 1–27 read; the cells of Tables 1–4 (pp. 23, 24, 26) taken from the page images; references pp. 28–30 skimmed. Round-1 card: c04.
**Role**: core · **Co-authors**: Nicholas I. M. Gould (Rutherford Appleton Laboratory), Mary E. Hribar (Rice CAAM) (p. 1) · **Place in the trajectory**: preprint dated September 6, 2000 (p. 1). This is the paper NITRO hands its refinement problem to: NITRO cites it as [24] for preferring the augmented system and as the "current investigation" into error detection and refinement [S008 pp. 18, 23, 26]. - **D1 Problem and entry point**: as in round 1 (pp. 2–3). Now with numbers:
  - Example 1 (pp. 8–9): a 2 × 4 matrix A with κ(A) = 7.142E+03. The normal-equations projection gives cos θ = −0.15 against 9.6E−21 for the exact projection, and the augmented system gives −.0032, "not acceptable either" (p. 9).
  - Example 2 (p. 9): CVXEQP3 with n = 1000 and m = 750. At iteration 50, r is of order 10⁵ while its projection g is of order 10⁻¹.
- **D2 Core idea and algorithm design (now with the constants)**:
  - Acceptance threshold: cos θ (3.15) below ε_m^0.75 ≈ 10⁻¹² "is sufficient" (p. 10).
  - Multiple projections and augmented-system refinement are applied while the cosine exceeds 10⁻¹² (Example 3, p. 13; Example 4, p. 16). One refinement step is normally enough, two or three sometimes help (p. 17). With the residual update, use at most one or two refinement steps (p. 18).
  - Algorithm IV (pp. 20–21) has a cosine tolerance θ_max and uses α = gᵀg/pᵀHp and a gᵀg stopping test, whose numerators cannot turn negative (p. 21).
  - G = diag(H) is suggested for barrier terms on bounds, G = I for trust-region methods, which the paper treats as unpreconditioned (p. 5).
- **D3 Assumptions and model**: as in round 1 (full row rank; H positive definite on the null space "for convenience"; ‖A‖ = 1 and G = I in the analysis; pp. 2, 10–11). Constants now readable:
  - γ = 2.5n^{3/2} in (4.1) (p. 11).
  - The bound assumes ε_m κ²(A) somewhat smaller than 1 (footnote, p. 11).
  - When ‖g‖ is small its denominator becomes max(‖g‖, ε), with ε a multiple (e.g. 10) of ε_m (footnote, p. 11).
- **D4 Analysis and proof devices (statements now readable)**:
  - Normal equations, (4.1) and (4.3): ‖Δv‖ ≤ γ ε_m κ²(A)‖v‖, and the relative projection error is ≤ γ ε_m κ²(A)·‖v⁺‖/‖g⁺‖, a ratio of at least about ‖r⁺‖/‖P_A r⁺‖ (p. 11). A typical outer stopping test at a 10⁻⁶ reduction gives a ratio of about 10⁶, which is tolerable in double precision when κ(A) is moderate (p. 12).
  - The bound checked against the run (p. 12): for Example 2, γ = O(10⁴), ε_m = 10⁻¹⁶, κ(A) = O(10³), ‖A‖ = O(10), and the ratio is O(10⁶) at iteration 50. So "there could be no correct digits" in g⁺; the product is O(1) (my arithmetic). The bound "appears to be reasonably tight in this example", where CG stalled.
  - Augmented system: the error bound is linear in κ(A) (plus σ₁), and its multiplying factor is "difficult to predict" (p. 12).
  - Multiple projections: the error contracts R-linearly with rate γ ε_m κ²(A) (5.7), and improvement is guaranteed only if that rate is below 1 (pp. 14–15). On Example 1, cos θ = 6.2E−14 after one refinement and 9.6E−21 after a second (p. 13).
  - The least-squares perturbation bound (5.8) is linear in κ, which shows that the normal-equations approach is not backward stable (p. 15).
  - Augmented-system refinement reaches 9.6E−21 on Example 1 in one step (p. 16), and so does the residual update alone (p. 18).

**Method links**:
- Method 3 ✅ evidence (rounding error as the regime): an internal diagnostic (the cosine) with a threshold tied to machine precision, ε_m^0.75 ≈ 10⁻¹² (p. 10). The costly fix is applied only above it (pp. 13, 16), and the one-component repair (the residual update) is ablated against a reset done only at the start (pp. 18–19). In numbers: the test is met on 13 of 14 QPs against 11 for refinement alone and at most 1 for the baseline (p. 23).
- Method 5 ✅ evidence (step 4 with numbers): the error bound, evaluated with Example 2's constants, predicts no correct digits exactly where CG stalls, and is called "reasonably tight" while generally "overly pessimistic" (p. 12).
- Method 4 ✅ evidence: the refinement problem NITRO names [S008 p. 23] is answered here, and the remedies are shipped in NITRO, GALAHAD and HSL VE12/VE19 (pp. 22, 25).

**Transferable techniques**:
- Set the trigger for a costly accuracy fix from machine precision (here ε_m^0.75 ≈ 10⁻¹²), and apply the fix only when a cheap per-iteration diagnostic exceeds it (pp. 10, 13).
- Plug the failing example's own constants (γ, ε_m, κ, the norm ratio) into the error bound and show that it predicts the stall (p. 12).
- When no variant meets the test, tabulate the best residual each variant reached instead of a bare failure mark (p. 24).
