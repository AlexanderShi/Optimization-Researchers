### S717 · Development of a Multivariable Proxy Model for Six-Minute Walk Distance (6MWD) in Duchenne Muscular Dystrophy (DMD) Using Machine Learning Methods (682) (Neurology 94 (15_supplement), abstract 682, 2020, DOI 10.1212/wnl.94.15_supplement.682)
**Read**: abstract (a meeting abstract; text via OpenAlex) · **Role**: supplement · **Coauthors** (Crossref): Nicolae Done, Joel Iff, James Signorovitch, Erik Henricson, Jimmy Royer, Craig McDonald; Bertsimas is fourth of seven
- **D1 Problem & entry** {ML+AP}: the six-minute walk distance (6MWD) is a common endpoint in DMD trials but rarely used by clinicians. The aim is a proxy built from variables available in clinical practice (abstract).
- **D2 Key idea**: four learners select predictors: regression trees, optimal regression trees (ORT), random forests and LASSO, all with ten-fold cross-validation. The top predictors are then re-checked in a cross-validated linear regression (abstract).

**Method links**:
- Method 4 ✅ (step 5 only): the optimal tree is dueled against greedy trees, random forests and LASSO under one cross-validation protocol, and a plain linear model is printed beside it (abstract). No solver, time limit or certificate is mentioned.

**Transferable**: when a nonlinear model wins, refit a cross-validated linear model on its top predictors and print both scores, so the reader sees what the nonlinearity adds (abstract).

**Quotes**:
- "Predictors were selected using regression trees, optimal regression trees (ORT), random forests, and LASSO regression." (abstract)

### H001 · Adaptive Linear Algebra (homepage preprint 2023, no DOI)
**Read**: abstract. Page 1 of the homepage-linked author PDF was read only to check the title and authors. The abstract is recorded in abstracts-chase-a3-04.json, and the PDF is saved for the next round. · **Role**: supplement · **Coauthors** (PDF p. 1): Thodoris Koukouvinos
- **D1 Problem & entry** {RO+LO}: two basic problems of linear algebra, linear systems and eigenvalue–eigenvector pairs, when the data are uncertain (abstract).
- **D2 Key idea**: let the solution be an affine function of the uncertain parameters (affine adaptive optimization), derive upper bounds on the optimal value, and solve to optimality with cutting planes. For eigen-pairs the policy is linear, and all pairs are computed by alternating optimization (abstract).
- **D8 Contribution** (abstract):
  - Adaptive linear systems have a lower condition number than the nominal, so they are more accurate on ill-conditioned matrices.
  - They beat the robust solution on multi-period systems by using the realized errors of earlier periods.
  - Adaptive eigen-pairs beat nominal and robust ones on perturbed ill-conditioned matrices.
  - The all-pairs step by alternating optimization claims no optimality.

**Method links**:
- Method 1 ✅: a problem of numerical linear algebra is recast as adaptive robust optimization and solved exactly by cutting planes (abstract).
- Method 4 ⚠ variant: dueled against the nominal and robust solutions; exact for each eigen-pair, but with no certificate for the alternating all-pairs step (abstract).
- new-pattern candidate: **adaptive sequel**. The robust version appears to be S458, "Robust linear algebra" (same two authors; card s2-18) [inferred from title]; this paper lets its solution adapt.

**Transferable**: after a robust formulation of a problem, allow affine adaptive solutions and test them where realized errors are observed between periods (abstract).

**Quotes**:
- "We derive upper bounds for the optimal value and solve the problem to optimality using cutting planes." (abstract)
- "We show that for adaptive linear systems the condition number of the underlying matrix is reduced from the nominal and therefore the solution is more accurate on linear systems involving ill-conditioned matrices." (abstract)
