### S067 · Sensitivity analysis for mixed binary quadratic programming (Mathematical Programming 2026, doi:10.1007/s10107-025-02265-6; read as arXiv:2312.06714v2)
**Read level**: full (pp. 1-43: main text, all proofs of §§3-4 including the clique-of-six non-attainment proof, conclusion, references, Appendix A and the per-density tables of Appendix B). **Role**: core · **Coauthors**: Diego Cifuentes, Jingye Xu (both Georgia Tech; the three are marked as contributing equally, p. 1) · **Place in trajectory**: journal version of the IPCO 2024 paper (ref [16], p. 3); part of the 2024-2026 dual-bound line with the same coauthors (the decomposable Lagrangian dual, ref [34] arXiv:2411.12085, is used for the Appendix A instances, p. 40).

- **D1 Problem and entry point**: Entry is an operational setting: similar MBQPs are re-solved repeatedly with the same constraint matrix and changing right-hand sides, because the constraints describe "invariant physical resources" (p. 2). Solvers find good primal solutions fast but struggle with matching dual bounds (p. 2), backed by Appendix A: on ten instances Gurobi's primal is within 1.6% of the best known dual after 60 s but its own dual gap is still 12.1% after 1200 s (Table 7, p. 40). The classical sensitivity theory for IPs (Cook et al. [8] and successors) gives nothing for binaries because it relies on the infinity norm of integer variables (p. 2). So the question is: from an already solved instance, infer dual bounds on z(b + Δb) (p. 2).
  - Transferable: before building a method, put a one-table appendix that shows the gap you claim exists (primal near-optimal early, dual bound stuck) on instances you did not design for the purpose (Appendix A, p. 40).
- **D2 Key idea and algorithm design**: Use Burer's completely positive reformulation of MBQP [14], which is convex, so its copositive dual gives, by weak duality, a lower bound on z(b + Δb) as an explicit function of Δb (eq. (4), pp. 4-5). Three results then shape the method: a closed-form near-optimal dual built from two "building blocks", KK_i (the homogenised square (b_i t - a_i'x)^2) and G_j (a penalty on non-binary x_j), plus τH - lT (eq. (7), pp. 6-7); Proposition 5: adding KK_i to any ε-optimal dual keeps it ε-optimal, so the ε-optimal dual set is never a singleton (p. 9), and each such addition worsens the sensitivity bound by (Δb_i)^2 (Remark 3, p. 10). Hence the algorithm searches the ε-optimal face for a dual with small KK contribution (problem (9), p. 10), with extra linear blocks K_i, l as a variable, McCormick columns, and the copositive cone replaced by S+ + SP so that an SDP is solved (problem (12), p. 11). The weights w(1), w(2) are set so the objective equals the average predicted bound over the target range of Δb (pp. 11-12). What did not change: Burer's reformulation itself, and the weak-duality bound (4).
  - Transferable: when a convex reformulation has many optimal duals and you will use the dual for something downstream (here, bounds under perturbation), do not take the solver's dual; write the downstream quantity as a function of the dual and optimise it over the near-optimal dual face (pp. 9-12).
- **D3 Assumptions and model**: MBQP min x'Qx + 2c'x s.t. a_i'x = b_i, x >= 0, x_j binary for j in B, rational data (p. 2). Assumption (A): the linear constraints imply 0 <= x_j <= 1 for binaries, "without any loss of generality" by adding slacks (p. 4). Strong duality results need P bounded or Q PSD (Theorem 3, p. 5); a finite lower bound l on z(b) is assumed known (p. 5). The computations replace COP by S+ + SP, which is a restriction of the dual with no guarantee (p. 11; stated as open, p. 36).
- **D4 Analysis and proof devices**: (i) Hardness (Theorem 1, p. 3; proof pp. 16-18): a two-sided (Γ1, Γ2)-approximation of |Δz| is NP-hard; the reduction writes edge colouring of a cubic graph as a binary program with a constraint sum(-w_i) <= -4, which Vizing forces to value 4, then changes that one right-hand side to -3: Δz is 1 if the graph is 3-edge-colourable and 0 otherwise, and any two-sided approximation returns p > 0 exactly in the first case (Holyer [25], pp. 16-18). The definition is justified on the page: without the lower factor an algorithm could "cheat" by returning 0 (p. 3). (ii) Theorem 3(a) (Slater point when P is bounded): H = T + sum AA_i is strictly copositive by a recession-direction argument against Assumption (A) (Lemma 1, pp. 18-19). (iii) Theorem 4 (local stability, p. 7; proof pp. 19-23): perturb rhs and binarity by ε; split the feasible set into finitely many polyhedra indexed by binary patterns w; an LP shows the set of non-empty patterns does not change for small ε (Prop. 9, p. 20); Vavasis's characterisation of QP optima [20] makes each piece's value a quadratic in ε, so the minimum is piecewise quadratic and Lipschitz, hence bounded below by l - t2 ε (pp. 22-23). (iv) Theorem 3(b) (closed-form ε-optimal dual, Theorems 12-13, pp. 28-33): show copositivity of U by splitting non-negative y = [t; x] into three cases: a linear equation violated → the KK_i "penalty" pays; x_j/t far from {0,1} → G_j pays; otherwise x/t is almost feasible and local stability pays (pp. 24, 29-30); constants come from LPs and a Charnes-Cooper transformation of a linear-fractional program (pp. 25-27). The authors call the blocks augmented-Lagrangian-like penalties and cite their exact augmented Lagrangian duality work [26, 27] (p. 24). Remark 1 notes the construction gives an alternative proof of Burer's theorem when Q is PSD or P bounded (p. 7). (v) Boundary: Theorem 3(c), a two-variable instance min x1^2 - x2^2, x1 = x2, x >= 0, with Q not PSD and P unbounded, where the COP dual is infeasible (p. 8), and Remark 2 shows local stability fails there, so "the sufficient conditions for local stability Theorem 4 cannot be further relaxed" (p. 8). Theorem 3(d): the COP dual of the stable-set MBQP on a 6-clique has no optimal solution although there is no gap; proof by a sequence of test vectors y1, y+, y-, y2 that force all γ_v equal and then a contradiction (pp. 33-36). Theorem 12's constants are called "rather loose" (p. 28).
  - Transferable: to prove a hand-built matrix is copositive, partition the non-negative orthant by which constraint the normalised point violates and assign one PSD "penalty block" to pay for each violation; the residual near-feasible case is covered by a stability lemma about an ε-perturbed problem (pp. 24, 29-30).
  - Transferable: to show an approximation of a sensitivity quantity is hard, build a trivial program whose value under a one-unit rhs change encodes an NP-hard yes/no property; the two-sided approximation factor then decides it (pp. 16-18).
  - Transferable: to show a parametric optimal value is locally Lipschitz in a rhs perturbation for a nonconvex QP with binaries, enumerate the binary patterns, freeze the set of non-empty patterns for small ε by an LP threshold, and use Vavasis's finite-candidate characterisation to make each piece quadratic (pp. 19-23).
- **D5 Numerical experiments**: Five synthetic classes: COMB (cardinality-constrained weighted stable set on random bipartite graphs, 10+10 nodes, density 0.3/0.5/0.7, Δp = 1..10), KBQP (BQP library Q, n = 100, cardinality p = 10, ten instances), SSLP and SSQP (n = 20, m = 5, on/off continuous variables, linear or quadratic objective, Δb in {0,...,3}^m), PACK (n = 100, m = 10; 2,000 sampled Δb) (pp. 12-13). For PACK the rhs is reset to b = Ax* - e because random packing instances were "likely to be insensitive" to small rhs changes (p. 13). Baselines: Shor1 and Shor2 (Shor SDP + non-negativity + McCormick, Shor2 also with the squared constraints) and Cont (continuous relaxation) (pp. 13-14). Ground truth z(b + Δb) by solving each perturbed MBQP; metric "relative gap" (z - p_method)/(z - p_Shor1), so Shor1 = 1 and smaller is better (p. 14). Julia 1.9, Gurobi 9.0.2, Mosek 10.1, a Windows PC with an i7 and 16 GB RAM (p. 13). Results: "our method provides the tightest sensitivity bounds in all cases" (p. 14), and Shor2 is worst although it is close to Burer's formulation, explained by multiple optimal duals (pp. 14-15). Amortisation argument: once the dual is computed, bounds for all 4^10 Δb of PACK take about 10 s, versus an expected day of solver time (p. 16). A weight sweep (σ = 2..10) shows each σ is best near Δk = σ (Table 1, p. 15). My reading against the tables: the "all cases" claim does not hold at Δk = 1 for COMB, where the method's average relative gap is 1.28, worse than Shor1 (1) and Cont (0.90) (Table 1, p. 15; also 1.35/1.13/1.36 by density, Tables 8-10, pp. 40-41). The method is also slower than Shor1 on KBQP (1845 s vs 1313 s, Table 2, labelled "SBQP", p. 15). Tables 17-19 print two numbers in the method's single column (pp. 42-43).
  - Transferable: if the instance generator makes the studied effect vanish (random rhs gives no sensitivity), move the instance to where the effect exists (reset b to Ax* - e) and say why in one sentence (p. 13).
  - Transferable: when the method's output is a function of a perturbation, choose its free weights to maximise the average bound over the declared target range, and show a sweep where the weight targets other ranges (pp. 11-12, 15).
- **D6 Positioning**: Continues Cook-Gerards-Schrijver-Tardos IP sensitivity [8] and its successors [9-13], judged not by criticism but by a precise reason they fail for binaries (p. 2). Burer's CPP reformulation [14] is the starting point; using it for shadow prices was "first considered" by Guo-Bodur-Taylor [15] for electricity markets (p. 2). Part (a) of Theorem 3 is credited to Brown et al. [17] (non-constructive, via Kim-Kojima [18]) and a Linderoth-Raghunathan presentation [19] "explores similar questions" (p. 5); parts (b)-(d) are claimed new "To the best of our understanding" (p. 5). Copositivity cutting-plane works [15, 19, 32, 33] are named as the next place the structure could help (p. 37).
- **D7 Writing and rhetoric**: Results-first layout: "section 2 presents all our results. Details of the proofs are presented in section 3 and section 4." (p. 3). Proof sketches in §2 carry the intuition, long proofs are deferred (pp. 6-7). The negative parts (c), (d) are set beside the positive ones inside one theorem (p. 5), and the paper answers its own question "Is this an artifact of our proof technique?" with part (d) (p. 5). Hedging is moderate and placed: "Preliminary computations" in the section title (p. 10), "We hope that the structure information ... could perhaps offer opportunities" (p. 7), "rather loose" (p. 28). The results paragraph is the least hedged sentence in the paper ("tightest sensitivity bounds in all cases", p. 14).
- **D8 Contribution and limits**: Contribution: theory (hardness, strong duality conditions with counterexamples, non-attainment, local stability) plus an SDP algorithm and a preliminary computational study. Limits stated: instance size limited by the SDP solver (p. 36); no guarantee for the S+ + SP restriction (p. 36); constants loose (p. 28). Future work: extend strong duality to generalised copositive reformulations of QCQPs [29], scalable SDP solvers [31], cutting planes for (3) using part (b)'s structure (pp. 36-37). Unstated (my reading): instances are small (n ≤ 100) and synthetic; Δb only increases in the tested ranges; the Δk = 1 exception to "all cases" is not discussed.

**Method links**:
- Method 4 ✅ evidence: the main theorem is a demarcation in one statement: sufficient conditions (a), (b), a counterexample when both are dropped (c), and non-attainment even when they hold (d); Remark 2 shows the local-stability hypotheses "cannot be further relaxed" (pp. 5, 8); hardness of approximation comes first (p. 3).
- Method 5 ✅ evidence: motivated by dual bounds solvers cannot find (p. 2, App. A p. 40); the deliverable is a dual bound for every Δb from one tractable SDP (S+ + SP instead of COP), with the amortised cost reported (pp. 11, 16).
- Method 3 ⚠ variant: the MILP list move ("what does IP theory know? sensitivity theorems [8]; does it transfer?") is applied to MBQP, but the answer is a conic reformulation and duality, not a substructure convexification (p. 2).
- Method 2 ⚠ variant: ground truth is the exact z(b + Δb) of each perturbed instance (p. 14), but the reported metric is normalised to a baseline relaxation (Shor1), not to the ceiling, and there is no stripped instrument.

**Transferable techniques**:

### S080 · Regularized MIP model for integrating energy storage systems and its application for solving a trilevel interdiction problem (INFORMS Journal on Computing 2026, doi:10.1287/ijoc.2024.0771; read as arXiv:2402.04406v2)
**Read level**: full for pp. 1-24 (main text, examples, tables, conclusion); the case analysis of the Theorem 1 proof (pp. 6-9) and Appendix A (proof of Theorem 2 via Lemmas 1-2, pp. 26-32) skimmed for structure only; Appendix B (trilevel formulation, dual (15), Proposition 5, McCormick step, pp. 32-34) read. **Role**: core · **Coauthors**: Dahye Han (Georgia Tech), Nan Jiang (Cornell Tech), Weijun Xie (Georgia Tech) · **Place in trajectory**: power-systems application line after the AC-OPF SOCP work and the N - k / relay-attack work with E. S. Johnson (Johnson and Dey 2022, cited for dropping Ohm's law, p. 17); uses the ℓ1-sparsity idea of his sparse-regression dual-bound paper (Dey et al. 2022, p. 3).

- **D1 Problem and entry point**: Two entries. Modelling: exact battery models need a binary per time and bus to forbid simultaneous charging and discharging; the common LP relaxations "may yield unrealistic solutions for the sake of simplicity", with Arroyo et al.'s counterexamples showing simultaneous charge and discharge (p. 2). Application: no prior work on battery placement under N - k contingency (p. 2); a trilevel min-max-min problem with binaries at every level is out of reach: even for IEEE 14-bus with the first level fixed, the Zeng-An bilevel algorithm does not converge in 6 hours (p. 18).
  - Transferable: open an application paper with the solver experiment that fails on the smallest instance; one sentence of this kind justifies a reformulation better than a complexity citation (p. 18).
- **D2 Key idea and algorithm design**: Read the complementarity p^c_t p^d_t = 0 as a sparsity condition and add an ℓ1 penalty λc sum p^c + λd sum p^d to the objective, "in the same spirit" as the lasso and Dey et al. 2022 (pp. 2-3). Theorem 1: if the minimum charge and discharge rates are 0 and λc + ηc ηd λd >= 1 - ηc ηd, the regularised MIP has the same value as its LP relaxation (p. 6). The penalty depends only on the efficiencies and is small for realistic ones (p. 3; at η = 0.95 the threshold 1 - η^2 is about 0.1, my computation from the condition). The regularised optimum is feasible for the original problem, hence an upper bound (p. 3). Then use it as the third level of the trilevel problem: the third level becomes an LP (Theorem 1), is dualised, its duals are bounded (Remark 2, p. 18; Proposition 5, p. 34), so the bilinear products of duals and interdiction binaries are linearised exactly by McCormick, and the resulting bilevel problem is solved by the Bienstock-Özbay algorithm (p. 18; App. B, pp. 33-34). What did not change: the battery constraints and DC network model; the bilevel algorithm is used as is.
  - Transferable: if a binary only enforces complementarity of two non-negative quantities, try an ℓ1 penalty on both and look for a threshold on the penalty at which the LP relaxation has an optimal solution satisfying the complementarity (an exchange argument usually gives it) (pp. 3, 6).
- **D3 Assumptions and model**: DC OPF with batteries at a subset of buses, identical battery parameters constant over time (said to be unnecessary for the regularisation results, p. 4); ηc <= 1/ηd to rule out arbitrage (p. 4); slack load-shedding and excess-power variables with normalised cost 1 (p. 5). Theorem 1 needs E^min_c = E^min_d = 0, defended as "standard" (Pozo 2022, Kody et al. 2022; p. 9). In the trilevel problem Ohm's law is dropped following Johnson and Dey (2022) and generator cost is set to 0 because the focus is meeting demand (p. 17), so the third level is a network-flow problem (p. 33).
- **D4 Analysis and proof devices**: Theorem 1 proof by an exchange argument: from an LP optimum with both p^c and p^d positive, net them out (formulas (2a)-(2e)) and rebalance load shedding and excess power so power balance (3) still holds, then compare objectives in four cases (pp. 6-9; case details skimmed). Corollary 1: for lossless batteries the LP relaxation is exact even with λ = 0 (p. 9). Boundary: Examples 1 and 2 on a two-bus, two-period network show the equivalence fails if either assumption is dropped, and the authors call the two assumptions "the best that we may expect" (pp. 9-10). Baseline for λ: z^reg is concave and non-decreasing in λ (Remark 1) and for λ >= e the regularised problem equals the no-battery problem (Proposition 1, p. 11), with Example 3 showing batteries can always be used for λ in (0,1)^2 (p. 12). Structure: Theorem 2 (p. 13; App. A): optimal solutions never charge while shedding load, and under the strict inequality never discharge while there is excess power; Example 4 shows the unregularised problem can discharge during excess (p. 13). Quality: Proposition 2 gives an exactness condition in terms of the gap δ between the best and second-best objective values (p. 14), and Example 5 checks it; Theorem 3 bounds c(p_reg) - c(p*) <= T Nb max{E^max_c λc, E^max_d λd} by a two-line optimality argument (p. 15); Proposition 3 picks λ minimising this bound (p. 15). The authors explain why the bound is pessimistic (it assumes no charging at all and maximal rates, p. 16) and show worst-case vs empirical in Figure 2(d) (p. 17). Trilevel: sandwich z^LP <= z^OPT <= z^REG with a proof of the upper inequality through the attacker's best response to the regularised plan (pp. 18-19), giving Proposition 4: the regularised plan is a solution with optimality gap at most (z^REG - z^LP)/z^REG (p. 19). Proposition 5: all third-level duals bounded (β <= 2), so the McCormick reformulation is exact, "not a relaxation" (p. 34).
  - Transferable: to certify a heuristic plan for a min-max-min problem, solve the problem twice with the inner level replaced by a restriction (gives a feasible plan and an upper bound) and by a relaxation (gives a lower bound); the plan's gap is the ratio of the two (pp. 18-19).
  - Transferable: before linearising dual-times-binary products with big-M, prove explicit bounds on the duals from the dual constraints; then McCormick is an exact reformulation (p. 34).
  - Transferable: for a penalty parameter, prove where it degenerates (λ >= e removes the batteries) so a reader knows the meaningful range (p. 11).
- **D5 Numerical experiments**: MATPOWER networks IEEE 14, 73, 118, 162, 300, PEGASE 89, 1354, RTE 1888 read by PowerModels; Julia 1.7, Gurobi 10.0, a Linux machine with a 2.3 GHz processor and 64 GB RAM (p. 19). T = 24 hourly loads shaped on an EIA demand curve, nominal loads rescaled to about 0.8 G^max "In order to have the optimal solutions with nontrivial battery operations", Gaussian noise for scenarios; IEEE minimum generation set to 1/3 of maximum to match PEGASE/RTE (pp. 19-20); battery parameters from Kody et al. scaled by network size (Table 1, p. 20). Test 1 (ground truth available): solve the exact MIP and compare; average optimality gap of the regularised solution over 40 scenarios is at most 0.33% (IEEE 73, η = 0.85) and mostly 0.00% (Table 2, p. 21). Test 2 (trilevel, no ground truth): 10 simulations per network, budgets (b, k) in {(2,3), (2,5), (3,5), (5,10)}, 0.5% or 6-hour stopping rule; "solution-gap" = (upper bound of z^REG - max of lower bounds of z^LP and z^VCH)/upper bound, where VCH is Pozo's tightened convex-hull LP (pp. 19, 21). Solution-gaps are near 0 for small networks but reach 18.21% (PEGASE 1354) and 22.83% (RTE 1888) on average for b = 5, k = 10 (Table 3, p. 22), attributed to the lower-bound models not converging in 6 hours (p. 22). The regularised trilevel problem usually solves within the limit with small trilevel-gap, while the LP and VCH versions often hit 21,600 s with gaps up to 24.97% (Tables 4-7, p. 23). The Zeng-An baseline appears only in the one-sentence non-convergence claim, not in a table (p. 18).
  - Transferable: report two gaps separately: the algorithm's own convergence gap on each model ("trilevel-gap") and the certified gap of the plan against the best lower-bounding model ("solution-gap"); a large solution-gap with a small trilevel-gap points to the lower bound, not the plan (pp. 21-23).
- **D6 Positioning**: Battery-modelling literature is organised by modelling choice: simple lossless models (Chandy et al.), loss models without complementarity (Sioshansi et al.), MIP models, and LP relaxations surveyed by Pozo, with Arroyo et al.'s counterexamples as the criticism (p. 2). The perturbation idea is credited to Singh and Knueven for a single solar-battery system (p. 9). Complexity of the battery problem is placed between Bakhshi-Ostrowski (polynomial for lossless) and Bansal-Günlük (NP-hard with time-varying bounds), leaving fixed bounds with losses open (p. 24). The application claim is "the first time that the N - k contingency problem for battery operations has been studied" (p. 3).
- **D7 Writing and rhetoric**: Contributions as three bold-led bullets, each with its formal result and its practical consequence (pp. 2-3). Every theorem is followed by a toy two-bus example showing it is sharp or showing the phenomenon (Examples 1-6, pp. 9-16). Claims in the abstract and conclusion are stronger than the tables for large networks: "solves large-scale instances of these problems efficiently and yields near-optimal solutions in most cases" (p. 24), while the certified solution-gap on the two largest networks is 7-23% (p. 22); the text does say the large gaps are "most likely due to having a poor lower bound" (p. 22).
- **D8 Contribution and limits**: Contribution: modelling (a regularised MIP with zero integrality gap), theory (exactness threshold with sharpness examples, structural and worst-case bounds), and an application algorithm with certified gaps. Limits and future work stated: the properties depend on the objective and constraint structure, other objectives left open (p. 24); NP-hardness of the lossy battery problem with fixed bounds is open (p. 24). Unstated (my reading): Ohm's law is dropped in the trilevel model, so it is a transport model (p. 17); the regularised plan's optimality for large networks is not certified; the Zeng-An comparison rests on one instance and one sentence.

**Method links**:
- Method 5 ✅ evidence: the deliverable is a certified gap: LP relaxation and VCH give lower bounds, the regularised (restricted) model gives the plan and the upper bound, Proposition 4 turns them into a guarantee, and hardware and time limits are named (pp. 18-19, 21-22).
- Method 4 ✅ evidence: Theorem 1's two assumptions are each shown necessary by an example and called "the best that we may expect" (pp. 9-10); Proposition 1 marks where λ makes the model degenerate (p. 11); the worst-case bound is shown against the empirical gap (Fig. 2(d), p. 17).
- Method 2 ⚠ variant: ground truth by solving the exact MIP exists only for the single-level DCOPF test (Table 2, p. 21); for the trilevel problem the yardstick is a relaxation lower bound that does not converge on large networks (p. 22); no stripped instrument.
- Heuristic 9 (borrow one tool from a neighbouring field) evidence: ℓ1 regularisation for sparsity taken from the lasso and from his own sparse-regression work (p. 3). Heuristic 2 (give the strongest baseline its best shot) not followed: the Zeng-An baseline is one untabulated run (p. 18).
- New-pattern candidate: "regularise to make the relaxation exact" (an ℓ1 penalty with a threshold that gives zero integrality gap, traded against a bounded loss in the original objective) (pp. 3, 6, 15).
- New-pattern candidate: "restriction-relaxation sandwich to certify a hard multilevel solution" (pp. 18-19).

**Transferable techniques**:

- Sharpness examples on a two-bus, two-period network for each hypothesis (pp. 9-10).
- Worst-case quality bound for a penalised model plus the parameter that minimises it, then the empirical gap plotted against the bound (pp. 15-17).

### S081 · Non-monotonicity of branching rules with respect to linear relaxations (INFORMS Journal on Computing 2026, doi:10.1287/ijoc.2024.0709; read as arXiv:2402.05213v1)
**Read level**: full (pp. 1-17: main text, both proofs, experiments, conclusion, references; Appendix A, pp. 16-17, contains only figure captions in the extracted text, the plots themselves are not in the text). **Role**: core · **Coauthors**: Prachi Shah (Georgia Tech, student), Marco Molinaro (Microsoft Research and PUC-Rio) · **Place in trajectory**: follow-up to the full strong branching paper with the same group (ref [16], Math. Programming 2023) and to the random-IP branch-and-bound work [15]; part of the 2020-2026 branch-and-bound theory line; the SKILL's "Full strong branching and non-monotonicity" anatomy.

- **D1 Problem and entry point**: Entry is the founding assumption of branch-and-cut: a tighter LP relaxation should give smaller trees, because any tree for the weaker formulation is a certificate for the tighter one (pp. 1-2). But a branch-and-bound algorithm fixes a branching rule that uses local LP information, so the same tree need not be produced and a tighter formulation may give a larger tree (p. 2). The question is made precise by first removing every other source of tree-size variation: objectives with no dual degeneracy at any node (a set C(P, P') that discards only finitely many objectives) and best-bound node selection, justified because a best-bound subtree can be recovered from any tree (p. 2). Then Definition 1: a rule is monotonic if |T^r(P', c)| <= |T^r(P, c)| for every tighter P' and every c in C(P, P') (p. 2). Monotonicity would be "a theoretical justification of the branch-and-cut algorithm" (p. 2).
  - Transferable: before asking whether a solver component has a property, list the confounders that make the quantity ill-defined (here dual degeneracy and node selection), remove each by a restriction you can justify in one sentence, and only then write the definition (p. 2).
- **D2 Key idea and algorithm design**: Two constructions and two experiments. Theorem 1: any rule that branches only on fractional variables is non-monotonic; the counterexample is a 4-dimensional polytope Q, the convex hull of three vertex sets V1, V2, V3 "closely related to cross-polytope", and P = conv(Q ∪ {(1,1,1,1/2)}); Q is the lift-and-project closure of P in x4, yet the tree for P has 11 nodes and the tree for Q has 15 (pp. 3-5). Theorem 2: for full strong branching with product, linear or ratio scores, a single cut can increase the tree exponentially (pp. 4-8). Computationally, a controlled instrument (cover cuts on multi-dimensional knapsacks in a naive B&B) and a realistic one (SCIP's own root cuts on MIPLIB 2017, rounds 0-10) (pp. 8-12).
- **D3 Assumptions and model**: Pure binary/integer programs with LP relaxations P' ⊆ P having the same integer points (p. 2); best-bound node selection; non-degenerate objectives (p. 2). FSB scores: product with small ε, linear with µ = 1/6 following Achterberg et al., Le Bodic-Nemhauser ratio (p. 3); infinite gain for infeasible children with a stated tie rule (footnote, p. 3). Theorem 2 is proved for the product score, "identical" for the others (p. 4).
- **D4 Analysis and proof devices**: Theorem 1: an explicit small polytope where the tighter formulation makes x4 integral at every vertex, so a fractional-only rule cannot branch on it and must build the complete tree in x1, x2, x3 (15 nodes), while the weaker formulation's root vertex has only x4 fractional, which splits the problem into easier halves (11 nodes) (pp. 4-5, Fig. 1). Theorem 2: a two-dimensional gadget P = {(x,y) in [0,1]^2 : three inequalities} and P' = P plus 13x + 10y <= 14, with an explicit vertex table and objective values (Table 1, p. 6); FSB-P scores computed by hand (0.96 vs 4.37 for P; 1.3125 vs 0.8625 for P') so the rule branches on y first under P and on x first under P' (pp. 6-7). The n-fold instance Q_n couples n independent copies through one auxiliary continuous variable z with 13x_i + 10y_i <= z and z <= 16.7 (redundant), so the single valid cut z <= 14 adds the gadget cut to all n copies at once (pp. 6-7). Upper bound by recursion T(n) <= 4 + T(n-1), so |T(Q_n)| <= 4n + 1 (p. 7). Lower bound by counting complete "gadgets": no pruning by bound until the gap closed by branching (at most g = 6.75 per gadget) exceeds the integrality gap G = 0.75n, so |T(Q'_n)| >= 6(2^⌊0.75n/6.75⌋ - 1) (pp. 7-8). Remark 1: the upper bound does not use node selection (p. 8). The conclusion locates the result between two monotone extremes: a fixed a-priori branching order is monotone but may be large, and optimal branching is monotone but #P-hard (Gläser-Pfetsch), leaving open whether a good, efficient, monotone rule exists (p. 13).
  - Transferable: to turn a constant-size counterexample into an exponential one, take n independent copies and couple them through one auxiliary variable that appears only in a redundant constraint, so that one cut on that variable acts as n cuts; then bound the tree by a recursion on n for one formulation and by counting complete gadgets before pruning-by-bound becomes possible for the other (pp. 6-8).
  - Transferable: for a branching-rule counterexample, compute the strong-branching scores by hand from a vertex table of a 2-D polytope; a reader can check every step (pp. 6-7).
- **D5 Numerical experiments**: Instrument 1 (fully controlled): 100 random multi-dimensional knapsacks, n = 20, m = 50, weights zero with probability 0.25 else uniform in {1..1000}, capacity half the row sum, continuous random prices so instances are almost surely non-degenerate (p. 8). Cover cuts found by an exact separation IP per row (p. 8-9); each violated cover added alone, then all together (p. 9). Metrics: gap closed ΔG, relative tree-size change ΔT, depth of cut Δd (eq. (10), p. 9). Code: a Python 3.10 naive branch-and-bound with Gurobi 10.0.1 as LP solver, FSB-P "implemented purely as an oracle returning a branching variable, without influencing any other process within branch-and-bound, thus allowing fair node counting [18]", best-bound order, no presolve or other cuts (p. 9). Results: 19.8% of single cuts increased tree size, with weak correlation of ΔT with ΔG and with depth (p. 9); with all cuts, 8 of 100 instances grew, all with total gap closed at most 10% (p. 9). Instrument 2 (realistic, partly controlled): MIPLIB 2017 benchmark filtered to at most 10,000 variables and 500 integer variables, feasible, solved within 72 hours with one round of cuts, not solved at the root: 35 → 21 instances (p. 11). SCIP 8.0 via PySCIPOpt with presolve and propagation off, cuts only at the root, vanilla FSB without side effects, fixed variable order per seed, the optimal value supplied, 3 seeds, round limit 0 to 10 (p. 10). Results by gap-closed band: > 50% steady decrease (3 instances), 20-50% decreasing with rises (2), ≤ 20% no trend with spikes (supportcase26 grew more than 20-fold in one round for all seeds), and 0% gap with large changes attributed to dual degeneracy (pp. 11-12); no data point with tree growth beyond 20% gap closed (Fig. 6, p. 12). The authors state that dual degeneracy could not be controlled in MIPLIB (p. 10) and disclaim that this is "by no means an evaluation of SCIP" (p. 13).
  - Transferable: run the same question on two instruments: a synthetic one where every confounder is removed (so any effect is the phenomenon itself) and a benchmark one with the solver stripped and seeds varied (so the effect is shown to matter in practice), and say explicitly what the second cannot control (pp. 8-11).
  - Transferable: group benchmark instances by an outcome variable you can measure (total gap closed) rather than by instance family, and report the pattern per band (pp. 11-12).
- **D6 Positioning**: Opens with the history of branch-and-cut (Cook, Lodi; Crowder-Johnson-Padberg, Padberg-Rinaldi, Balas-Ceria-Cornuéjols) and recent trade-off studies of branching vs cutting (Basu et al. [7, 8], Kazachkov-Le Bodic-Sankaranarayanan [22]), and positions the paper as "another aspect of the interaction" (p. 1). Builds on own work: FSB analysis [16], random-IP B&B [15] (for the best-bound property), cut-selection review [17] (p. 13). Uses Gamrath-Schubert [18] for the fair node-counting protocol (p. 9). No author is criticised.
- **D7 Writing and rhetoric**: Contribution list of three numbered items, the third already stating the empirical "main insight" (p. 3); the same insight sentence appears in the abstract, contributions and §3 (pp. 1, 3, 12). Plain surprise markers tied to numbers: "Contrary to expectation" (p. 9), "surprisingly common in practice" (p. 11). The conclusion protects the main object from over-reading: "The objective of this paper is not to claim otherwise" (p. 12), and ends with the rule of thumb (20% gap closed) phrased as "could be a good rule of thumb" (p. 13). Hedging on the mechanism: increases are "possibly due to inherent non-monotonicity" (pp. 1, 3).
- **D8 Contribution and limits**: Contribution: theory (non-monotonicity of all fractional-only rules; exponential blow-up for FSB) plus an empirical prevalence study and a rule of thumb for cut selection. Limits stated: MIPLIB experiments cannot control dual degeneracy (p. 10); zero-gap instances are confounded by degeneracy (p. 12). Open question: does a good, efficient, monotone rule exist (p. 13). Unstated (my reading): only 20-variable knapsacks and 21 easy MIPLIB instances; only FSB-P tested empirically; the 20% threshold is read off two scatter plots without a statistical test; in the arXiv v1 text the MIPLIB per-instance plots are only captions (pp. 16-17).

**Method links**:
- Method 1 ✅ evidence: the object is an unexplained solver regularity (adding cuts sometimes increases node counts), stripped to a property with a measure well defined for every instance after removing degeneracy and node selection (p. 2), proved tightly, then returned to practice with a rule of thumb (p. 13). The conclusion makes the "engineering vs mathematical" explanation explicit (p. 12).
- Method 2 ✅ evidence: naive B&B with FSB as an oracle "thus allowing fair node counting" (p. 9) and SCIP with presolve and propagation off, the optimal value supplied, 3 seeds (p. 10); instance ladder from random controlled instances to a filtered benchmark with the exclusions stated (pp. 8, 11). This is the protocol the SKILL quotes from the released code; the v1 text already has it.
- Method 4 ✅ evidence: a general negative result (Theorem 1), a worst-case blow-up (Theorem 2), and the monotone extremes (a-priori rule, optimal branching) named to bound the open question (p. 13).
- Taste "a yardstick that does not track usefulness" evidence: depth of cut shows weak correlation with tree-size change (Fig. 4b, pp. 9, 13).

**Transferable techniques**:
- Control-then-define: remove confounders (dual degeneracy, node selection) before defining the property (p. 2).
- One auxiliary variable in a redundant constraint couples n copies so one cut acts as n cuts (pp. 6-7).
- Tree-size lower bound by counting complete gadgets until pruning by bound is possible (integrality gap / max gain per gadget) (p. 8).
- Two-instrument design (fully controlled synthetic, then stripped solver on a filtered benchmark with seeds) (pp. 8-11).
