# Paper cards · batch c07 (core)

Batch intent: See how Leyffer, between roughly 2003 and 2008, turned the "MPCCs can be solved as NLPs" result into a portable toolkit: first by widening the set of NLP reformulations of a complementarity constraint and proving SQP still converges fast (S022), then by carrying the same strong-stationarity machinery up one level to equilibrium problems with equilibrium constraints (S011), and, on the MINLP side, by building an LP/NLP-based branch-and-cut solver in which NLP linearizations are managed like MILP cuts (S015). ### S022 · Complementarity constraints as nonlinear equations: Theory and numerical experience (Optimization with Multivalued Mappings, Springer 2006, DOI 10.1007/0-387-34221-4_9)
**Read level**: full. Read version: Argonne preprint ANL/MCS-P1054-0603 (p. 1), all 39 file pages. Main text pp. 1–29 read closely. Appendix A (iteration counts, pp. 30–32) and Appendix B (problem characteristics, pp. 33–36) skimmed for the failure cases and the ξ column. Reference list (pp. 37–38) read.
**Role**: core · **Coauthors**: none (single author) · **Position in trajectory**: Argonne period, directly after the Fletcher–Leyffer MPEC-as-NLP numerical report [16] and the Fletcher–Leyffer–Ralph–Scholtes local SQP convergence paper [17] (p. 3, p. 38). It extends [17] from the bilinear form to a family of NCP functions (p. 3).

- **D1 Problem & entry**: The entry is a received verdict. Writing complementarity as x1, x2 ≥ 0, X1x2 ≤ 0 violates MFCQ at every feasible point, so the multiplier set is unbounded, the central path does not exist and linearizations can be inconsistent near a solution. Together with disappointing early numbers, this had made solving MPCCs as NLPs "commonly regarded as numerically unsafe" (p. 2). Recent SQP and IPM successes [16, 17, 1, 3, 28] reopened the question (p. 2). The paper's question is which other nonlinear (NCP-function) formulations of the complementarity constraint can be used in the same way, without the smoothing parameter that earlier NCP approaches [8, 10] had to drive to zero (p. 3).
  - Transferable technique: start from a "this is unsafe" verdict and list its causes (here, the MFCQ failure and early bad numbers, p. 2). Then ask whether each cause is in the mathematics or only in the formulation.
- **D2 Core idea & algorithm design**: Replace 0 ≤ x1 ⊥ x2 ≥ 0 by x1, x2 ≥ 0, Φ(x1, x2) ≤ 0, where Φ is an NCP function, and solve the result with the SQP filter solver, without smoothing (p. 3). Four design moves:
  - The candidate set is wide: bilinear, Fischer–Burmeister, min / natural residual and Chen–Chen–Kanzow (pp. 3–4). It adds three new functions. One is a smoothed natural residual that stays exact for any σ > 1/2 because it adds ab/σ rather than a constant (p. 4). The other two are a piecewise-linear and a piecewise-quadratic smoothing of the min-function that equal min near the axes and delay the decision in the middle sector (pp. 4–5, Fig. 1).
  - Subgradient convention: ∇φ(0,0) = 0 for every NCP function (Convention 3.4, p. 9). Other choices of v ∈ ∂φ(0,0) were seen to converge to M- or C-stationary points (p. 9).
  - The linearization is relaxed by δ(min(1, φ))^(1+κ) so the QP has a strict interior (3.3) (p. 9).
  - The QP Hessian deliberately leaves out ∇²Φ, which avoids the unbounded Fischer–Burmeister Hessian at the origin (p. 13).

  The method is a standard SQP plus filter and trust region. Only the constraint representation changes (p. 13).
  - Transferable technique: when several reformulations of one constraint exist, make one implementation detail (here, the subgradient picked at the kink) the thing that makes KKT points of the reformulation equal to the stationarity concept you want (p. 9, p. 12).
  - Transferable technique: smooth a nonsmooth function only in the region where nonsmoothness hurts, and keep it exact where exactness gives you a CQ-like property (min-function contours kept parallel to the axes, p. 5).
- **D3 Assumptions & model**: [A0]–[A5] on p. 14: the subgradient convention, twice Lipschitz-continuously differentiable f and c, MPCC-LICQ, MPCC-SOSC at a strongly stationary point, strict complementarity-type nonzero multipliers including both bound multipliers positive on biactive indices, and a QP solver that picks a linearly independent basis. [A6] (exact complementarity at iterate k) is on p. 15. [A7] (all QPs consistent near x*) is on p. 18.
  - The author ranks his assumptions: [A2] and [A3] are "the most restrictive" because they exclude B-stationary points that are not strongly stationary (p. 14). [A7] is "clearly an undesirable assumption" because it assumes progress of the method. It is then shown to hold for the min-type functions (Prop. 3.6) and for mixed-P vertical complementarity (p. 18).
  - Scope: the results hold for linear complementarity but not for general nonlinear complementarity, because SQP moves off nonlinear constraints. This is one reason given for slacks (p. 23).
  - Transferable technique: rank your own assumptions from mildest to most restrictive. For an assumption on the algorithm's progress, say which problem classes satisfy it (p. 14, p. 18).
- **D4 Analysis & proof techniques**: The skeleton runs as follows.
  - (i) Linearization consistency for each NCP function (Prop. 3.5, pp. 9–10). The min-type functions give consistent linearizations near a strongly stationary point under MPCC-MFCQ (Prop. 3.6, p. 11), which the author reads as a constraint qualification for (1.3) (p. 11, p. 23).
  - (ii) Unification: under the convention, every NCP gradient has the same structure (0, τa), (τb, 0), (τb, τa), (0, 0) (p. 11). One proof then gives KKT ⇔ strong stationarity for all eight functions, with explicit multiplier maps (3.5)–(3.7) (Thm. 3.7, p. 12). The multiplier ray has a minimum-norm "basic" multiplier (3.8) (p. 12).
  - (iii) Case split for local convergence. If complementarity holds at some iterate, the QPs of (1.3) and of the relaxed NLP have the same feasible sets, solutions and related multipliers (Lemmas 5.3–5.5, pp. 16–17), so quadratic convergence carries over (Thm. 5.6, p. 17). Otherwise every admissible QP basis corresponds to a "reduced NLP" with LICQ and SOSC (Lemmas 5.7–5.10, pp. 19–21). The δ-perturbation is o(‖d_N‖), so the Dennis–Moré characterization gives superlinear convergence (Prop. 5.11, p. 22). Since there are finitely many bases, the result holds whichever basis the QP solver picks (Thm. 5.12, p. 22).
  - (iv) The filter global-convergence outcomes (A)/(B)/(C) from [18] are used to predict what will happen. (B), convergence to a KKT point, cannot occur for (1.3), so outcome (C) is the one to analyse (p. 13).

  Proofs of Prop. 5.2 and Lemma 5.5 are cited from [17] (p. 15, p. 16), so proofs are transferred, not redone. The rate is honestly limited: with κ < 1 quadratic convergence cannot be obtained in general (p. 14).
  - Transferable technique: when the active normals are linearly dependent (CQ failure), prove convergence basis by basis. Show that each basis the QP solver can pick defines an equality-constrained "reduced NLP" with LICQ and SOSC, then use finiteness of the bases (pp. 19–22).
  - Transferable technique: introduce a common notation (τ1, τ2) that makes a whole family of functions look alike at the solution, so one proof covers the family (p. 12, p. 14).
- **D5 Numerical experiments**: The NCP formulations are built into his SQP-filter solver through an AMPL interface. The interface adds slacks, applies the reformulation and the relaxation (3.3), and lets the user pick formulation and parameters (p. 23).
  - Test set: MacMPEC, about 150 problems. Several similar 32×32 discretizations were left out for run time, with the stated bias that "the results would have been even better" for the scalar-product form (p. 23).
  - Parameters: defaults were chosen on a small representative subset; "No attempt was made to 'optimize' the parameter values" (p. 24, Table 1).
  - Numerics: a cancellation error in single precision would make φNRs declare an infeasible point complementary, and a stable rewrite is given (6.1) (p. 24).
  - Metrics: performance plots by iterations and by CPU time (Figs. 3–4). Failures are set to a large number so that robustness can be read from the right asymptote (p. 25).
  - Failure reporting: a per-formulation failure list with three named modes, "TR too small", "infeasible QP" and "iter. limit" (p. 26). Failures are linked to problems known to lack strongly stationary limits (ex9.2.2, ralph1, scholtes4), or to a model for which the MPCC formulation is inappropriate (gauvin) (p. 27). IEEE evaluation errors are excluded as model errors (p. 27).
  - Outcome: the lumped scalar product x1ᵀx2 ≤ 0 and the smoothed natural residual win. The min-functions, theoretically the most attractive, are "disappointing" (6/4/8 failures). Fischer–Burmeister and the quadratic min are worst (p. 27).
  - Diagnosis from the multiplier: a bounded ξ is used as a certificate of strong stationarity, and only four problems have large ξ (p. 27). Exact zero complementarity at most solutions is explained by three mechanisms, including the QP solver's degeneracy handling (p. 28).
  - Per-instance iteration counts and problem characteristics with degeneracy counts are given in the appendices (pp. 30–36).
  - Transferable technique: in the failure table, give each failure a mode and, where you can, a reason that ties it to the theory's hypotheses (the problem has no strongly stationary point) or to the model (an IEEE error). Then readers can tell method failures from instance pathologies (pp. 26–27).
  - Transferable technique: report a computed quantity that certifies the theory's conclusion on each instance (here the size of the complementarity multiplier ξ as a strong-stationarity indicator) next to the timing results (p. 27, Appendix B p. 33).
- **D6 Literature positioning**: The paper presents itself as extending his own [17] (p. 3). It sets itself against smoothing NCP approaches [8, 10], which must control a smoothing parameter: "Our contribution is to show that this smoothing is not required" (p. 3). It credits Anitescu's elastic-mode SQP and the IPM relaxations of Raghunathan–Biegler and Liu–Sun as parallel routes (p. 2). The pessimistic prior view ([5, 29] on MFCQ failure, [2] on early numbers) is restated and then called "premature" (p. 2). The earlier smoothing work is re-stated, not attacked.
  - Transferable technique: state the field's pessimistic verdict with its original citations before overturning it, and call it "premature" rather than wrong (p. 2).
- **D7 Writing & rhetoric**: The contribution is stated in one sentence in the introduction (p. 3) and repeated in the conclusions (p. 28). Hedging is low in the theory and appears where practice is involved: "Luckily, SQP methods converge for a simple choice of subgradient" (p. 8); "At present, we believe that current SQP methods cannot avoid convergence to C-stationary points" (p. 29). Negative results are stated plainly ("disappointing" twice, p. 27). There are few proofs relative to their length, and a Discussion of Proofs section (§5.3, pp. 22–23) explains the intuition, for example that the complementarity curvature can be ignored because it is zero away from the origin and the reduced Hessian vanishes at the origin.
  - Transferable technique: after a technical convergence section, add a short "discussion of proofs" that gives the geometric reason the result holds and the exact point where it would break (nonlinear complementarity, p. 23).
- **D8 Contribution & limitations**: Theory: equivalence of KKT points and strong stationarity for the whole NCP family, and superlinear local SQP convergence. Algorithmic: two new smoothed min-functions with a CQ-like property and an exact smoothed natural residual. Numerical: a robustness ranking on MacMPEC (pp. 28–29). The conclusions also propose a lumped NCP formulation eᵀΦ ≤ 0 (7.1) and argue that lumping allows nonmonotone componentwise complementarity (p. 29).
  - Limitations are specific: global convergence from arbitrary starts and avoidance of C-stationary points are open (p. 29); the results do not cover nonlinear complementarity (p. 23); quadratic convergence is lost when κ < 1 (p. 14); [A7] is needed for the non-min functions (p. 18).
  - Transferable technique: when your theory favours one variant and the numbers favour another, publish both and name the mismatch (min-function, p. 27). The mismatch is the next research question.

**Method links**:
- Method 2 ✅ evidence: the home toolkit (SQP with filter and trust region, and the strong-stationarity/KKT equivalence of [17]) is carried to a wider family of MPCC reformulations; the algorithm is unchanged and only the formulation varies (pp. 3, 13, 23).
- Method 6 ✅ evidence: the whole study compares formulations of one constraint, and the solver behaviour is traced to formulation properties. Lumping gives one constraint and nonmonotone componentwise residuals (p. 27). The linearized feasible region of Fischer–Burmeister is smaller, which shows up as many infeasible-QP failures (p. 27). Evaluation errors are attributed to the model (p. 27). Slacks are needed because SQP leaves nonlinear complementarity constraints (p. 23).
- Method 5 ✅ evidence: failures stay inside the performance plots (p. 25); there is a per-instance failure taxonomy (p. 26); the test-set filter and its direction of bias are stated (p. 23); there is no tuning of defaults (p. 24); the theoretically preferred variant is reported as losing (p. 27).
- Method 3 ⚠ variant: the hypothesis check is applied to failures rather than to counterexamples. Failing problems are matched to known violations of the strong-stationarity assumption before the method is blamed (p. 27).
- Method 4 ✅ evidence: MacMPEC is the test bed, and the paper adds a per-instance appendix with degeneracy classifications d1, d2, dm taken from [21] (pp. 30–36).
- New-pattern candidate: "exactness by convention". Choose the subgradient or implementation convention at a kink so that first-order points of the reformulation coincide with the target stationarity concept; the wrong choice yields spurious stationary points (p. 9, p. 12).
- New-pattern candidate: "basis-by-basis convergence under CQ failure". Prove fast convergence for each basis an active-set QP solver can choose, each defining a well-posed reduced problem, and use finiteness of the bases (pp. 18–22).

**Transferable techniques**:
- Fix ∇φ(0,0) = 0 (or the analogous convention) and check that KKT points of the reformulation coincide with the stationarity notion you need; test other subgradients numerically for spurious limits (p. 9).
- Relax a linearized complementarity constraint by δ·min(1, φ)^(1+κ) so the QP has an interior, and show the relaxation is o(‖d‖), which keeps superlinear convergence by Dennis–Moré (p. 9, p. 22).
- Check reformulas for cancellation in low precision and rewrite them in the stable "conjugate" form, as was done for Fischer–Burmeister (p. 24).
- In a robustness study, set failures to a large value inside the performance profile, and list failures by mode with instance names (pp. 25–26).

**Quotes**:
- "Our contribution is to show that this smoothing is not required." (p. 3)
- "The results for the min-function, on the other hand, are disappointing." (p. 27)

### S011 · Solving multi-leader–common-follower games (Optimisation Methods & Software 2010, DOI 10.1080/10556780903448052)
**Read level**: full. Read version: Argonne preprint ANL/MCS-P1243-0405, April 2005, revised March 2007 (file p. 1). All 33 file pages read, including the table of contents (p. 2) and the reference list (pp. 30–33). There is no appendix. Figures 1 and 2 are not in the text layer (only their captions, p. 7 and p. 25).
**Role**: core · **Coauthors**: Todd Munson · **Position in trajectory**: Argonne, the next step after the MPEC-as-NLP line ([10, 11, 16], p. 31): from one leader (MPEC) to several leaders (EPEC). The electricity application comes from his joint work with Chen, Hobbs and Munson [4] (p. 30).

- **D1 Problem & entry**: The entry is an application, deregulated electricity markets where large producers lead and small producers and the ISO follow (p. 4). EPECs, introduced by Pang–Fukushima [27], model these markets (p. 4). Algorithms at the time were diagonalization (Gauss–Jacobi/Seidel cycles of single-leader MPECs) and Su's sequential NCP with a relaxation parameter driven to zero (p. 4). The opening is the MPEC lesson: if MPECs can be solved reliably as NLPs, all leaders' problems can be solved simultaneously by writing each leader's strong-stationarity conditions (p. 4).
  - Transferable technique: when a new problem class is built out of copies of a class you already solve reliably, ask whether the reliable method can be applied to all copies at once instead of by cyclic decomposition (p. 4).
- **D2 Core idea & algorithm design**: Strong stationarity of an MPEC equals the KKT conditions of its NLP reformulation with Ys ≤ 0 (p. 8). So each leader's MPEC is replaced by those KKT conditions and they are concatenated, giving a nonsquare NCP (4.1) (p. 12). Leaders may hold different multipliers on the followers' constraints, which the authors read as cost differentiation (p. 12). Then come reformulations aimed at the solver:
  - Ys ≤ 0 is replaced by 0 ≤ y ⊥ s ≥ 0, which makes complementarity transparent to the solver (pp. 12–13).
  - Multiplier non-uniqueness (the ray) is removed by 0 ≤ ψi + σi ⊥ ξi ≥ 0, which forces basic multipliers (4.4)–(4.5) (p. 13).
  - An MPEC (4.6) minimizes the ℓ1-norm of ξ to select the minimum-norm multiplier (p. 15).
  - An NLP (4.7) penalizes all complementarities in the objective. A penalty parameter of one is always enough because the game has no objective of its own (pp. 15–16).
  - A restriction, "price consistency", makes the multipliers on common constraints identical across leaders. Under [A1] (separable plus common constraints) and [A2] (separable plus common objective) this yields square NCPs (5.6)/(5.7) that PATH can solve (pp. 16–20). Under complete separability it is equivalent to a single MPEC that minimizes the leaders' collective loss (Prop. 5.1, p. 21).
  - Transferable technique: when a multiplier set is a ray, add a complementarity condition (or an ℓ1 objective) that picks the basic or minimum-norm element, so the reformulated system is less degenerate (p. 13, p. 15).
  - Transferable technique: offer a restricted model (here price-consistent) that is easier to solve. Say explicitly that its solutions solve the general model but not conversely, and solve it first, falling back to the general model if it has no solution (p. 16, p. 21).
- **D3 Assumptions & model**:
  - Followers: replacing them by their KKT system needs convexity and a CQ for each follower. Otherwise the NCP admits saddle points or maxima, or may have no multipliers. The authors say "We accept these limitations" (p. 6).
  - Leaders: equilibrium points are strongly stationary only if every leader's MPEC satisfies MPEC-LICQ (Prop. 4.1, p. 14). The method computes strongly stationary points, not equilibria (p. 11).
  - Price consistency: [A1] is "not very restrictive" (p. 18). [A2] is called "a rather restrictive assumption" (p. 18). The electricity models violate [A2], so no price-consistent version exists for them (p. 25).
  - Transferable technique: for each simplifying assumption, test it against your own application set and report which instances violate it (p. 24, p. 25).
- **D4 Analysis & proof techniques**: The proofs are short, and the formulation work carries the paper.
  - Thm. 3.1: the Nash set of the multi-leader game equals the intersection of the Nash sets of k modified games, each attaching the common follower response to exactly one leader. The proof argues optimality both ways (p. 10).
  - Cor. 3.2: uniqueness or nonexistence for one subgame transfers to the whole game (p. 11). The authors note that the characterization is computationally intractable, because all solutions of each subgame would be needed (p. 11).
  - Prop. 4.1 follows from Scheel–Scholtes [29] (p. 14). Thm. 4.1 (local solutions of (4.6), and of (4.7) with zero penalty, are strongly stationary) "follows directly" (p. 16).
  - A two-player generalized Nash example with parameters a, b, c shows that the price-consistent game can have zero, one or infinitely many equilibria while every point (x1, c − x1) is an equilibrium of the unrestricted game (pp. 21–22).
  - Transferable technique: characterize the solution set of a coupled game as an intersection of simpler games, each with the nonconvexity in one player only. This splits existence into "each piece exists" and "the intersection is nonempty" (pp. 10–11).
  - Transferable technique: use a two-variable parametric example to map all regimes (unique, none, infinitely many) of a restricted model against the unrestricted one (pp. 21–22).
- **D5 Numerical experiments**: A new test set was built because "there are no established test problem libraries" (p. 22). It is published as MacEPEC, with each formulation as its own AMPL model file (*-NCP.mod, *-NCPa.mod, *-MPEC.mod, *-NLP.mod, *-PC.mod, *-PCa.mod, *-GJ.mod, *-GS.mod, *-NCPt.mod) (p. 22).
  - Random instances: 30 random QPEC-leader EPECs from a Matlab generator in three datasets (Table 1, p. 24). The authors admit that random problems are a poor substitute and justify them by the lack of realistic problems (p. 23). Data are written in single precision on purpose, because that "usually increases degeneracy" (p. 23).
  - Academic instances: ex-001; example-4, infeasible by design; outrata3/4, with outrata4 modified to satisfy [A2] (pp. 23–24).
  - Electricity instances: three models; electric-3 is a 14-node PJM case with about 150 constraints and 160 variables, "the largest EPEC solved to date" (p. 25).
  - Baselines: GJ, GS and Su's NCP(t) were reimplemented in AMPL (p. 22). Solvers are filterMPEC for the NCP/MPEC/NLP models and PATH for the square price-consistent NCPs; PATH on the nonsquare NCPs was "rather disappointing" (p. 26).
  - Metric: iteration counts, with major iterations summed or averaged as described. CPU time was avoided because AMPL-script methods run slower than Fortran or C (p. 27).
  - Outcome tags: [I] converges to an infeasible point, [S] reaches a spurious stationary point, CYCLE means the diagonalization cycles (p. 27, Table 4).
  - Solutions compared, not only speed: different solvers reach different stationary points. In 29 of 30 random instances GS, GJ, PC, PCa and NLP agree; NCP(t) finds a better point for electric-2 (pp. 28–29).
  - Transferable technique: when a method can return different stationary points, add a "compare the solutions" subsection beside the performance table, and tag each run as infeasible, spurious-stationary or cycling instead of just "failed" (pp. 27–29).
  - Transferable technique: generate random instances in reduced precision to make them more degenerate, and say so (p. 23).
- **D6 Literature positioning**: The paper builds on Pang–Fukushima [27] (EPEC paradigm) and on Su [32] (the definition of strong stationarity for EPECs, and the competing sequential NCP) (p. 4, p. 14). It contrasts itself with Su: "In contrast, we attack (4.1) directly" (p. 12). It also contrasts with diagonalization and with MPEC special-purpose methods (branch-and-bound, implicit nonsmooth, piecewise SQP), all of which "require significantly more work than a standard NLP approach" (p. 7). From numbers it concludes that relaxation methods are best used with inexact solves such as interior-point methods (p. 28). The positioning is by reformulation and comparison, not by criticism.
- **D7 Writing & rhetoric**: Claims are calibrated. The conclusion is "no clear overall winner, though the NLP approach is often the fastest" (p. 28), and "competitive", not "superior", in the conclusions (pp. 29–30). The authors are open about a case where only the baseline works: "Gauss-Seidel is the only solver that finds a feasible point for electric-1" (p. 28). There is a counter-intuitive finding about warm starts in NCP(t) (p. 28). Limitations they accept are stated in the first person ("We accept these limitations", p. 6). Theory and practice are kept apart: §3–5 are formulation and characterization, §6 is numbers.
- **D8 Contribution & limitations**: The contribution is mainly formulation and modelling, with an algorithmic consequence: a family of NCP/NLP/MPEC formulations and a price-consistent square NCP that let standard solvers treat the EPEC as one problem (p. 29). A public test library (MacEPEC) is a second contribution (p. 22). Open questions: no MPEC solver guarantees strongly stationary limits under reasonable conditions, and nobody knows how to formulate and presolve NCPs, MPECs and EPECs so that solvers can exploit structure such as skew symmetry (p. 28, p. 30). Hand-coding the strong-stationarity conditions in AMPL is "potentially error prone", which is a cost of the approach that the authors admit (p. 25).

**Method links**:
- Method 2 ✅ evidence: the MPEC-as-NLP toolkit (strong stationarity = KKT of the NLP, filterMPEC) is carried one level up to EPECs; the new class is recast into the home classes NCP, NLP and MPEC (pp. 4, 8, 12–16).
- Method 4 ✅ evidence: a new public library (MacEPEC) is started because none existed, with several formulations of each problem kept side by side as separate model files, plus an instance generator (pp. 22–24).
- Method 5 ✅ evidence: competitors are rebuilt in the same modelling environment (GJ, GS, NCP(t)) (p. 22); the choice of unit (iterations, not CPU) is justified (p. 27); failures are tagged by type (p. 27); there is a rule of thumb rather than a winner (p. 28); baseline wins are reported (p. 28).
- Method 6 ✅ evidence: reformulations (4.2)–(4.4) are aimed at the solver's degeneracy (p. 13); "A bad formulation can often hide structure such as skew-symmetry that PATH can exploit during the solution." (p. 28).
- Method 3 ⚠ variant: the small parametric example is used to show what a restriction loses (pp. 21–22), not to break a method.
- New-pattern candidate: "restricted model first, general model as fallback". Solve the easier restricted formulation (price-consistent) first and fall back to the general reformulation if it has no solution (p. 21).
- New-pattern candidate: "solution-set comparison as an evaluation axis". For nonconvex equilibrium problems, compare which stationary points each method reaches, not only how fast (pp. 28–29).

**Transferable techniques**:
- Turn "each player solves an MPEC" into one system by concatenating each player's strong-stationarity (= NLP-KKT) conditions, then pick among NCP, MPEC (minimum-norm multiplier) and NLP (penalized complementarity) versions for different solvers (pp. 12–16).
- In a penalized feasibility NLP for an equilibrium without an objective, a unit penalty suffices; use the zero optimal value as the certificate (pp. 15–16).
- Ship every formulation of every test problem as a separate model file with a consistent suffix scheme so that others can rerun the comparison (p. 22).

**Quotes**:
- "We accept these limitations because it is not clear at present how they can be avoided in practice." (p. 6)
- "Regarding the performance of the different solvers and formulations, there appears to be no clear overall winner, though the NLP approach is often the fastest." (p. 28)

### S015 · FilMINT: An outer approximation-based solver for convex mixed-integer nonlinear programs (INFORMS Journal on Computing 2010, DOI 10.1287/ijoc.1090.0373)
**Read level**: full for the text in the file. Read version: Argonne preprint ANL/MCS-P1374-0906, dated March 28, 2008 (file p. 1). All 32 file pages read, including the table of contents (p. 2) and the references (pp. 29–31). The appendix with instance names, characteristics and per-instance times, cited on p. 10 and p. 27, is **not in this file** (not read). The performance profiles survive only as axis ticks and legends in the text layer, so curve shapes were not read and the cards rely on the authors' prose about each figure.
**Role**: core · **Coauthors**: Kumar Abhishek, Jeffrey T. Linderoth (Lehigh) · **Position in trajectory**: the convex-MINLP line. It implements the LP/NLP-based branch and bound of Quesada–Grossmann. A "simplistic" version had been tried in Leyffer's 1993 PhD thesis (p. 4). It sits alongside MINLP-BB (Leyffer 1998) and in parallel with Bonmin (p. 5).

- **D1 Problem & entry**: The stated aim is a solver that solves MINLPs "at a cost that is a small multiple of the cost of a comparable mixed integer linear program" (p. 4). The entry is a gap between an old observation and practice. In the 1993 thesis, a simplistic LP/NLP-BB often beat nonlinear branch and bound and outer approximation by an order of magnitude, yet apart from the concurrent Bonmin no implementation existed (pp. 4–5). The motivating applications are listed (nuclear core reload, cyclic scheduling, trim loss, synthesis, layout) (p. 4).
  - Transferable technique: re-open an old observation from your own thesis that the field never turned into software, and build the software with current tools (pp. 4–5).
- **D2 Core idea & algorithm design**: Build LP/NLP-BB inside an existing MILP branch-and-cut framework (MINTO) entirely through its user application functions: appl_mps, appl_feasible, appl_constraints and appl_primal, with "No changes are necessary to the core MINTO library" (p. 9). filterSQP solves the NLP subproblems. As an active-set SQP it warm-starts from the LP node solution, and its restoration phase returns the feasibility problem NLPF(y^k) automatically when NLP(y^k) is infeasible (p. 9). After an integer point, the node is re-solved because the new linearizations cut that point off (p. 7, Algorithm 1.1 p. 8). The main design principle is to treat nonlinear linearizations like MILP cutting planes (p. 18):
  - add only violated linearizations;
  - drop rows inactive for 15 consecutive LPs into a cut pool (MIOCUTDELBND = 15) (p. 20);
  - generate linearizations at a node with probability min{β2^(−d), 1}, which biases them to the top of the tree where branching decisions matter most (p. 22);
  - stop on tailing-off (K) and cap the number of points per node (M) (p. 22).

  A hierarchy of linearization points (p. 23):
  - ECP: linearize at the fractional LP point, cheapest and weakest;
  - fixfrac: solve NLP(y^k) with y fixed at fractional values;
  - NLPR: solve the node NLP relaxation, strongest and costliest.

  They are tried in that order (Algorithm 3.1, p. 24). The defaults in Table 1 set β_nlpr = 0 (p. 25). Dual preprocessing is switched off, because it is invalid for the OA master unless all integer points are in K (p. 13). Benders aggregation of cuts was considered and deferred (pp. 20–21).
  - Transferable technique: implement a new algorithm as user callbacks of a mature framework without touching its core, so all the framework's features (cuts, heuristics, branching, node selection) can be switched on one by one (p. 9, p. 12).
  - Transferable technique: when valid inequalities can be generated at any point (convexity), order the point-selection rules from cheap and weak to expensive and strong, and give each its own budget (β, K, M) (pp. 22–24).
- **D3 Assumptions & model**: f and g are convex and twice continuously differentiable, and X and Y are compact polyhedral sets (p. 4). On nonconvex problems the techniques "may be applied as a heuristic" (p. 4). Finite convergence of the OA master is cited "under mild conditions" from Fletcher–Leyffer 1994 and Bonami et al. 2008 (p. 7). Validity of every linearization depends on convexity (p. 6, p. 20). The authors flag one MILP feature as invalid in this setting: dual preprocessing (p. 13).
- **D4 Analysis & proof techniques**: n/a. No new theorems. The only arguments are validity by convexity (p. 6, p. 20), the necessity of re-solving a node after its integer point is cut off (p. 7), and the Forrest–Hirst–Tomlin argument that branching decisions near the root matter most, which motivates linearizing early (p. 22).
- **D5 Numerical experiments**: The design is an ablation ladder.
  - Test set: 222 convex instances from MINLPLib, MacMINLP and the CMU–IBM library, all converted to AMPL (p. 10).
  - Hardware: a Lehigh cluster of identical 1.8 GHz Opterons; 4-hour time limit (p. 10).
  - Difficulty tiers by a reference solver (MINLP-BB): easy < 1 min (100 instances), moderate 1 min–1 h (37), hard > 1 h (85) (p. 10).
  - Metric per tier: time profiles for moderate instances and a scaled solution value ρ = 1 + (z_s − z*)/z* for hard instances, so the hard-tier profile measures solution quality after 4 hours (pp. 10–11). Easy instances are dropped from the analysis because the solvers perform about the same, and details are available on request (p. 11).
  - Ladder steps:
    1. Vanilla LP/NLP-BB (most-fractional branching, best bound, no MILP features), close to the thesis version, against MINLP-BB. It wins on moderate instances and is "not competitive" on hard ones, especially for finding good feasible solutions (p. 11).
    2. Each MILP feature switched on individually: cuts, preprocessing, primal heuristics (pp. 13–15), branching rules (pseudocost best; strong branching surprisingly poor, pp. 15–16), node selection (adaptive best, p. 16).
    3. Winners combined into vanIP (p. 18).
    4. Row management (p. 20).
    5. Each linearization scheme individually, then the combined default (p. 25).
    6. Final comparison with MINLP-BB (same filterSQP NLP solver), Bonmin I-Hyb in two dated versions (a summer-2006 repository build and release 0.1.4) and vanilla (p. 25, p. 27).
  - Final comparison results: FilMINT and Bonmin-v2 lead on moderate instances; FilMINT and both Bonmin versions lead on hard instances; 88 of 122 moderate+hard instances are solved by some solver (p. 27).
  - Tuning: the FilMINT defaults "were optimized based on all previous experiments" on the same suite (p. 27).
  - Transferable technique: split the test set into difficulty tiers using a fixed reference solver, and use a different metric per tier (time where solves finish, scaled best objective where they do not) (pp. 10–11).
  - Transferable technique: name each intermediate build (vanilla → vanIP → row-mgmt → filmint) and show a profile for each step, so readers can see which change paid off (pp. 12–25).
- **D6 Literature positioning**: The algorithm is credited to Quesada–Grossmann ("a clever extension of outer approximation", p. 5), with Leyffer's 1993 thesis as the motivating evidence (p. 4). Differences from the concurrent Bonmin are spelled out in four points (p. 5): how linearizations are added and managed (extra linearizations at fractional points, smaller cut sets); an active-set NLP solver with warm starts versus IPOPT; MINTO's MILP features versus CBC's; and a pure outer-approximation method versus Bonmin's hybrid. The MILP-side comparisons cite Linderoth–Savelsbergh 1999 for the expectation that pseudocost branching would win (p. 16).
- **D7 Writing & rhetoric**: Claims are mostly calibrated, with one strong phrase. Calibrated: "not competitive with MINLP-BB for difficult instances" (p. 11); "The poor performance of strong branching was surprising" (p. 16); "Further research and empirical experiments will be required" (p. 23). Strong: "The experiment conclusively demonstrates that linearizing about additional points is quite advantageous" (p. 25). The abstract claims Bonmin comparisons "highlight the effectiveness of FilMINT" (p. 3), while §4 reports a tie with Bonmin-v2 on moderate instances (p. 27). There is a section-reference slip: the comparison with Bonmin is announced for "Section 5" (p. 5) but appears in Section 4 (p. 25).
- **D8 Contribution & limitations**: The contribution is software and an empirical study: a solver on NEOS (p. 27) and evidence on which MILP techniques carry over to MINLP, which the authors say may matter beyond LP/NLP-BB (p. 10). Future work: new heuristics and cutting planes (p. 27), better point-selection methods (p. 23), Benders-style aggregation (p. 21). Limitations are partly left implicit. The method is for convex problems only (p. 4). The defaults were tuned on the comparison suite itself (p. 27), and the paper does not discuss this. Easy instances are left out of the reported results (p. 11). The per-instance appendix is missing from this preprint (p. 10, p. 27).

**Method links**:
- Method 1 ✅ evidence: the algorithm is built in a framework the authors control through callbacks, with no core changes (p. 9). The inner NLP solver's own outputs are reused: warm starts from the LP node and the restoration phase as the feasibility problem (p. 9). Linearizations are reinterpreted as cuts and managed with MILP cut machinery (p. 18).
- Method 5 ⚠ variant: the self-built vanilla baseline, the same NLP solver in MINLP-BB, dated competitor versions and a reported loss (p. 11) all fit. Against the method, the defaults were tuned on the comparison suite (p. 27), the easy tier was dropped (p. 11), and the abstract claim is stronger than the §4 result (p. 3 vs p. 27). This is consistent with the documented gap noted under Method 5 [03 E22]. The "biased subset ... 88 problems" sentence cited in SKILL.md [03 E20] does not appear in this preprint. Here p. 27 says only that 88 of 122 instances were solved by one of the five solvers and that Fig. 16 profiles that subset.
- Method 2 ⚠ variant: here the toolkit carried into the new class is the MILP one (MINTO's cuts, heuristics, branching, node selection; coauthor Linderoth's base) brought into MINLP, rather than Leyffer's NLP base (pp. 10–18). His NLP base (filterSQP) supplies the subproblem solver (p. 9).
- Method 4 ✅ evidence (weak): uses MacMINLP together with converted MINLPLib and CMU–IBM models (p. 10).
- Heuristic 1 (ablate from a plain baseline, one feature at a time) is directly evidenced: "By turning on each feature individually, we obtain an indication of which MILP techniques have the biggest impact." (p. 12).
- New-pattern candidate: "cut-management analogy". Treat a new family of valid inequalities exactly like MILP cuts (violated-only, a cut pool with an inactivity counter, depth-biased generation probability, tailing-off test, per-node cap) (pp. 18–22).
- New-pattern candidate: "difficulty tiers set by a reference solver, with a metric per tier" (pp. 10–11).

**Transferable techniques**:
- Generate outer-approximation cuts at a node with probability min{β2^(−d), 1}, so β is the expected number of nodes per level that get cuts in a complete tree (p. 22).
- Use an active-set NLP solver with a restoration phase so that infeasible NLP(y) subproblems return the ℓ1 feasibility solution automatically, which gives a valid linearization point either way (p. 6, p. 9).
- Deactivate any MILP preprocessing that infers properties of optimal solutions ("dual" reductions) when the LP is only an outer approximation (p. 13).
- When a competitor is evolving, benchmark two dated versions of it and state where each came from (p. 27).
