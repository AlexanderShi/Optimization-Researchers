### S058 · On the semidefinite representability of continuous quadratic submodular minimization with applications to moment problems (arXiv preprint 2025, arXiv:2504.03996; read as v3, 2026)
**Read level**: full (pp. 1-46; references pp. 46-49 skimmed). Read version: arXiv v3 (p. 1). Earlier versions (v1 with the "polynomial time" claim, v2) were not in the file and were not read.
**Role**: core · **Coauthors**: Karthik Natarajan, Rick Willemsen (both SUTD, p. 1) · **Place in trajectory**: a late instance of the 2009-2013 programme (completely positive representation [Burer 2009, 2012] and the n = 2 SDP-RLT hull result of Anstreicher & Burer 2010, cited pp. 8, 10) carried into continuous submodular minimization and moment/DRO problems.

- **D1 Problem and entry point**: The entry is a gap in a complexity table: quadratic minimization over {0,1}ⁿ vs [0,1]ⁿ, convex vs submodular (Table 1, p. 3). Over the box, submodular QP is known polynomial only when DR-submodular (Padberg LP) or when c ≤ 0 (Kim & Kojima SDP), pp. 2-3; the general submodular case is open. Three applications force the problem: multi-product pricing with substitutes without assuming PSD (B+Bᵀ)/2 or discretizing (Example 1, p. 4), a relaxed Chebyshev ambiguity set whose nonemptiness check is NP-hard in the exact form (Example 2, pp. 4-5), and covariance bounds for bounded random variables (Example 3, p. 5). Problem statement: QSMB, min{xᵀQx + cᵀx : x ∈ [0,1]ⁿ} with off-diagonal Q ≤ 0 (eq. (1), p. 2).
  - Transferable: open the paper with a 2×2 complexity table (domain × function class) and put your result in the one empty cell, with a footnote stating exactly how far it goes (Table 1 and fn. 2, p. 3).
- **D2 Core idea**: Keep the Shor SDP plus only the RLT *upper* bounds X ≤ xeᵀ (relaxation (2), p. 9), because submodularity makes the objective nonincreasing in the off-diagonals of X, so the RLT lower bounds are "less likely to be active" (p. 9). Prove this smaller relaxation tight for all submodular (Q, c) when n ≤ 3, irrespective of the sign of c (Theorem 1, p. 12), which also implies tightness of the full SDP-RLT relaxation (p. 9). Then show it fails at n = 4 by an explicit instance (Example 4, p. 14) and use the n ≤ 3 result through conic duality to get SDP-representable inner/outer approximations of a new moment cone (Proposition 7, p. 17), a DRO upper bound exact for n ≤ 3 (Proposition 8, p. 18) and a covariance bound exact for n ≤ 3 (Proposition 9, pp. 21-22). Changed vs Kim & Kojima: c arbitrary in sign and the RLT upper bounds added; unchanged: the basic Shor matrix Y(x, X) ⪰ 0 (pp. 7-9).
  - Transferable: use the sign structure of the objective to discard the constraint families that cannot bind, then prove tightness for the *smaller* relaxation, which is the stronger statement (p. 9).
- **D3 Assumptions and model**: Box [0,1]ⁿ (general [l,u] by affine map; the flip x ↦ −x also preserves submodularity, p. 2); Q symmetric with nonpositive off-diagonals, diagonal and c unrestricted (p. 2). DRO model: cost piecewise quadratic in ξ with −A_k(x) submodular and X SDP-representable (Proposition 8 (a)-(b), p. 18). Moment model: support in [0,1]ⁿ, means and diagonal second moments fixed, off-diagonals bounded below (eq. (5), p. 15); Σ need not be PSD, presented as a modelling advantage for pairwise-estimated moments (p. 15). Covariance model: −A submodular, 0 ≤ σᵢ ≤ √(μᵢ(1−μᵢ)) (Lemma 3, Proposition 9, p. 21).
- **D4 Proof devices**: (i) Pataki's rank bound turned into a counting lemma on extreme points, r(r+1) ≤ 2(a+1) with a the number of active RLT upper bounds (Lemma 1, pp. 9-10), which bounds the possible ranks by dimension. (ii) A completely-positive tightness certificate: if an optimal Y lies in CP(J) for the homogenized box cone J, the SDP is tight (Lemma 2, p. 11; CP representation from Burer 2009/2012, p. 10). (iii) Case analysis on rank r and on the counts (l, d, u) of active s-lower, diagonal and s-upper inequalities after "sorting by x" (pp. 11-12). (iv) For rank 2: an explicit rotation of a 2-column factor into J (Lemma 4, pp. 36-37), and a line segment Y(λ) = (1−λ)Y + λY(1) along which the objective does not increase by submodularity, ending in a rank-3 point with more active inequalities or a rank-2 point with X ≥ xxᵀ (Lemma 5, pp. 37-39). (v) Inductive peeling: when all s-upper inequalities are active, Y = x₁eeᵀ + (1−x₁)Ỹ and recurse; ε-subtraction of a rank-one term to reduce rank (Lemma 6, pp. 40-41). (vi) Index merging: an active s-lower inequality forces two identical columns of Y (Lemma 7, pp. 41-42), so the instance reduces to n−1 variables with submodularity preserved, giving ρₙ ≤ vₙ ≤ vₙ₋₁ = ρₙ₋₁ ≤ ρₙ (Proposition 5, p. 42). (vii) Conic duality of moment cones: M₀ = M₁ + M₂, M₀* = K₁ ∩ K₂, with closedness from Dickinson (pp. 16-17). (viii) Counterexample certification in exact rational arithmetic: enumerate all 3⁴ = 81 KKT active-set patterns over the rationals to prove the QP optimum is 0, and exhibit a rational feasible point of value −109/1024 with Y ≻ 0 by Sylvester's criterion (Proposition 12, p. 43); a rational point rounded to denominator 10⁸ certifies that the gap survives full RLT plus triangle inequalities (p. 44). (ix) Remark 1 locates the exact configuration where the proof fails for n = 4 (rank 3, l = 0, partial d and u), and the counterexample sits in exactly that configuration (pp. 13-14, 43).
  - Transferable: before searching for a counterexample, write down which (rank, active-set) configuration the proof cannot handle at n+1 and search there; then certify the counterexample with a rational feasible point plus a KKT enumeration, not a solver gap (pp. 13-14, 43).
  - Transferable: prove SDP tightness by showing that some optimal solution can be moved, without loss in objective, to one with a completely positive factorization (Lemma 2 + Lemmas 4-6, pp. 11, 36-41).
- **D5 Experiments**: (a) 1,000 random submodular instances, n uniform in {4,…,20}, Gaussian Q with off-diagonals set to −|Qᵢⱼ| and Gaussian c, deliberately outside the known polynomial cases (pp. 26-27); global QP by Gurobi (tolerance 10⁻⁸), SDP by Mosek (10⁻¹⁰); the gap uses the SDP *dual* objective "because it provides a rigorous lower bound via weak duality", relative gap with denominator max{1, |p*+d*|/2} (p. 27). All gaps 10⁻¹⁴ to 10⁻⁹, against a conservative 10⁻⁴ threshold (p. 27; Figure 2, p. 28). (b) A further 34,000 instances at n ∈ {4,5,6,7}: no gap above 10⁻⁴, and all but one optimal SDP solution had rank 1 with no active s-lower inequality (p. 27). (c) Applications at n = 3: a three-bundle pricing instance with indefinite (B+Bᵀ)/2 solved exactly (profit +30.07% over baseline, pp. 29); DRO stratified sampling solved by enumerating the 406 integer allocations with an exact inner SDP (pp. 30-31), compared with the Delage-Ye set (Table 4, p. 32); Laplacian-energy bounds on a 50-vertex grounded path, where the new set is stronger for α ≤ 0.2 and weaker beyond (Figure 3, pp. 34-35), and SDP vs summed bivariate bounds on path/star/complete graphs, 1,000 instances per cell (Table 5, p. 36). (d) Gap-closing test on the counterexample: (2), full RLT, full RLT + triangle inequalities (Table 6, p. 44).
  - Transferable: to judge "tight", compare the global QP value with the SDP *dual* objective (a valid bound), and read a gap-free random panel as evidence that gap instances are rare, not as evidence of a theorem (p. 27).
  - Transferable: when an application has a numerical coincidence (two ambiguity sets agree at one allocation), explain it analytically in the text (the 1/(4mᵢ) argument, p. 32).
- **D6 Positioning**: Builds explicitly on Kim & Kojima 2003 ("inspired by", p. 5; Proposition 1, p. 7) and on Anstreicher & Burer 2010 for n = 2 (Proposition 2, p. 8); positions the moment set as an alternative to Delage & Ye (pp. 4-5, 19-20) and compares, rather than claims dominance: "neither subsumes the other" (p. 34). Credits Hössjer & Sjölander for the n = 2 covariance bound with a different proof (p. 25). Cites the submodular-maximization literature only to set it aside (p. 2). Self-citation is limited to the CP machinery (Burer 2009, 2012; Burer & Letchford 2009 for triangle inequalities, p. 44).
- **D7 Writing**: Claims are written at their proved level: "provably tight for dimension n ≤ 3" and "not tight in general, although it remains empirically tight" (abstract, p. 1). The theorem is assembled from three propositions proved later (§2.3 vs §6). Geometry is given its own figures: a projection of the three nested bodies showing that submodular objectives point to the "northeast" boundary where they coincide (Figure 1, pp. 12-13), and a projection on (objective, triangle slack) showing the residual gap (Figure 4, pp. 44-45). The error that led to v2/v3 is acknowledged by name: "We thank Shaoning Han for pointing out an error in an earlier version of this paper." (p. 46).
- **D8 Contribution and limits**: Theory (n ≤ 3 tightness; n = 4 counterexample) plus modelling (new ambiguity set, covariance bounds). Limits stated precisely: complexity for n ≥ 4 open, needing "either a different certificate or a hardness reduction" (p. 46); triangle inequalities remove >99.9% of the counterexample gap but not all (Table 6, p. 44). Future work: combine the two ambiguity sets by infimal convolution (p. 34); characterize when RLT bounds for zero entries of Q are redundant, supported only by an unreported experiment ("our experiments indicate…", p. 46).

**Method links**: Method 2 evidence ✅: a small substructure (n ≤ 3), a proof in the smallest dimension where it holds, and the boundary published at the first certified counterexample (n = 4), with the kitchen-sink test (full RLT + triangle inequalities) shown not to close the gap (pp. 12-14, 44). Method 3 evidence ✅: dual-bound gap with a 10⁻⁴ threshold over 35,000 random instances, exact rational certificates for the counterexample, genericity read into the verdict, and the earlier error credited by name (pp. 27, 43-44, 46). Method 3 variant ⚠: in v3 the dual-objective bound is used alone (no eigenvalue-ratio second signal) because the global QP optimum is known from Gurobi (p. 27). Method 1 evidence ✅: tightness is proved through the completely positive representation of the box QP (pp. 10-11). Method 4 variant ⚠: the random panel is deliberately placed outside the known polynomial cases (p. 27), but it is not filtered to instances the baseline fails, and the paper says this panel cannot find the non-generic gap configuration (p. 27). New-pattern candidate: "prove tightness of the leanest relaxation that the objective's sign structure allows" (p. 9). New-pattern candidate: "proof-failure map guides the counterexample" (Remark 1 → Example 4, pp. 13-14).
**Transferable techniques**:
- Pataki-style counting r(r+1) ≤ 2(a+1) to bound the rank of extreme optimal solutions, then handle each rank separately (pp. 9-12).
- Index merging under an active coupling constraint to set up induction on n while preserving the problem class (pp. 41-42).
- Exact verification of a nonconvex QP optimum in tiny dimension by enumerating all 3ⁿ KKT active-set patterns over the rationals (p. 43).
- A 2-D linear projection onto (objective, slack of a violated cut) so the relaxation gap and the effect of a cut are both visible in one figure (pp. 44-45).
**Quotes**:
- "The experiment is therefore best understood as evidence that violations of tightness are rare." (p. 27)
- "What fails at n ≥ 4 is therefore this particular semidefinite certificate, not necessarily tractability itself." (p. 46)

### S056 · Optimization over trained neural networks: Going large with gradient-based algorithms (CPAIOR 2026, doi:10.1007/978-3-032-27242-3_35; arXiv:2512.24295)
**Read level**: full (pp. 1-16; references pp. 16-19 skimmed). Read version: arXiv v2 (p. 1); the LNCS typesetting was not read. Figures 1-8 are images whose content is known only from captions and text.
**Role**: core · **Coauthors**: Jiatai Tong (Northwestern), Yilin Zhu, Thiago Serra (Iowa), p. 1; Burer is last author · **Place in trajectory**: a follow-up to Tong, Cai & Serra's LP Walk (CPAIOR 2024, ref. [55]) and a companion of S057 (cited as ref. [64], p. 6); part of the constraint-learning line Burer entered with student Zhu.

- **D1 Problem and entry point**: Exact MILP formulations of ReLU networks are either weak (big-M) or huge (disjunctive), pp. 1-2, so local search over linear regions is used for large models (p. 2). Two prior methods are renamed to expose a cost ladder: MILP Walk (Perakis & Tsiourvas) and LP Walk (Tong et al.), pp. 3-4. Empirically LP Walk wins on larger networks because it can do more iterations per unit time (p. 4). The entry is to push the same trend one step further: an even cheaper iteration (p. 4). Problem: maximize f(x) over a polytope X, f a ReLU network (eqs. (1)-(2), p. 5).
  - Transferable: name the existing methods so that they line up on one axis (per-iteration cost vs per-iteration progress) and place the new method at the empty end of that axis (pp. 3-4).
- **D2 Core idea**: Gradient Walk: projected gradient ascent on the piecewise-affine network, using the closed-form gradient wᴸ⁺¹∏(zˡI)Wˡ, constant inside a linear region (eqs. (13)-(15), pp. 6-7). PPGA adds restarts from Gaussian perturbations of the best point when k consecutive small improvements accumulate, because in a piecewise-affine landscape the gradient norm says nothing about local optimality (pp. 7-8; Algorithm 1, p. 7). PPGALR adds a "linear region valve": a ratio test over neurons estimates the step u to the next region boundary (eq. (17), p. 8), and if the learning rate would cross fewer than V regions the step is rescaled (eq. (20), p. 9; Algorithm 2). V and c are set adaptively (V = 1/‖∇f‖, c = u) to avoid extra hyperparameters, explicitly for fairness to methods with fewer hyperparameters (p. 9).
  - Transferable: when a landscape is piecewise linear, replace the gradient-norm stopping test by a progress-window test on objective improvement (pp. 7-8).
- **D3 Assumptions and model**: X a polytope (a box in experiments), with boundedness defended by the validity-domain literature and by the need to benchmark against MILP-based methods (p. 6). Feed-forward ReLU network with all weights and biases in [−1, 1] (p. 5); the expectation of vanishing gradients in deep networks follows from that assumption (p. 8). Networks are taken at random initialization, untrained, "in line with prior work" (p. 10).
- **D4 Proof devices**: n/a for theorems: there is no convergence or optimality result. The only analysis is a per-step cost count: O(dm² + n₀m) for a gradient step, about twice that for PPGALR, versus one LP per SimplexWalk step, exponential in n₀ in the worst case (§4.3, p. 11).
- **D5 Experiments**: 36 network configurations (n₀ ∈ {10, 100, 1000}, depth ∈ {2,4,6,8}, width ∈ {100, 1000, 10000}), p. 10. Hyperparameters of the three gradient methods chosen per configuration by grid search (45 points, 5 min each) on 5 separate seeds and a vote over the top-5 sets; evaluation on 20 fresh seeds (10-29), 7,200 s per run, best value logged every second (pp. 10-11). Baselines: plain PGA and SimplexWalk (LP Walk), the latter chosen because it already beat Gurobi and MILP Walk (p. 10). Dolan-Moré performance profiles at 30/60/120 min and split by input size, depth and width (pp. 11-13). Losses reported: PPGALR is worse at depth 2; SimplexWalk improves with longer runs and dominates the three smallest depth/width cases (pp. 13-14); both gradient methods do badly at γ = 50000 (p. 15). A single-instance case study of step-size distributions explains why the valve helps in deep networks (pp. 14-15). Single Xeon core, Python 3.10.8, Gurobi 11.0, code public (pp. 9-10).
  - Transferable: tune hyperparameters on seeds disjoint from the evaluation seeds, choose by vote across tuning instances, and report the protocol (pp. 10-11).
  - Transferable: when profiles show an aggregate win, split them by each size parameter to find which one drives the win, and say where the baseline still wins (pp. 12-14).
- **D6 Positioning**: Continues the "specialized local search with lower per-iteration cost" trend (p. 15) begun by MILP Walk and LP Walk (pp. 2-4). Reviews the MILP-strengthening literature (big-M tightening, valid inequalities, hybrid formulations) as context, not as competitor (pp. 1-2). Perturbation-to-escape-saddles work for smooth problems is cited and set apart because here saddles sit on nondifferentiable boundaries (pp. 7-8).
- **D7 Writing**: Short conference style built around figures of a 2-input toy network (Figures 1-3, pp. 2-4) that show each walk's trajectory. Contributions stated as "two-fold" (abstract, p. 1). Explanations of results are hedged ("it is possible that", "likely", "seem to be", pp. 12-14). Typo in the keywords ("Constraining learning", p. 1).
- **D8 Contribution and limits**: Algorithmic and empirical; no theory. Limits: no safeguard against too-large steps (p. 15); the dependence on weights in [−1,1] (p. 8); evaluation only on untrained random networks (p. 10). Future work: a variant robust to large learning rates, other landscape features, other constraint-learning models, specific function families (p. 16).

**Method links**: Method 5 evidence ✅: algorithm first, no convergence theory, value shown by benchmarking against the strongest prior local method (pp. 9-15). Method 5 variant ⚠: competitors and the new methods are not run "at their defaults"; the gradient methods are grid-search tuned, and the valve parameters are made adaptive for fairness (pp. 9-11). H8 evidence ✅: losses printed with hypotheses (SimplexWalk at small sizes, PPGALR at depth 2, large γ), pp. 13-15. H10 evidence ✅: seeds, hardware, versions and public code (pp. 9-11). Methods 1-4 not engaged (no relaxation, no hull, no certificate). Burer's individual contribution cannot be separated from his coauthors' in this text.
**Transferable techniques**:
- A ratio test along the gradient over all neuron pre-activations to estimate the distance to the next linear region, used to rescale the step (eqs. (17)-(20), pp. 8-9).
- Restart from a perturbation of the incumbent, with noise scaled as Ξ/√n₀, triggered by a count of sub-threshold improvements rather than by gradient size (Algorithm 1, p. 7).
- Performance profiles at several time budgets (30/60/120 min) to show how a slower-per-step baseline catches up over time (pp. 11-14).
**Quotes**:
- "Hence, the size of ∇f(x) is not a reliable measure of local optimality in our case." (p. 8)
- "In a nutshell, we double down on the trend of using specialized local search with lower per-iteration cost to find better solutions in constraint learning." (p. 15)

### S057 · An extended validity domain for constraint learning (INFORMS Journal on Computing 2026, doi:10.1287/ijoc.2024.0815; arXiv:2406.10065)
**Read level**: full (pp. 1-25 main text; supplementary material pp. 28-36 read; references pp. 25-27 skimmed). Read version: arXiv v2, dated May 27, 2025 (p. 1); the IJOC published version was not read. Figures are images known only from captions and text.
**Role**: core · **Coauthors**: Yilin Zhu (Iowa, Department of Mathematics, p. 1) · **Place in trajectory**: Burer's entry into constraint learning (CL) with a student; S056 later cites it (S056 ref. [64]). It brings the convex-hull reformulation idea into a data-driven setting.

- **D1 Problem and entry point**: In CL a learned model ĥ is embedded in an optimization model; the optimizer can push the solution far from the training data where ĥ extrapolates badly, so x̂ is "optimal" for ĥ but suboptimal or infeasible in reality (p. 2). Validity domains (also called trust regions; the paper avoids that term because of its NLP meaning, p. 3) restrict x to stay near data: Box, convex hull CH (Courrieu), enlarged hull CHε (Maragno et al.), one-class SVM, isolation forest (Shi et al.), pp. 3, 6-7. The entry is that all of these act only in x-space (p. 3). Problem: standard CL form (1) vs true model (2), with four error measures (optimal value, optimal solution, function value, feasibility), pp. 4-5.
  - Transferable: define several error metrics up front, including ones only measurable when ground truth is known, and say which ones the method targets (pp. 5, 16).
- **D2 Core idea**: Apply the convex hull in an extended space (x, y, φ) that appends the predictions y and the objective value φ = f(x) (pp. 7-9). The justification is the "simple observation—though perhaps not well known" (p. 7) that the true problem equals min φ over conv(F⁺), the hull of the graph of f over the feasible set (Proposition 1, p. 8), and that with dense enough feasible samples the hull of the sample graph recovers v* (Proposition 2, p. 8). The validity domain CH⁺ = conv(F⁺_N) projects into CH, so v̂(CH⁺) ≥ v̂(CH) (Proposition 3, p. 9). Variants CH′ use a subset J of outputs, keep infeasible samples, or drop φ, and stay "sandwiched" between CH⁺ and CH (p. 9); an enlarged CH⁺ε is an SOC-representable Minkowski sum (p. 10). What is not changed: the ML model is untouched, and the method is model-agnostic (p. 3).
  - Transferable: before inventing a heuristic constraint, ask what the *exact* convex reformulation of the true problem is in a lifted space, then use its data-driven inner approximation as the heuristic (pp. 7-9).
- **D3 Assumptions and model**: Theory assumes noiseless evaluations of h (pp. 7-8); practice uses noisy values directly, as ML training does (p. 4). Regression only, not classification (p. 3). F̂ nonempty and attaining its optimum (p. 4). Proposition 2 assumes conv(F⁺) ⊆ lim conv(F⁺_N) (p. 8). In experiments the learned function sits in the objective (problem (4), pp. 5, 11).
- **D4 Proof devices**: Carathéodory-type convex-combination argument: a point of conv(F⁺) is a convex combination of feasible graph points, so its φ is at least the minimum f(xᵏ) (Proposition 1, p. 8). Sandwich argument v*_N ≥ v* with a convergent sequence in conv(F⁺_N) (Proposition 2, p. 8). Projection inclusion proj_x(CH⁺) ⊆ CH giving a one-line bound comparison (Proposition 3, p. 9). A 1-D worked example (f = (x−1.75)², four samples, least-squares line) shows CH⁺ improves function-value and solution errors but worsens optimal-value error (Figure 1, pp. 10-11).
  - Transferable: illustrate a new constraint on a 1-D example with four samples where you can draw both the old and new feasible sets and see which error it trades (pp. 10-11).
- **D5 Experiments**: Protocol adopted from Shi et al. (2024) (p. 10): an experiment is a 6-tuple (ground truth, sampling rule, N, noise, seed, ML model), giving 7 × 2 × 3 × 3 × 100 × 3 = 37,800 experiments on seven benchmark functions (Beale … Rastrigin), Uniform vs Normal sampling, N ∈ {500, 1000, 1500}, noise σ ∈ {0, 0.1, 0.2}, seeds 2023-2122, three scikit-learn models with fixed hyperparameters (grid search tried and found not to change conclusions, p. 12). Model quality reported (test R², Table 1; training times, Table 2, p. 13). Medians reported, scaled so Box = 1.00, with means in the supplement "to avoid any out-sized influence by the tails" (p. 13; Table S3, p. 29). Ratio distributions CH⁺/CH: better on over 60% of experiments, mode at 1.0 (Figure 2, p. 15). Enlarged hulls trade function-value error for flexibility (Table 4, pp. 15-17). Larger dimension: n₁ = 20 rotated hyper-ellipsoid, 900 experiments, with the combinations that were "prohibitive" (over 30 minutes) disclosed and excluded (pp. 16-18). Two stylized models: norm-ball NLP (Table 6, p. 19) and two-product pricing with known log-log demand (Table 7, pp. 20-21), where CH⁺ has the best feasibility error but much worse optimal-value and solution errors. Case study without ground truth: Gurobi's avocado pricing model; profit $45.84M unconstrained, $39.51M Box, $38.02M CH, $32.54M CH⁺, the last close to the empirical average of $31.10M (pp. 21-24). Sensitivity to sampling rule, noise, N and function type in the supplement (pp. 30-35). Code and results public (p. 10). Single Xeon core, Python 3.10.8, Gurobi 11.0 (p. 10); Gurobi 12.0 for the case study (p. 22).
  - Transferable: adopt the main competitor's published experimental protocol so the comparison cannot be blamed on a different testbed (p. 10).
  - Transferable: report medians normalized to the simplest baseline (= 1.00) and put the means in a supplement with a sentence on whether conclusions change (pp. 13, 28-29).
- **D6 Positioning**: Situates CL within the taxonomies of Kotary et al. and Sadana et al. (pp. 1-2) and the CL survey of Fajemisin et al. (p. 2). Each existing validity domain is described neutrally (pp. 6-7); the comparison is with the strongest recent one (IsoFor, Shi et al.), and CH⁺ is said to be faster than it (p. 3). Implementation details of embedding packages (OptiCL, JANOS, OMLT, Gurobi ML) are explicitly out of scope (p. 2). Acknowledges Paul Grigas, an associate editor and three referees (p. 25).
- **D7 Writing**: Intuition first, then propositions, then the hedged claim: "we believe the property projx(CH⁺) ⊆ CH is a defining feature of our approach" (p. 9). Worse outcomes are argued for, not hidden: CH⁺'s higher optimal-value error in pricing is defended because "one cannot have true optimality without true feasibility" (p. 20). The paper keeps the name "CH⁺" for the variants actually implemented (p. 10), saying so each time (pp. 20, 24). Small inconsistencies remain in this version: the supplement attributes $32.54M to "CH" where the main text gives it to CH⁺ (p. 35 vs p. 24); Table 7's caption speaks of "three errors" for four error columns (p. 21).
- **D8 Contribution and limits**: Methodological (a new validity domain) with light theory and a broad computational study. Limits stated concretely: CH⁺ is not best on optimal-value error; there is no rule for choosing a validity domain, which the authors say they "unfortunately lack" (p. 25); CH⁺ is somewhat more sensitive to noise (Table S4, p. 33); ε for CH⁺ε can be too loose (p. 20); the extended hull needs historical data on all variables, which the avocado case lacks for shipped quantities (pp. 23-24). Future work: feasibility of (1) under validity domains, other domain techniques in the extended space, "model aware" domains, classification (p. 25).

**Method links**: Method 1 variant ⚠: the same reflex as the conic programme (write the whole problem as linear minimization over one convex hull in a lifted space, Proposition 1, p. 8), but the hull is then inner-approximated from data and used as a constraint, not relaxed by a cone. Method 4 variant ⚠: experiments are designed where ground truth is known, and the excluded "prohibitive" combinations are disclosed (pp. 11, 16), but the testbed is the competitor's benchmark rather than one engineered where the incumbent fails. H8 evidence ✅: losses on optimal-value error printed and argued (pp. 16, 19-20, 25). H10 evidence ✅: code, results and fixed seeds public (pp. 10, 12). H5 evidence ✅: the strongest recent baseline (IsoFor) run with its authors' defaults (p. 13). New-pattern candidate: "carry the lift-and-hull reformulation from conic relaxation into data-driven (ML-embedded) optimization" (pp. 7-9; S056 shows the same group's continuation).
**Transferable techniques**:
- Extended-space convex hull of (x, ŷ, f(x)) samples as a constraint that keeps both inputs and predictions near the data (pp. 9-10).
- "Sandwich" variants between an existing method and the new one (CH′ with subsets of outputs or infeasible samples), so partial data still yields a usable version (p. 9).
- A case study without ground truth judged against an empirical benchmark (the average off-peak revenue) instead of an error metric (pp. 22, 24).
