### S237 · A test set of quadratic, binary quadratic and integer quadratic programs (test-set description, undated, no DOI or arXiv id)
**Read level**: full (pp. 1-3: all four class descriptions and the references). First-page check: title and "Carlos J. Nohra, Arvind U. Raghunathan, and Nikolaos V. Sahinidis" match (p. 1). The work-list note says "type not verified". Verified here: a bare description of a test-problem collection, with no venue, date, download location or results (pp. 1-3).
**Role**: supplement · **Coauthors**: Carlos J. Nohra (CMU Chemical Engineering), Arvind U. Raghunathan (Mitsubishi Electric Research Laboratories) (p. 1) · **Position in trajectory**: the documentation of the test libraries of the two papers that put convex quadratic relaxations into BARON, S116 (SIAM J. Optim. 2021; version dated 13 October 2020, p. 1) and S133 (Math. Program. 2022).
- Both papers say their 960 CBQP, 30 QSAP, 246 BoxQP and 315 EIQP instances "are described in detail in" this document (S116 p. 23; S133 p. 20).
- Both give its location as ftp://ftp.merl.com/pub/raghunathan/MIQP-TestSet/ (S116 p. 32; S133 p. 28). The location was not checked (no web access in this batch).
- Dating: no earlier than 2017 (latest reference, Lima & Grossmann 2017, p. 3), and cited by the October 2020 version of S116.

- **D1 Problem and entry point**: The aim is a shared, larger test bed for nonconvex QPs and MIQPs: "a large collection of nonconvex problems" in four classes (p. 1). The entry is to keep published random sets and enlarge them. BoxQP extends the sets of [2, 3, 5], which stop at n = 125 (p. 1). EIQP extends Billionnet et al.'s 45 instances, which stop at n = 40 (pp. 2-3). No reason for the choice of classes is given (pp. 1-3). My reading: all four fit the model min xᵀQx + qᵀx with linear equalities, bounds and integrality that S116 treats (S116 p. 1).
- **D2 Core idea**: Keep every inherited instance and add new ones from the same generator at larger sizes and densities, counting per source (pp. 1-3):
  - BoxQP (0 ≤ x ≤ 1): 54 instances from [5], 36 from [3] and 9 from [2]. To these are added 15 instances at ρ = 1.00 (n = 70-125) and 132 at n = 150-400, giving 246. The nonzeros of Q and q are uniform on [−50, 50] (p. 1).
  - CBQP (binary, Σx_i = M): Lima & Grossmann's 960 instances, unchanged (p. 2).
  - QSAP (binary semi-assignment): 30 instances with 15-280 variables; no source is cited (p. 2).
  - EIQP (one equality row, bounded nonnegative integers): Billionnet et al.'s three class rules. Their 45 instances (n ∈ {20, 30, 40}) are kept, and 90 per class are added at n = 60-400, giving 315 (pp. 2-3).
- **D3 Assumptions and model**: All instances are random; no application instance is included (pp. 1-3).
  - Generator knobs: n; the density ρ of Q (BoxQP, CBQP); the cardinality M ∈ {n/5, n/1.25} (CBQP); the coefficient intervals (pp. 1-2).
  - EIQP rules: Q and q are integers in [−100, 100]; A is integer in [1, 50] or [1, 100]; b = 15ΣA_i or 20ΣA_i; u_i = 30, 50 or 70 (pp. 2-3). Hence x = 15·1 or 20·1 is an integer feasible point inside the bounds (my arithmetic).
  - One CBQP coefficient interval is printed as the degenerate "[−1, −1]" (p. 2).
- **D4 Analysis**: n/a (no derivations, pp. 1-3).
- **D5 Experiments**: none in the document (pp. 1-3). The set is the test bed of S116 (BARON 19.12 against six other solvers, S116 p. 23) and S133 (BARON 20.4, S133 p. 20).
- **D8 Contribution and limits**: The contribution is data: a documented library of 1,551 instances (my sum), of which 1,104 are inherited (99 + 960 + 45), 417 are newly generated (147 + 270) and 30 QSAPs have no stated source (pp. 1-3). The authors state no limits. Missing (pp. 1-3):
  - reference optima, best-known bounds or difficulty information;
  - file format, seeds or generator code;
  - a download location in the document itself.
  No future work is given.

**Method links**:
- Method 2 ✅ evidence (step 5, a paper's instances become a public library): the test bed of two BARON papers is released with a stand-alone description (pp. 1-3) on the industrial co-author's FTP server (S133 p. 28). Whether it also joined BARON's development set is not stated.
- Method 4 ⚠ variant: the library is built on five published sets (p. 3) rather than a private one. But it ships no certified optima or best-known bounds (pp. 1-3), so its users must compare relaxations by bounds and gaps against each other, not by distance to a certified optimum.
- New-pattern candidate *extend inherited sets with their own generator*: published instances are kept intact and enlarged with the same distributions at larger n and density, with per-source counts (pp. 1-3).
- Evidence for the existing candidate *structural-knob instance generator* (S018, c03): classes are indexed by n, ρ, M and coefficient interval (pp. 1-2).

**Transferable techniques**:
- When building a test library for a new relaxation, keep the instances earlier papers used. Add new ones from the same generator at sizes beyond them, stating counts per source (99 + 147 BoxQP; 45 + 270 EIQP), so that old and new results stay comparable (pp. 1-3).
- Write the library a short stand-alone note per class (model, size and density ranges, coefficient distributions, source paper), and cite that note from every paper that uses the set (pp. 1-3; S116 p. 23; S133 p. 20).
- For random equality-constrained integer instances, set the right-hand side from a known interior integer point (b = c·ΣA_i with c < u_i), so that every instance is feasible by construction (pp. 2-3; the rule comes from Billionnet et al.).

**Quotes**:
- "In the following, we describe a large collection of nonconvex problems consisting of quadratic, binary quadratic and integer quadratic programs." (p. 1)
- "This collection is an expanded version of the set of BoxQP instances generated in [2, 3, 5]." (p. 1)

### S387 · MINLP for regularized symbolic regression with applications to data-driven modeling of critical minerals processes (poster, ACS Spring Meeting 2026, Atlanta, no DOI or arXiv id)
**Read level**: full (the one-page poster). The text layer was read in full. Page images of the local PDF were used for the BIC formula, the workflow and expression-tree graphics and the four plots; plotted values are my approximate readings. First-page check: title and "Nick Sahinidis" (third of three; Georgia Tech ChBE and ISyE) match (p. 1). The work-list note calls it a "manuscript without venue"; the text layer and footer give "ACS Spring Meeting, 2026 March 24, Atlanta, GA" (p. 1).
**Role**: supplement · **Coauthors**: Dimitrios Fardis (first author, Georgia Tech ChBE), Radhakrishna Tumbalam Gooty (NETL and NETL support contractor) (p. 1) · **Position in trajectory**: the poster twin of the S271 talk deck: same three authors, same models star_bic / star / alamo_quad, and the plotted values the S271 card reads (S271 p. 1; S271 card D5). It covers the same leaching unit as S206 ("Fardis et al., 2025", p. 1) and the AIChE 2024 poster S242, under DOE PrOMMiS funding (p. 1).
- Dropped from the deck: the GDP constraints, the depth formula in the binaries, the STAR flowchart and the EO optimum values (S271 pp. 6-10, 16).
- Added: regularized vs non-regularized parity plots for one output, a figure not among those the S271 card describes (p. 1, image).
- For the synthesis: count S387 and S271 as one piece of evidence.

- **D1 Problem and entry point**: The poster opens with an application question, "What data-driven techniques are the most appropriate to model and optimize critical mineral processes?", and answers it from prior work: ALAMO sparse quadratics (Fardis et al., 2025) (p. 1). Symbolic regression (SR) then enters as the method that assumes no model form ("useful for law discovery") but needs a guard against overfitting (p. 1).
- **D2 Core idea**: SR is written as a disjunctive program (Cozad, 2014) and solved by STAR, randomized rounding of the relaxed MINLP (Sarwar, 2022) (p. 1).
  - The change is the objective: BIC = n_data ln(SSR/n_data) + L ln n_data, with complexity measured as the tree depth L (p. 1, image).
  - Each surrogate ĥ is then embedded in min f(x) s.t. ĥ(x) = 0, x ∈ [x^l, x^u] (workflow graphic, p. 1, image).
- **D3 Assumptions and model**: one leaching tank with sulfuric acid and solid feed in, and leach solution and solid waste out (p. 1). The R² chart lists 30 outputs: 16 liquid-outlet and 14 solid-outlet quantities (p. 1, image; my count). The penalty counts tree depth, not fitted parameters as the usual BIC does (my observation). Not on the poster: input ranges, sampling plan, noise, and on which points R² and the parity plots are computed (p. 1).
- **D4 Analysis**: n/a (no proofs, p. 1).
- **D5 Experiments**: star_bic, star and alamo_quad on one unit (p. 1, image; approximate readings):
  - training time: alamo_quad is near 0 s from 10 to 1,000 points; star takes about 550 s at 10 points and about 4,300 s at about 50; star_bic about 1,300 s and 7,500 s;
  - R²: star falls to about 0.74 on Gd and about 0.62 on Y, while star_bic and alamo_quad stay near 1;
  - a Gd parity pair showing far more points than any SR training set, so it is evaluated beyond the training data; which points is not said;
  - optimum deviation: star_bic about 0.04% at 10 points, star about 0.7%, alamo_quad 0.14-0.27%.
- **D8 Contribution and limits**: The contribution is BIC-regularized SR shown as a surrogate for one critical-minerals unit (p. 1).
  - Stated limits: training is "4-5 orders of magnitude larger", and BIC doubles it; SR is efficient only "for moderate numbers of training points" (p. 1).
  - Future work: other model-selection criteria and complexity metrics (number of nodes, complexity-weighted operators) (p. 1).
  - Not stated: the chosen trees carry no optimality bound (randomized rounding); there is one unit and no repeat; the SR runs stop at about 50 training points (p. 1, image).

**Method links**:
- Method 3 ✅ evidence: an algebraic model of a simulated unit is chosen by an information criterion inside an MINLP and embedded in optimization over the input box. The price is stated (4-5 orders of magnitude, doubled by BIC) (p. 1). The poster starts from the simplest-adequate verdict (ALAMO sparse quadratics) (p. 1).
- Method 3 ⚠ variant: as in S271, the SR MINLP is not solved to certified optimality, since STAR rounds a relaxation randomly (p. 1). Research Taste mark 3 (a certificate, or a heuristic paired with a bound) is not met for the model-selection step.
- Method 4 ✅ evidence: surrogates are judged by the deviation of their optimum and solution point from a reference ("Correct solution point", p. 1). The poster does not name that reference; the deck gives the EO optimum, 5128.2 mg rare earths per hour (S271 p. 16).

**Transferable techniques**:
- Show what regularization buys with a paired parity plot (regularized vs unregularized) for an output on which the unregularized model fails (here Gd, R² about 0.74), next to per-output R² for all 30 outputs (p. 1, image).
- Open an applied poster with the application question, answer it with the group's earlier benchmark winner, and then test the new method against that winner on the same axes (training time, R², optimum deviation) (p. 1).

**Quotes**:
- "Regularization with BIC doubles the training time for SR." (p. 1)
- "Regularized SR prevents overfitting." (p. 1)

### S388 · The Treewidth-Convex HullTheorem and DP for Cut Generation in MINLP (poster, MIP 2024, no DOI or arXiv id)
**Read level**: full (the one-page poster). The text layer was read in full. Page images were used for Figure 1, the two bar charts of Figure 2 and the table layout; bar heights are my approximate readings. First-page check: title (the poster prints "Hull Theorem") and "Nikolaos V. Sahinidis" (third of three, Georgia Tech) match (p. 1). The work-list note calls it a "manuscript without venue"; the footer names MIP 2024 (p. 1).
**Role**: supplement · **Coauthors**: Sourabh K Choudhary (first author) and Santanu S. Dey, Georgia Tech (p. 1). SKILL.md's Academic Lineage records Choudhary as co-supervised by Dey and Sahinidis · **Position in trajectory**: BARON's multilinear cut generation (Bao, Khajavirad, Sahinidis & Tawarmalani 2015, ref. [1]) meets the Bienstock–Muñoz bounded-treewidth LP (ref. [2]) (p. 1). The same three authors revisit the exactness proof in the 2026 manuscript H009. Its abstract gives a midpoint proof and a complementary-slackness proof and does not mention cut generation (H009 p. 1; H009 not read beyond its abstract).

- **D1 Problem and entry point**: two entries (p. 1).
  - A known theorem: an unconstrained binary polynomial problem (UBP) with treewidth d and n variables "can be reframed as an LP with O(n2^d) nonnegative variables and constraints" [2]. The poster gives another proof.
  - A computational bottleneck: cuts for a multilinear intermediate z = L(x) over a box come from the cut-generation LP (CGLP) of [1]. Its dual has one weight λ_i per box vertex v^i, that is 2^n columns (my count).
- **D2 Core idea**: two parts (p. 1).
  - Proof: the LP is converted into a DP formulation, from which integrality follows; as a corollary the LP is TDI.
  - Algorithm: the CGLP dual is solved by column generation. The pricing problem L(b) − πᵀb − π_0 is itself a UBP and is solved by DP. The cut z ≥ ax + b, with a and b the duals of the two constraint blocks, is added if z* < ax* + b.
  - My reading: the DP of the proof is the pricing routine.
- **D3 Assumptions and model**: a multilinear intermediate over a finite box (p. 1). The DP needs a tree decomposition of bounded width, and the test instances are "generated from a known tree-decomposition" (p. 1); finding one for a general model is not discussed (p. 1). Sizes: n = 25-30 with d = 10 (table), and n = 15-20 with 40 or 80 monomials (Fig. 2, image).
- **D4 Analysis (brief)**: only the skeleton is given (LP → DP → integrality → TDI); the proof itself is not on the poster (p. 1).
- **D5 Experiments**: two comparisons (p. 1, table and image; bar heights approximate).
  - CGLP time, DP pricing against a "gray code" method that the poster does not explain. At n = 20: under 1 s against about 46 s with 40 monomials, and about 34 s against about 64 s with 80 monomials.
  - Root bound, "basic relaxation with our cuts" against BARON's lower bound after 20 min, on 6 unconstrained and 6 linearly constrained example instances. It is better by 60.8-67.0% (unconstrained) and 43.2-50.3% (linearly constrained), after 76-184 s of cut generation. "Better by" equals (bound − BARON LB)/|BARON LB| (my arithmetic).
  - Not given: BARON's version and settings, what the "basic relaxation" is, and any optimal values.
  - A valid bound cannot exceed the optimum, so BARON had not closed these instances in 20 minutes (my inference).
- **D8 Contribution and limits**: The contribution is an alternative proof with a TDI corollary, and a CGLP framework for NLPs with multilinear intermediates (p. 1).
  - Stated future work: integration "within the Branch and Bound (B&B) tree of standard solvers" (p. 1).
  - Also limiting: synthetic instances from known decompositions, one example instance per size and type, and root bounds only (p. 1). With 80 monomials the DP's own time grows steeply with n (Fig. 2, image).

**Method links**:
- Method 5 ✅ evidence (step 1, partial): the new cuts are reported with their bound and their time together (76-184 s against BARON's 20-minute bound), and the separation routine is timed against an alternative (Fig. 2) (p. 1). Numerical failures are not discussed, and there is no library (p. 1).
- Method 5 ⚠ variant (step 3): the costly exact separation is not replaced by a cheaper object. It is kept and made cheaper by column generation with structure-exploiting pricing (p. 1).
- Method 2 ⚠ variant: a stand-alone prototype is judged against BARON's lower bound from outside, not as an on/off build inside BARON. Integration into "standard solvers" is future work (p. 1).
- Heuristic 1 ✅ (card text only): a special class (bounded-treewidth multilinear terms) whose small instances (n = 25-30) BARON does not close in 20 minutes, with folding into general solvers named as the next step (p. 1).
- Evidence for the existing candidate *Transfer integer-programming devices into global optimization* (s02): column generation and DP over a tree decomposition are used to separate multilinear cuts (p. 1). Also evidence for *structural-knob instance generator* (S018): instances are generated from a known tree decomposition with n, d and the number of monomials set (p. 1).
- New-pattern candidate *constructive re-proof as the oracle*: the DP that re-proves the exactness theorem serves as the pricing routine of the cut generator (p. 1).

**Transferable techniques**:
- When a cut-generating LP has one column per box vertex, solve its dual by column generation. The pricing problem is a binary polynomial problem over the same interaction graph, so a DP over a tree decomposition prices it exactly (p. 1).
- Generate test instances from a known tree decomposition, so that n and the width d can be varied separately (p. 1).

**Quotes**:
- "We show that the LP can be converted into a DP formulation and hence the integrality can be proven." (p. 1)
- "Future work involves integrating this within the Branch and Bound (B&B) tree of standard solvers." (p. 1)
