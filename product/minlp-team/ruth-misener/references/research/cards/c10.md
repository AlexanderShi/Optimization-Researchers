### S039 · SnAKe: Bayesian optimization with pathwise exploration (NeurIPS 2022, doi:10.52202/068431-2553, arXiv:2202.00060)

**Read level**: full. Main text pp. 1-10, references pp. 11-13, checklist p. 14, appendices A-F pp. 15-25 read in full; the figure-only appendix pages pp. 26-39 (Figures 11-30) skimmed via their captions only.
**Role**: core · **Coauthors**: Jose Pablo Folch (first and corresponding author), Shiqiang Zhang, Calvin Tsay, Mark van der Wilk (Imperial); Robert M. Lee, Behrang Shafei, David Walz (BASF SE) (p. 1) · **Position in trajectory**: BASF-funded BO line (acknowledgements, p. 10) next to the tree-ensemble work (S047); this is the paper behind her later talk remark that a global method had been turned into a local one (SKILL.md, Taste warning sign 3).

- **D1 Problem and entry point**: Entered from an application whose physics breaks two standard BO assumptions at once: in droplet microfluidic reactors, large input changes (e.g. temperature) leave steady state, so "the expense of evaluating the function can increase significantly when making large input changes between iterations", and results arrive with delay, so decisions are asynchronous (abstract and pp. 1-2; Figure 6, p. 15). A second motivation is spatially continuous exploration (pollution tracking, autonomous boats on Ypacarai Lake, p. 2). The problem is stated as maximising f with noisy observations, a delay t_delay, a known input-change cost C(x_t, x_{t+1}), simple regret as metric and cumulative cost to be kept small (§3.1, p. 3).
  - Transferable: before designing, list which assumptions of the standard method the application breaks (here: free movement in input space, immediate observations) and make each one a model element (cost term, delay parameter) (pp. 1, 3).
- **D2 Core idea**: Decouple what to query from the order in which to query it: draw a large batch by Thompson sampling (one GP sample per point, §3.3, pp. 3-4), order it by solving a travelling salesman problem with edge weights = input-change cost (§3.4, p. 4), follow the path until new data arrive, then resample and re-route (Algorithm 2, p. 7). Naive resampling gets stuck at local optima because each resample reintroduces exploitative points that the TSP always visits first (§3.5, Figure 1, p. 4); the fix is ε-Point Deletion: oversample T points and delete, for each already-queried point, the nearest new sample within ε (Algorithm 1, p. 6). A parameter-free variant sets ε to the smallest GP length scale (ℓ-SnAKe, p. 8; App. E.4, p. 19). Because batch creation and deletion ignore the cost and TSP is scale-invariant, the method is invariant to cost scaling, unlike cost-aware acquisition functions such as EIpu (pp. 3, 7). Unchanged from classical BO: the GP surrogate and Thompson sampling.
  - Transferable: when the order of evaluations carries the cost, first choose a set of queries with a standard criterion, then optimise the sequence (TSP) as a separate combinatorial problem; this also makes the method invariant to the scale of the cost (pp. 3-4, 7).
- **D3 Assumptions and model**: f continuously differentiable on a compact X ⊂ R^d, Gaussian noise, known cost function C, GP prior (p. 3). The escape analysis additionally assumes noise-free observations, resampling at every iteration and a worst-case TSP that always picks a point in the δ-ball if one exists (pp. 4-5). For experiments, prior knowledge of GP hyperparameters is "simulated" by an educated guess from max(T/5, 10d) random points and box bounds of half/double that guess (App. E.3, p. 19). The SnAr case uses a first-order dynamic reactor model and a quasi-steady-state cost (Eqs. (3)-(4), p. 9).
- **D4 Analysis and proof technique**: Heuristic, explicitly not rigorous: "we are not providing rigorous theoretical justification for the step or proving any type of regret bounds" (p. 4). Devices: number of samples falling in a δ-ball is Binomial(T - t, p_t), so full escape has probability (1 - p_t)^{T-t} (Remark 3.3, p. 5); with p_t → p > 0 near a local maximum, increasing the budget only lengthens the time stuck, never the exploration budget after escape (Remark 3.4, p. 5); with point deletion and ε ≥ 2δ, escape needs only N_t ≤ q_t, giving an expected exploitation time pT and T(1 - p) iterations left for exploration (p. 6). The analysis is checked empirically: p_t estimated by 5000 Thompson samples per data size (≈0.74 in an interval with a stationary point, → 0 without one; App. D, Figures 8-9, p. 17) and the predicted escape iteration pT plotted against actual paths for T = 100 and 250 (Figure 10, p. 18).
  - Transferable: when a heuristic step lacks a theorem, write a back-of-envelope probability model of the failure mode (here Binomial escape), derive a prediction (escape at iteration ≈ pT), and plot the prediction against the observed behaviour on a 1D toy (pp. 5-6, 17-18).
- **D5 Numerical experiments**: Synthetic sequential benchmarks (Branin2D, Ackley4D, Michalewicz2D, Hartmann3D/6D, Perm10D) with budgets T = 15, 50, 100, 250 and 2-norm cost (p. 8; Tables 3-4, p. 23); asynchronous runs with t_delay = 10, 25 (Tables 5-6, p. 24); SnAr chemistry benchmark in Summit with a physics-based cost and delays 5-50 (pp. 8-9; Tables 7-10, pp. 24-25); Ypacarai Lake with three Shekel objectives and a 10-unit (≈100 km) travel budget, including a simultaneous three-objective variant (Table 1, p. 10; Table 2, p. 16). Baselines: EI, UCB, PI, EIpu (γ = 1 fixed), truncated EI, a TSP-ordered Sobol "Random" path, and asynchronous UCB/EIpu with local penalisation and Thompson sampling (pp. 8, 19-20). ε ∈ {0, 0.1, 1} plus ℓ-SnAKe is reported everywhere (p. 8). Fairness moves: same seed per run-function pair (p. 19); Ackley's domain shifted "to avoid having the optimum exactly at a point in the Sobol grid and giving SnAKe an unfair advantage" (p. 21). Failures reported: Perm10D and low budgets (p. 8; Table 3 caption, p. 23; Figure 16 caption, p. 31). Two audit notes: the main text says all results are over 25 runs (p. 8) while the asynchronous and SnAr figures are over 10 runs (pp. 25) and Ypacarai over 10 runs (p. 10); and "comparable" regret hides cases where EI is clearly better at T = 250 (e.g. Hartmann3D -12.4 vs -9.4 for ℓ-SnAKe, Table 4, p. 23).
  - Transferable: when your method trades one metric for another, plot regret against the cost actually spent (not only against iterations) and include a "your ordering, no learning" baseline (TSP-ordered random path) to show what the learning adds (pp. 8-9).
- **D6 Positioning**: Closest analogue named and differentiated: process-constrained batch BO fixes hard-to-change inputs per batch, SnAKe instead penalises changes and decides when to make them (p. 2). Cost-aware BO assumes region-dependent costs, here the cost depends on the move, so "we focus on optimization paths instead of optimization sets" (p. 2). Three precise objections to the natural adaptation γ-EIpu (new hyperparameter, over-exploitation near local optima, conflict with batch diversity) (p. 2). Look-ahead BO and RL are acknowledged and set aside for horizon or environment reasons (p. 3). Cites own group once (Thebelt et al. 2022 on physics limits in BO, p. 2).
  - Transferable: when adapting the obvious baseline to your setting, list its specific failure points (a), (b), (c) before presenting your method (p. 2).
- **D7 Writing and rhetoric**: Contribution stated in the abstract with a robustness claim tied to the single hyperparameter and a parameter-free fallback (p. 1). A playful name and image ("Just as the snake grows by carefully eating items in the classic arcade game", p. 2). The negative result (naive resampling stuck) is shown before the fix (§3.5, Figure 1, p. 4). Hedging is explicit and placed in three places: the analysis disclaimer (p. 4), the limitation paragraph inside §4's introduction (p. 8) and the checklist ("it is not fully rigorous and it is only meant to illustrate the importance of the Point Deletion heuristic", p. 14). Acknowledgements credit "Discussions with colleagues in the Imperial Department of Computing" for ε-Point Deletion and ℓ-SnAKe, and the reviewers (p. 10).
  - Transferable: show the naive version failing on a 1D picture first, then present the fix with the same picture (Figure 1(a)-(c), p. 4).
- **D8 Contribution and limits**: Contribution: a new problem setting (BO with movement costs and asynchronicity) plus an algorithmic framework; "SnAKe spends 45-55% of the cost while making similarly strong predictions to classical BO" on SnAr (p. 10). Limits are specific: needs enough iterations to fill the space, poor on Perm10D, ordinary at low budgets (p. 8); TSP is NP-hard and solved heuristically by simulated annealing on an adaptive grid that introduces two more hyperparameters (N_l, N_g) asserted, not shown, not to matter (p. 7; App. E.1, pp. 17-18). Future work: several SnAKes in parallel, multi-objective variants (p. 10). The general ordering-based scheme is offered as a template (Algorithm 3, App. B, p. 15).

**Method links**:
- Method 2 (parameterised family, then remove the parameter): evidence ✅. The paper sweeps ε ∈ {0, 0.1, 1}, claims robustness for non-zero ε and offers ℓ-SnAKe as the parameter-free alternative (abstract p. 1; p. 8); the ε = 0 endpoint is shown to cost regret (Table 4 caption, p. 23). Variant ⚠: the adaptive-grid parameters N_l, N_g are introduced with an assertion but no sweep (p. 7).
- Method 5 (benchmark like an auditor): variant ⚠. Fairness moves exist (shifted Ackley domain p. 21; common seeds p. 19; EIpu with one fixed γ rather than per-comparison tuning, pp. 8, 20), but run counts are inconsistent (25 stated, 10 used for asynchronous and SnAr results, pp. 8, 25) and no tuning of the competitors' γ is attempted although the paper argues they "require careful tuning" (p. 8).
- Method 3 (partner's model and data as the problem): weak evidence ✅. The setting comes from the BASF partner's reactor (authors and funding, pp. 1, 10), but the surrogate is a generic GP, not a partner model.
- Heuristic 1 (choose by broken assumption): evidence ✅. Two complications of the reactor collide with BO's assumptions (cost of moving, delayed observations) (pp. 1-3).
- Workflow D step 2 / Taste warning sign 3 (purpose check, global turned local): evidence ✅. The resampling design that gets stuck at local optima is exposed and analysed (Remark 3.4, p. 5) and fixed by point deletion (pp. 5-6).
- new-pattern candidate: "select-then-sequence" (choose the query set with a statistical criterion, order it with a combinatorial solver; scale invariance follows) (pp. 3-4, 7).

**Transferable techniques**:
- Separate set selection (Thompson-sampled batch) from sequencing (TSP over the batch with cost-weighted edges); re-plan only when new observations arrive, which makes asynchronous delays free to handle (Algorithm 2, p. 7).
- Fix over-exploitation from repeated resampling by deleting, for each past query, its nearest new sample within a radius ε (Algorithm 1, p. 6); set ε from the GP length scale to remove the parameter (p. 19).
- Turn a heuristic's failure mode into a Binomial model and validate its predicted escape time empirically (Remarks 3.3-3.4, p. 5; Figures 8-10, pp. 17-18).
- Model a physical input-change cost as response time of a first-order system, capped by the slowest variable (Eqs. (3)-(4), p. 9).
- Report both "regret vs iterations" and "regret vs cost spent", and include an "order only, never learn" baseline (p. 8).

**Quotes**:
- "We show the method is robust to the choice of its single hyper-parameter and provide a parameter-free alternative." (p. 1)
- "While we include some mathematical analysis in Sections 3.6 and 3.7, it is not fully rigorous and it is only meant to illustrate the importance of the Point Deletion heuristic." (p. 14)

### S047 · Tree ensemble kernels for Bayesian optimization with known constraints over mixed-feature spaces (NeurIPS 2022, doi:10.52202/068431-2711, arXiv:2207.00879)

**Read level**: full. Main text pp. 1-10, references pp. 11-14, checklist p. 15, appendices A-F pp. 16-27 read in full (figure pages pp. 21-24 read for captions and axes).
**Role**: core · **Coauthors**: Alexander Thebelt (first and corresponding author), Calvin Tsay (Imperial); Robert M. Lee, David Walz, Behrang Shafei (BASF SE); Nathan Sudermann-Merx (Cooperative State University Mannheim) (p. 1) · **Position in trajectory**: the "tree-kernel BO" step of the trees → ENTMOOT → OMLT → tree-kernel BO → BARK line (SKILL.md Method 3); reuses the group's ENTMOOT/OMLT tree formulations (p. 5).

- **D1 Problem and entry point**: Two known obstacles to tree ensembles as BO surrogates, cited from Shahriari et al.: (i) quantifying uncertainty for exploration and (ii) optimising a piecewise-constant acquisition function (abstract p. 1; p. 2). The entry is that existing tree-based tools solve (i) with empirical variance or quantile regression and (ii) with random or local search, and none support input constraints (p. 2), while many real problems carry known constraints and hierarchies (NAS layer hierarchies, kernel/stride consistency, p. 1).
  - Transferable: open with the two standing obstacles a respected review names for your model class, then show that one formulation removes both at once (abstract, p. 2).
- **D2 Core idea**: Use the kernel interpretation of a tree ensemble (the fraction of trees in which two points share a leaf, k = σ0² |T|^{-1} z(x)ᵀz(x')) as a GP prior (Eq. (1), p. 3), and write the GP's UCB acquisition as a mixed-integer second-order cone program: Mišić's tree-ensemble MILP (Eqs. (3), p. 4) plus input-linking constraints (Eqs. (4), p. 5) give the leaf binaries; the kernel vector K_{x,X} becomes linear in the leaf binaries through a precomputed data-leaf incidence matrix A (Eq. (8b), pp. 5-6); the Gram matrix and targets are constants; the variance needs only the "≤" direction and is a second-order cone constraint (p. 6). Known constraints h(x) = 0, g(x) ≤ 0 (linear, quadratic, polynomial) are added directly (Eq. (5), p. 5). Because the optimum is a box of leaf intersections, the query is the box midpoint (random rounding for integers, uniform sampling for categories), projected onto the feasible set when constraints cut the box (Eqs. (9)-(11), p. 6). What is unchanged: the tree MILP of Mišić / ENTMOOT / OMLT and the kernel of Davies-Ghahramani (pp. 3-5).
  - Transferable: when a learned model enters an optimisation problem, precompute every data-dependent quantity (here the incidence matrix A) so that the model's output is linear in the decision binaries (Eq. (8b), pp. 5-6).
- **D3 Assumptions and model**: The tree ensemble (LightGBM, depth 3, 50 trees; depth 5, 100 trees for CIFAR-NAS) and the kernel hyperparameters (σ0², σ_y²) are trained separately (p. 3; App. C.1, p. 16). The kernel is non-stationary and describes a prior over piecewise-constant functions (p. 3). Constraints may be linear, quadratic or polynomial (p. 5); κ and boosting hyperparameters are kept constant across benchmarks (p. 6). Acknowledged limits of the model: the tree kernel may be a poor prior for purely continuous spaces (p. 6).
- **D4 Analysis and proof technique**: n/a for theorems (checklist "N/A", p. 15). Formulation devices instead: the kernel as a sum over leaf binaries weighted by a constant matrix (Eq. (8b), p. 6); the one-sided relaxation of the variance equality into a second-order cone, recognised automatically by Gurobi 9 and compatible with Bonmin, MindtPy, Pajarito and SHOT (p. 6); NP-hardness of acquisition and projection problems stated, but Gurobi "often solves both problems to ε-global optimality for moderately-sized tree models in less time compared to random sampling" in preliminary runs (p. 6); indicator and symmetry-breaking constraints that force inactive layers to default values for NAS (Eqs. (18)-(19), p. 19; Eqs. (27), p. 26).
  - Transferable: if a nonconvex equality enters the problem only through a bound in the useful direction, keep only that inequality and check whether it is a conic constraint (p. 6).
- **D5 Numerical experiments**: Twenty seeds, median and first/third quartiles, same initial points for all methods (5, or 10 for NAS), HTCondor cluster (p. 7; App. B, p. 16). Three questions: (i) does the tree kernel capture uncertainty? tested by constraining the tree-agreement ratio R in the optimiser and measuring relative prediction error (Eqs. (12)-(13), Figure 2, pp. 7-8; Figure 6, p. 21); (ii) global vs sampling acquisition optimisation, via LEAF-GP-RND = same acquisition maximised by 2000 random evaluations (p. 8; App. C.1, p. 16); (iii) constrained and mixed spaces: G1, G3, G4, G6, G7, G10, Alkylation, Pressure Vessel, CIFAR-NAS (29D), VAE-NAS (32D) (pp. 8-10; Figures 8-9, pp. 23-24). Baselines: SMAC3 (given InCondition hierarchies), SKOPT-GBRT/RF, BoTorch UCB/EI with Matérn, pymoo GA (p. 3; App. C, pp. 16-17). Competitors without constraint support get a quadratic penalty with λ ∈ {1, 10, 100} and only their best run is plotted (Eq. (14), p. 8; Eq. (15), p. 17). Losses stated: BoTorch Matérn methods improve fastest on Hartmann (6D) (p. 8); SMAC slightly beats LEAF-GP on CIFAR-NAS (p. 10). Audit notes: BoTorch restarts are cut to five for constrained problems because of run time (p. 17); G4 is labelled 5D on p. 9 and Table 2 (p. 18) but "10D" in Figure 8 (p. 23).
  - Transferable: to isolate the value of exact acquisition optimisation, keep surrogate and acquisition fixed and swap only the optimiser for random sampling (LEAF-GP vs LEAF-GP-RND, p. 8).
- **D6 Positioning**: Builds on Mišić (2020) and the group's own gradient-boosted-tree MINLP (Mistry et al.), ENTMOOT and OMLT (pp. 2, 4-5). Prior tree-based BO tools are restated, not attacked: SMAC (empirical variance + local/random search), TPE ("ignores dependencies between dimensions"), SKOPT (quantile regression, random sampling) (p. 2). The ReLU-network MIP approach of Papalexopoulos et al. is noted to rely on random initialisation for exploration (p. 2). The novelty claim is the combination: "Although these two needs have been considered separately, we are able to address both simultaneously" (p. 10).
  - Transferable: present a combination paper by naming the two needs addressed separately in prior work and the single formulation that addresses both (p. 10).
- **D7 Writing and rhetoric**: A "Contributions." paragraph mapping each claim to a section (p. 2). Claims are graded by setting: "performs as well as state-of-the-art methods" for unconstrained problems and "outperforms" for mixed-variable constrained problems (abstract, p. 1; repeated in the conclusion, p. 10). An explicit "Limitations." paragraph inside the method section (pp. 6-7). The weakest test is framed before results are shown: "We do not expect tree model-based approaches to perform well since both benchmark functions are continuous" (p. 8).
  - Transferable: state in advance where your method should not win, then report that result honestly as "roughly equivalent" (p. 8).
- **D8 Contribution and limits**: Contribution: algorithmic (MISOCP acquisition for tree-kernel GPs) plus software (github.com/cog-imperial/tree_kernel_gp, p. 2). Limits: poor prior on purely continuous spaces; NP-hard acquisition for large data and high dimension, with Gurobi as a heuristic fallback (pp. 6-7); the query heuristic (box midpoint + projection) is a heuristic choice inside an exact solve (p. 6). SKILL.md Method 4 step 8 records that BARK later called this heuristic "not principled and hence potentially sub-optimal" (not re-read here). No explicit future-work list (p. 10).

**Method links**:
- Method 3 (the trained model is the problem: constraints, then a toolkit): evidence ✅. The tree ensemble is written as MILP constraints with ENTMOOT/OMLT formulations (pp. 4-5) and the BO acquisition is solved globally as a MISOCP (pp. 5-6), which is Method 3 step 8 in practice; partner co-authors and funding from BASF (pp. 1, 10).
- Method 1 (structure as insider information): evidence ✅. The structure exploited is that the tree kernel is an inner product of leaf indicators, so the GP posterior becomes linear/conic in binaries (Eq. (8b), p. 6); domain structure (NAS hierarchies, layer symmetries) enters as indicator and symmetry-breaking constraints (pp. 10, 19).
- Method 4 (judge a component inside the whole algorithm): evidence ✅. Exact acquisition optimisation is judged by full BO runs against a sampling variant of the same algorithm (LEAF-GP-RND, p. 8), not by acquisition values alone.
- Method 5 (benchmark like an auditor): variant ⚠. Strengthened competitors (best of three penalty weights, SMAC given hierarchy information, pp. 8, 17) and stated losses (pp. 8, 10), but BoTorch restarts reduced for constrained problems (p. 17), and figure/table inconsistency on G4 (pp. 9, 23).
- Heuristic 7 (do-not-use conditions next to the method): evidence ✅. Limitations paragraph names purely continuous spaces and large NP-hard instances (pp. 6-7).
- new-pattern candidate: "validate the surrogate's uncertainty signal by constraining it inside the optimiser" (cap tree agreement R and measure prediction error, Eqs. (12)-(13), pp. 7-8).

**Transferable techniques**:
- Encode a tree-kernel GP's mean and standard deviation as a MISOCP via a precomputed data-leaf matrix and a one-sided cone constraint for the variance (Eqs. (6)-(8), pp. 5-6).
- Resolve the "flat optimum" of piecewise-constant acquisitions by taking the midpoint of the optimal leaf box and projecting onto known constraints (Eqs. (9)-(11), p. 6).
- Test whether a model's uncertainty proxy is informative by adding a constraint that caps it and plotting prediction error against the cap (pp. 7-8).
- Give penalty-based competitors their best penalty weight from a small grid and plot only that (p. 8).
- In NAS-type spaces, add indicator constraints fixing inactive-layer hyperparameters to defaults to break symmetry and shrink the search (pp. 10, 19).

**Quotes**:
- "The method suffers from standard BO challenges where the tree kernel may not be a good prior for the underlying black-box function, e.g., purely continuous feature spaces." (p. 6)
- "Although LEAF-GP is not specialized to this setting, observe that it performs roughly equivalently to the state of the art on these continuous, unconstrained optimization problems." (p. 8)

### S055 · A robust approach to warped Gaussian process-constrained optimization (Mathematical Programming 196(1), 2022, doi:10.1007/s10107-021-01762-8, arXiv:2006.08222)

**Read level**: full, of the arXiv v1 preprint (15 Jun 2020), not the journal version: main text pp. 1-25, references pp. 25-31, appendices A-D pp. 32-39 all read.
**Role**: core · **Coauthors**: Johannes Wiebe (first author, Imperial Computing); Inês Cecílio, Jonathan Dunlop (Schlumberger Cambridge Research) (p. 1) · **Position in trajectory**: Wiebe's line on degrading equipment (cites Wiebe, Cecílio, Misener 2018, p. 31) moving into robust optimisation over learned functions; its Python module that turns a GPy model into Pyomo expressions (p. 18) precedes the OMLT toolkit idea.

- **D1 Problem and entry point**: Two communities each miss half: BO handles black-box constraints via probability of satisfaction, while the global-optimisation community replaces black boxes by surrogates but "This approach, however, rarely considers uncertainty in the black box function" (p. 2). Parametric-uncertainty treatments of surrogates (Hüllen et al.) are the closest prior work; this paper proposes "a more direct approach utilizing probabilistic surrogate models" (p. 2). The new class is constraints in which the same black box appears several times at different points, Σ_i g(y_i) x_i ≤ b, motivated by degradation over periods, routing times, project durations and drill scheduling (Eq. (1), p. 2), required to hold with probability 1 - α (Eq. (2), p. 3).
  - Transferable: identify a constraint pattern that recurs across applications (here aggregation of one black box over several decision points), list four applications that contain it, and make the pattern the paper's problem class (p. 2).
- **D2 Core idea**: For a standard GP, the chance constraint has an exact deterministic equivalent (mean plus quantile times standard deviation, Eq. (4), pp. 5-6). For a warped GP (monotonic tanh warping into a latent GP, Eq. (3), p. 5) no direct reformulation is known, so build an α-confidence ellipsoid in latent space, map it back through the warping to a decision-dependent uncertainty set U(y) (Eqs. (6)-(9), pp. 6-7), and write the robust constraint's inner maximisation through Wolfe duality; KKT stationarity and complementary slackness then yield a deterministic counterpart free of Σ^{-1} (Eqs. (11)-(13), pp. 7-8). When U is nonconvex, solve the inner problem globally by a custom spatial branch and bound on boxes (Algorithm 1, p. 11). An a posteriori bisection on α trades the a priori guarantee for less conservatism (Algorithm 2, pp. 11-12). For drill scheduling, a continuous-depth formulation replaces the discretised MINLP and the integer part (number and placement of maintenance events) is handled by bounded enumeration plus heuristics (pp. 15-18).
  - Transferable: when a chance constraint has no closed form, replace it by a robust constraint over a confidence set of the model's predictive distribution, then dualise the inner maximisation to get a single-level deterministic counterpart (pp. 6-8).
- **D3 Assumptions and model**: The guarantee holds "given that the warped GP models the underlying data generating distribution well" (p. 6). Warping monotone (a_j, b_j ≥ 0, p. 5). The Wolfe-duality reformulation is exact only when the warped set U is convex; Theorem 1 gives a sufficient condition: concave (convex) warping with x ≥ 0 (x ≤ 0) (p. 9). Lemma 4 assumes x_i ≥ 0 (p. 10). Drill scheduling: rock parameters per segment known a priori, few maintenance events (≤ 4) and ≤ 10 grouped segments (p. 16); motor degradation modelled by a warped GP on 10 points from a published curve (Ba et al.) (p. 15); bit-rock model from Detournay et al. (App. D, pp. 36-38).
- **D4 Analysis and proof technique**: Wolfe duality on the inner maximisation and KKT manipulation to eliminate Σ^{-1} (pp. 7-8). Theorem 1 (unique KKT point) by moving the problem to latent space, using the inverse-function derivative (Lemma 1) to map KKT systems one to one, and convexity in latent space (pp. 9-10). Optimum on the boundary by a perturbation argument (Lemma 2 / Lemma 6, p. 10, p. 35); ellipsoid bounding box by stationarity (Lemma 3 / Lemma 7, pp. 35-36); monotonicity of h^{-1} makes the box corners give lower and upper bounds (Lemma 4, Theorem 2, pp. 10-11), which drive the box branch and bound (Algorithm 1, p. 11). Lemma 5 bounds the optimal maintenance depths by those of the no-degradation solution via an exchange argument and induction (p. 17), shrinking the enumeration (Note 1, p. 17). Appendix B shows the finite-dimensional ellipsoid problem conservatively approximates a robust problem over a set of functions (Theorem, pp. 33-35). Version caveats in v1: Algorithm 1's loop condition is printed as "≤ ε" (p. 11), Lemma 4's proof cites "Lemma 6" (p. 10), and "Fig. (??)" references are broken (pp. 13, 16).
  - Transferable: for a nonconvex inner maximisation over an ellipsoid with a monotone objective map, bound it by the ellipsoid's bounding box corners and branch on boxes, pruning boxes entirely inside or outside the ellipsoid (Lemmas 3-4, Theorem 2, Algorithm 1, pp. 10-11).
- **D5 Numerical experiments**: Pyomo 5.6.8 models, a new module converting GPy models into Pyomo expressions, Ipopt with 30 random multistarts stopped after five identical optima (p. 18). Production planning: T = 1, 2, 3, 6 periods, 30 confidence levels, 50 training points with uniform or non-uniform noise σ ∈ {0.01, 0.03, 0.05, 0.08}; feasibility measured on 1 million samples from the true distribution (pp. 19-22). Results: standard GP feasibility drifts from the target as noise rises (Figure 5, p. 20); warped-GP robust solutions are almost always conservative and conservatism varies with T (Figure 6, p. 21); worst-case profit falls with confidence (Figure 7, p. 22); the a posteriori procedure tracks the target at low noise (Figure 8, p. 23). Drill scheduling: 2- and 6-segment geologies, depths 2000-4500 m, enumeration vs boundary heuristic vs no-degradation heuristic, costs and solve times (Figures 9-11, pp. 24-26). For the drilling warping (neither convex nor concave), the reformulated solution is checked with Algorithm 1 and the bilevel problem would be solved only on failure; "For the instances considered in this work, the obtained solution always turns out to be feasible" (p. 19). No competing chance-constraint method (sampling or safe approximation) is run.
  - Transferable: evaluate a chance-constrained solution by its empirical feasibility under the true data-generating distribution on a large sample and plot achieved vs target confidence with the diagonal drawn in (Figures 5-6, 8, pp. 20-23).
- **D6 Positioning**: Bridges three literatures: BO with black-box constraints (p. 2), surrogate-based global optimisation including her own work (Boukouvala, Misener, Floudas 2016; Mistry et al. 2018) (p. 2; refs pp. 27, 29), and robust/chance-constrained optimisation (Charnes-Cooper for the Gaussian case, Ben-Tal et al. for dual robust counterparts) (pp. 5-6). **Method links**:
- Method 3 (the trained model is the problem: constraints, then a toolkit): evidence ✅. A trained (warped) GP is turned into deterministic Pyomo constraints with a reusable GPy-to-Pyomo module (p. 18); the partner's equipment degradation curve is the learned model (p. 15).
- Method 1 (structure detection as insider information): evidence ✅. The custom global strategy exploits the monotone warping and the ellipsoid geometry (Lemmas 2-4, Theorem 2, pp. 10-11); Lemma 5 exploits the structure of the no-degradation solution to bound maintenance depths (p. 17).
- Method 2 (parameterised family between extremes): variant ⚠. The confidence 1 - α interpolates between the nominal problem (1 - α = 0, ~50% feasible) and the fully robust one (1 - α = 1, zero profit) and is exposed as the user's lever, with Algorithm 2 as a procedure for setting it (pp. 11-12, 21-22); this is a probabilistic knob, not a formulation family.
- Method 5 (benchmark like an auditor): variant ⚠. Independent verification is strong (1 million samples from the true distribution, p. 20; a posteriori check of the reformulation by global inner solve, p. 19; enumeration as ground truth for the heuristics, pp. 24-26), but there is no competing method, and the outer problems are solved with a local solver (Ipopt multistart, p. 18).
- Heuristic 2 (industrial instance first, general class second): evidence ✅. Schlumberger co-authors and an industrially relevant drilling case next to a generic production-planning case (pp. 1, 3, 13-16), with public data (published degradation curve and rock parameters, pp. 15, 37).
- Heuristic 4 (prove the hierarchy, experiment for the rest, label it): evidence ✅. Theorem 1 covers concave warping with nonnegative x; for the drilling warping the paper says the theorem "cannot be applied" and checks feasibility numerically instead (p. 19).
- new-pattern candidate: "a posteriori validity check when a theorem's conditions fail" (solve the cheap reformulation, verify with an exact inner solver, fall back to the bilevel problem only on failure, p. 19).
