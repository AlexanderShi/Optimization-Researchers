# Batch c01 · Ruth Misener · core round 1 (PhD-era Floudas-group papers, 2010-2011)

Batch intent: see how the PhD-era Misener (Princeton, with Floudas) built the pooling/piecewise-linear line that later became GloMIQO/ANTIGONE: how she enters a problem from an application (lookup tables, EPA law), how she reads a model for hidden structure, how she picks among equivalent MILP formulations, and how she judges a formulation (root vs whole algorithm) before the 2012+ "auditor" benchmarking habits appear.
Focus dimensions: D1-D8 (default mathematical/computational meanings; team.json "card_dimensions" is empty), with emphasis on D1 (application entry), D2 (formulation choice), D5 (evaluation protocol) and D8 (how scope and losses are written).
Material roles: S012 core (JOTA 2010, piecewise-linear approximation of multidimensional functions); S025 core (Comput. Chem. Eng. 2010, extended pooling with the EPA Complex Emissions Model); S009 core (Comput. Chem. Eng. 2011, APOGEE: linear vs logarithmic piecewise relaxations).
Page mapping: all three files are author preprints, not the journal typeset versions. In each, the file's [[page N]] marker equals the preprint's own printed page number (S012: pp. 1-31, undated preprint; S025: pp. 1-38, dated February 8, 2010; S009: pp. 1-38, dated December 21, 2010). ### S012 · Piecewise-linear approximations of multidimensional functions (Journal of Optimization Theory and Applications 2010, doi:10.1007/s10957-009-9626-0)
Read level: **full** (pp. 1-31, author preprint; reference list pp. 28-31 skimmed).
**Role**: core · **Coauthors**: Christodoulos A. Floudas (advisor) · **Position in trajectory**: second PhD-era piecewise paper, after the 1-D gas-lift comparison (Misener, Gounaris, Floudas, Ind. Eng. Chem. Res. 2009, cited p. 2) and alongside the pooling piecewise-relaxation study (Gounaris, Misener, Floudas 2009, cited p. 3); its EPA example (§6.3) seeds S025.

- **D1 Problem and entry point**: Entered from an application: gas-lift oil production models whose objective and constraints are hydraulic lookup tables, i.e. non-smooth "piecewise-affine functions defined by linear interpolation between vertex points" (p. 1). Her own earlier 1-D comparative study found the Keha et al. formulation consistently best and recommended it for industrial problems (p. 2); this paper extends the explicit formulation to functions f: R^n → R with n ≤ 3 on an orthogonal grid (pp. 1-2). A second motive: approximate generic nonlinear functions by MILP, so that the approximation's optimum seeds a local search or gives a global solver an initial upper bound (p. 2).
  - Transferable: open by naming a data-defined (non-analytic) function class that practitioners already use (lookup tables) and state the payoff of being able to optimise over it exactly with MILP technology (pp. 1-2).
- **D2 Core idea and algorithm design**: Lookup table on an orthogonal grid → each point confined to one box with SOS1 variables per coordinate (§4.1, pp. 6-9) → each box split into simplices so the convex-combination weights are unique (Carathéodory argument, §3, pp. 5-6) → interpolation as a convex combination of the n+1 active vertices (§4.6, pp. 21-22). Key design choices: in 3-D, triangulation type B because three planes suffice and its six simplices have equal volume, so error is "relatively uniform" (§4.3, pp. 10-11); four orientations defined by the main diagonals, chosen per function to reduce error (p. 12). Two ways to pick the simplex: (a) one binary per separating plane, O(N²) constraints, equal spacing required (§4.5.1-4.5.2, pp. 15-19); (b) an SOS2 index over grid diagonals following Kosmidis et al., O(N) in 2-D and O(N²) in 3-D, allowing irregular grids that are finer where curvature is high (§4.5.3-4.5.4, pp. 15-16, 19-21). What it keeps: the 1-D Floudas / Nemhauser-Wolsey construction, which it "generalizes" (p. 6).
  - Transferable: before writing simplex-selection constraints, tabulate which vertices each binary switches off; here every deactivated pair lies on one edge (Table 1, p. 15), which lets whole edges be switched off with one aggregated constraint (Eqs. 42-47, pp. 18-19).
- **D3 Assumptions and model**: Functions of dimension ≤ 3 on an orthogonal grid (p. 4); higher-dimensional functions only if additively separable into ≤ 3-D terms or writable as sums of bilinear/trilinear products of ≤ 3-D tables, which are then relaxed with McCormick or trilinear envelopes (pp. 4-5, "up to nine dimensions each", p. 5). The cap n ≤ 3 is justified by the minimum number of simplices needed to triangulate a cube (1, 2, 5 for n = 1-3 vs 16, 67, 308, 1493 for n = 4-7; p. 4). Method (a) requires equal grid spacing (p. 15). No smoothness assumption is used; the result is an approximation, not a relaxation, so it gives no bound on the true problem (implicit throughout; the paper never states an error bound).
  - Transferable: justify a dimension cap with a concrete combinatorial count from the literature rather than with "for simplicity" (p. 4).
- **D4 Analysis and proof devices**: No theorems or proofs. Arguments are constructive and counting-based: uniqueness of interpolation from Carathéodory plus n+2 equations in n+2 unknowns (pp. 5-6); constraint-count orders O(N²) vs O(N) (pp. 15-16, 19, 21); variable-count trade-off of 3 binaries vs 2(N1+N2+N3)+3 continuous variables (p. 21). Approximation error is not bounded analytically; it is estimated empirically (D5).
- **D5 Numerical experiments**: CPLEX 9.0.2 in GAMS on a Pentium 4 (p. 24). Three examples of increasing difficulty (p. 24): six-hump camelback (2-D; 5 grids, 4×4 to 64×64; Tables 2-4, p. 25), a 4-D multilinear function split into a 2-D and a 3-D table (Tables 5-7, pp. 25-26), and the 11-input EPA Complex Emissions Model decomposed with §2.3 (Tables 8-10, pp. 26-28). Error is measured by sampling 1×10^7 random domain points and reporting absolute (and, for EPA, relative) max, average and standard deviation (pp. 25-27). Optimisation results report objective, variables, nodes, iterations and CPU (Tables 4, 7). Failure reported honestly: on the camelback the approximation lands in a non-global local minimum (p. 25). For the EPA model only approximation errors are reported, no optimisation run (Table 10, p. 28). Grid refinement is targeted by impact: EPA-3 refines ETB and ETH because their acetaldehyde coefficients are about an order of magnitude larger (pp. 27-28). No baseline solver or competing PWL formulation is run; the solver for the "actual nonlinear function" row in Table 4 is not named (p. 25). The claimed choice rule between methods (a) and (b) (p. 21) is not tested.
  - Transferable: an approximation-quality protocol: dense random sampling (10^7 points) of interpolation error per grid level, reported as max/average/std next to the optimisation result at that level (Tables 3, 6, 10).
  - Transferable: refine the grid only in the variables whose model coefficients are largest, and show the error drop for that output (EPA-3 vs EPA-2 toxics, pp. 27-28).
- **D6 Literature positioning**: Continues the 1-D line (Williams; Floudas; Nemhauser-Wolsey; Keha et al.; her own gas-lift study) (pp. 2-3, 6); borrows box-then-simplex partitioning from Zhang and Wang (p. 6) and the 2-D diagonal orientation from Kosmidis et al., whose results it generalizes "to a three dimension domain" (p. 16); places itself beside piecewise underestimation work (Meyer-Floudas, Karuppiah-Grossmann, Wicaksono-Karimi, Gounaris et al.) (p. 3). Positioning is additive, not critical. The reference list (pp. 28-31) contains no Vielma-Ahmed-Nemhauser work on nonseparable piecewise-linear models; S009 later takes up Vielma's line.
- **D7 Writing and rhetoric**: Contribution stated twice in the same words (abstract p. 1 and p. 2: "we develop two different explicit formulations of piecewise-linear functions and discuss the consequences of integrating the formulations into an optimization problem"). Long constructive exposition with many figures (Figs. 1-10) and a §5 "Summary of Explicit Equations" for implementers (pp. 22-24). Hedging is light; the conclusion is two sentences and claims "good approximations for large, industrially relevant models" (p. 28) although the EPA model was not optimised.
- **D8 Contribution and limits**: Contribution: formulation and modelling (explicit 2-D and 3-D PWL MILP formulations), with an approximation-error study. Limits written: dimension ≤ 3 (p. 4); equal spacing for method (a) (p. 15). Limits not written: no error bound, no guarantee for the original NLP, local minima of the approximation (shown, p. 25, but not discussed as a limit), no comparison of the two simplex-selection methods. No future work stated (p. 28).

**Method links**:
- Method 3 (variant ⚠): a 2010 precursor. A data-defined function (lookup table) is written as MILP constraints that exploit its piecewise-linear structure, "non-analytic functions can be used as an objective or constraint function for large optimization problems" (pp. 1-2). It differs from Method 3 in having no partner model, no toolkit and no switchable interface, though two formulations are offered (pp. 15-21).
- Method 2 (variant ⚠): the grid level is the knob (CB-1 to CB-5, MF-1 to MF-3, EPA-1 to EPA-5) and is swept with errors reported (pp. 25-28). There are no two textbook extremes, and the trade-off between formulations (a) and (b) is asserted, not measured (p. 21).
- Method 5 (variant ⚠): pre-2012 practice. Three examples, no competing solver or formulation, no independent verification of returned points. This fits the SKILL's dating of Method 5 ("every solver paper since 2012").

**Transferable techniques**:
- Use triangulations with equal-volume simplices (type B, one main diagonal) so the interpolation error is spread evenly over each box, and pick the orientation per function (pp. 10-12).
- Use an SOS2 index over grid diagonals instead of one binary per box to get O(N) constraints in 2-D and irregular grids (pp. 19-21).
- Cap the dimension by the cube-triangulation counts, and handle higher dimensions by separable sums or bilinear/trilinear products of low-dimensional tables, relaxed with known envelopes (pp. 4-5).
- Measure approximation quality by 10^7-point random sampling per grid level, and refine where coefficients are largest (pp. 25-28).

**Quotes**:
- "Noting the large number of simplices needed to partition hypercubes of dimension greater than three, this study restricts lookup tables to no more than three dimensions." (p. 4)
- "Note that, in this case, the approximation algorithm finds one of the non-global local minima, which is generated quickly." (p. 25)

### S025 · Mathematical modeling and global optimization of large-scale extended pooling problems with the (EPA) complex emissions constraints (Computers & Chemical Engineering 2010, doi:10.1016/j.compchemeng.2010.02.014)
Read level: **full** (pp. 1-29 read; references pp. 29-33 skimmed; Appendices A-D (parameter tables, pp. 33-38) skimmed for structure only).
**Role**: core · **Coauthors**: Chrysanthos E. Gounaris, Christodoulos A. Floudas · **Position in trajectory**: the "extended pooling" class that APOGEE (S009) later unifies with the standard and generalized classes. It is the first paper in this batch with a full spatial B&B implemented by her (C++/CPLEX/MINOS) and the first use here of an edge-concave relaxation, the ingredient GloMIQO later generalises.

- **D1 Problem and entry point**: Entered from regulation: 40 CFR 80.45 Complex Emissions Model codifies VOC, NOX and toxics emissions of reformulated gasoline as functions of eleven fuel properties; refinery products must satisfy upper limits (pp. 1-2). Problem: maximise blending profit on a fixed pooling network subject to those limits, an MINLP with bilinear, polynomial, exponential and fractional-power terms (abstract; pp. 2, 8). Gap claimed: Furman and Androulakis already formulated the EPA model as an MINLP, but for a single fuel and with redundancies; prior relaxation work (Gounaris-Floudas 2007) was preliminary; this is "the first success in globally optimizing large-scale pooling problems with the EPA Model appended" (pp. 2, 4).
  - Transferable: enter a global-optimisation project through a legally binding model whose terms are fixed by an outside authority. The instance cannot be simplified away, and every complication has to be relaxed (pp. 1-2, 4).
- **D2 Core idea and algorithm design**: The idea is first a better model, then a relaxation menu per term type. Model (pp. 2-3, 7-20): (1) attach the emissions model to each product of a pq-formulation pooling backbone, "Combining the advantages of a small formulation and a tight relaxation" (p. 9); (2) represent each EPA breakpoint by one binary per disjunction, not one per segment (15 vs 21 binaries per product, pp. 2-3); (3) recognise that eight extension functions that look bilinear are "without approximation" piecewise linear, and model them with slack variables (pp. 3, 13, 17); (4) drop redundant tracking of TAME (p. 10); (5) note that the NOX extensions are first-order Taylor expansions of Eq. (98) at fixed breakpoints (p. 18); (6) linearise RVP blending with an auxiliary variable for RVP^1.25 (pp. 20). Relaxation (§4, pp. 20-24): piecewise nf4r for q·y bilinear terms (her own study's pick, p. 21); plain McCormick for u·of terms, because piecewise relaxation "significantly increased the problem solution time without notable change in the objective function" (p. 22); outer approximation for the convex exponential terms, with tangent points spread evenly over the function's range rather than its domain (pp. 22-23); 2-3 hyperplanes plus a secant for low-curvature terms (p. 21); edge-concave facets for the non-exhaust benzene polynomial after subtracting a correction term (pp. 23-24); recursive bilinear arithmetic for the rest (p. 21). B&B (§5, pp. 24-25): multistart from lower-bounding solutions with N = 16 and N_OA ∈ {1,3,...,11}, local MINOS solves with binaries fixed and bounds inferred logically, OBBT on a cheap relaxation (N = 1, N_OA = 8) with nodes solved at N = 16, branching on the flow of_j with the largest relaxation discrepancy.
  - Transferable: when a nonconvex polynomial is not edge-concave, subtract a correction term α'·g(x) chosen at the variable bounds so that the remainder is component-wise concave. Relax the remainder with its vertex-polyhedral envelope and the correction with recursive arithmetic; here this gave a lower bound of -10.61 vs -13.56 from recursive arithmetic alone (pp. 23-24).
  - Transferable: run OBBT on a deliberately coarse relaxation (McCormick, N = 1) and solve the node itself on the fine one (N = 16) (p. 24).
- **D3 Assumptions and model**: Perfect mixing and linear blending of every quality except RVP (pp. 7-8); exact fuel-quality inputs, with uncertainty deferred to sensitivity analysis or parametric optimisation (p. 8; not carried out); summer case only, as the hardest (pp. 25-26); additives assumed to be blended at the refinery, a stated simplification (p. 25); identical emissions limits for all products (p. 25). Where the law and the EPA spreadsheet disagree, the law is followed (p. 3). Variable bounds are tightened from topology (Eq. 9, pp. 9-10) and by preprocessing analysis (p. 15). The OA scheme assumes monotone convex univariate terms (p. 22). Algorithm parameters (N, N_OA) "were obtained from experience with the small and mid-size test cases" (p. 24).
- **D4 Analysis and proof devices**: No theorems. Devices are modelling arguments: (i) component-wise concavity test via second partial derivatives to decide edge-concavity (Eqs. 156-158, p. 23), then a constructive shift α'4 = α4 + 3α6·RVP^L + α7·MTB^L that makes the remainder edge-concave (Eqs. 159-160, p. 23); (ii) range-uniform tangent points t(n) = ln(e^{tL} + n/N·(e^{tU} − e^{tL})) for exponentials (Eqs. 153-155, pp. 22-23); (iii) recognising piecewise-linear structure inside apparently bilinear legal formulas (Figs. 1-2, pp. 14, 17); (iv) counting formulas for model size as functions of the topology (p. 8). The non-monotone lower bounds caused by not preserving relaxations from parent to child are acknowledged, with citations (p. 25).
- **D5 Numerical experiments**: Three case studies (Table 3, p. 25): small (7 feeds, 1 pool, 2 products; 214 continuous, 30 binary, 108 nonlinear terms), medium (14/3/3; 331, 45, 180) and large (14 feeds, 5 pools, 10 products; 1104, 150, 640 nonlinear terms), each in EPA Regions 1 and 2 (p. 26). Hardware: Intel Core 2 Quad 2.83 GHz, serial; CPLEX 11.0 and MINOS 5.51 (p. 26). Results (Table 5, p. 27): 1-11 B&B nodes, final gaps 0.2-0.5%, CPU 4.5 s (small), 263-292 s (medium), 411-5274 s (large). The Figure 6 caption gives 487 CPU s for the medium case, which does not match Table 5's 292/263 s (p. 27); the paper does not explain the difference. Solutions are read for domain sense: the optimiser cuts unnecessary purchases of expensive additives (p. 26) and uses very little butane, matching Rhodes' advice to remove light ends (p. 11). Not done: no comparison with another global solver or with Furman-Androulakis computationally, no ablation of the relaxation menu beyond the edge-concave 22% figure (p. 23), no independent feasibility check. All instance parameters are published (Appendices B-D, pp. 35-38).
  - Transferable: publish every instance parameter (feeds, qualities, prices, bounds) in appendices so that a hard application instance becomes a public benchmark. S009 then reuses these instances (S009 Table 3, p. 9).
- **D6 Literature positioning**: A long, generous pooling-history paragraph from Haverly 1978 onwards (pp. 3-4). Direct, specific criticism of the closest prior model: Furman and Androulakis "introduce model elements departing from both 40CFR80.45 [2007] and the spreadsheet model", adding "disjunctions not present in either the law or the spreadsheet" (p. 3). Their model is also larger and uses bilinear terms where piecewise-linear terms are exact (pp. 2-3). Relaxation choices are justified by the group's own computational study (Gounaris et al. 2009) and Wicaksono-Karimi (p. 21).
  - Transferable: when you build on a predecessor's model of a regulation or standard, diff it line by line against the primary source and list the discrepancies with concrete examples (ΔE200 at 65.52 vol%, p. 3).
- **D7 Writing and rhetoric**: Numbered list of four reasons why the alternative formulation is valuable, placed in the introduction (pp. 2-3). Size headlines are repeated verbatim in abstract, introduction and conclusion ("1104 continuous variables, 150 binary variables, and 640 nonlinear terms"; pp. 1, 2, 29). Equation-heavy (Eqs. 1-161 over pp. 9-24). Little hedging; the conclusion restates contributions without limits (p. 29).
- **D8 Contribution and limits**: Contributions: a model (a leaner and law-faithful MINLP of the EPA-extended pooling problem), a relaxation menu with a 22% edge-concave gain (p. 23), and a B&B that solves all three cases to ≤ 0.5% gap (p. 27). Limits stated in passing: uncertainty not handled (p. 8), simplified additive logistics (p. 25), parameters tuned on small cases (p. 24). Not stated: the 0.5% tolerance, the lack of competitor runs, and the long large-case time in Region 1 (5274 s vs 411 s in Region 2, Table 5) left unexplained. No future work (p. 29).

**Method links**:
- Method 1 (evidence ✅): reading the model as written (the law's formulas) for structure the authors of the earlier model missed. Bilinear-looking extensions are exactly piecewise linear (pp. 3, 13, 17), NOX extensions are Taylor expansions (p. 18), TAME tracking is redundant (p. 10), three binaries per two disjunctions are redundant (pp. 2-3), a polynomial is edge-concave after a shift (p. 23). Each structure is then exploited in the relaxation. This is the earliest instance of Method 1 step 1 in this corpus (pre-2014).
- Method 4 (evidence ✅): the piecewise relaxation of u·of terms is dropped because it raised whole-solve time without changing the objective (p. 22), i.e. a tightening judged by its effect on the full solve, not by bound strength.
- Method 2 (variant ⚠): partition levels N and N_OA are levers, but they were fixed "from experience" on the small and mid-size cases and only asserted to "still perform well" on the large one (p. 24). There is no sweep and no robustness evidence in this paper; S009 supplies the sweep.
- Method 5 (variant ⚠): pre-2012 evaluation. There are no competitors, the tolerance is 0.5%, and Figure 6 (487 s) and Table 5 (292/263 s) disagree (p. 27). Public instance parameters (Appendices B-D) are the one auditor-like element.

**Transferable techniques**:
- Diff a predecessor's model of a standard against the primary legal text and follow the primary text where the two disagree (p. 3).
- Model k breakpoints of a piecewise rule with k binaries (one per disjunction), not k+1 segment binaries (pp. 2-3).
- Choose OA tangent points evenly over the function's range, not its domain, for steep exponentials (pp. 22-23).
- Use a shift-to-edge-concave decomposition for polynomials that are not edge-concave (p. 23).
- Bound tightening on a coarse relaxation, node solve on a fine one (p. 24).

**Quotes**:
- "closer examination (Figure 1) shows that the function is, without approximation, piecewise-linear." (p. 13)
- "significantly increased the problem solution time without notable change in the objective function" (p. 22)

### S009 · APOGEE: Global optimization of standard, generalized, and extended pooling problems via linear and logarithmic partitioning schemes (Computers & Chemical Engineering 2011, doi:10.1016/j.compchemeng.2011.01.026)
Read level: **full** (pp. 1-31 read; references pp. 31-36 skimmed; Appendix A (pp. 36-38, the two schemes restated for p·y terms) skimmed).
**Role**: core · **Coauthors**: Jeffrey P. Thompson, Christodoulos A. Floudas · **Position in trajectory**: closes the PhD-era pooling line. It unifies the generalized (Misener-Floudas 2010) and extended (S025) classes in one released tool and tests her own logarithmic novelty against the linear incumbent inside the full algorithm. It is the source of the Method 4 epigraph quote in SKILL.md.

- **D1 Problem and entry point**: Two prior large-scale pooling studies used piecewise relaxations whose number of binaries grows linearly with the number of segments (abstract, p. 1; pp. 2-3). The trigger came from a neighbouring community: Vielma-Nemhauser and Vielma et al. model piecewise-linear functions with a logarithmic number of binaries (p. 3). Question: does a logarithmic version of the piecewise relaxation of bilinear terms help, and how should the three pooling classes be solved by one tool (p. 3)?
  - Transferable: take a formulation trick proven for one problem class in a neighbouring community (MIP modelling of PWL functions) and ask whether it carries over to relaxations inside your own algorithm (pp. 3, 6).
- **D2 Core idea and algorithm design**: Start from the disjunctive program for the piecewise McCormick relaxation of x·y with x split into N_P uniform segments (Eq. 6, p. 14). Reformulate it as a MILP in two ways (§4.2, pp. 16-22): linear (nf4r: N_P binaries, ∆y SOS1-like) and the new logarithmic one, with ⌈log2 N_P⌉ binaries in a base-2 encoding of the active segment (Eq. 11), a ∆y and a slack s per binary so that ∆y(n_L) = y − y^L exactly when λ(n_L) = 1 (Eq. 13), and an extra cut (Eq. 12) when N_P is not a power of two (pp. 18-21). Difference from Vielma-Nemhauser: logarithmic, not linear, numbers of continuous variables too, because ∆y is a linear reformulation of (y − y^L)·λ, and the result is claimed as "the first logarithmically-scaled relaxation of continuous, nonlinear functions" (p. 19). Any injective map from segments to binary codes would do (p. 19). Li et al.'s logarithmic model is rejected as not sharp (pp. 6-7). The tool picks the formulation automatically (Algorithm 2, p. 25): count bilinear terms of the p- vs q-formulation and partition the variable set with fewer members. B&B (Algorithm 1, p. 24): topological correctness checks, OBBT at the root and when the parent's bounds improved significantly, branching on the largest relaxation discrepancy at a point 0.15·midpoint + 0.85·relaxation solution, local SNOPT solves started from the relaxation's solution pool, 7200 s limit.
  - Transferable: encode the active segment of a piecewise relaxation in base 2, and pair each binary with a continuous "copy" variable plus a slack so that the continuous part also scales logarithmically (Eqs. 11-14, pp. 19-21).
  - Transferable: let the solver choose the formulation and the variables to partition by counting nonconvex terms and variable-set sizes (Algorithm 2, p. 25).
- **D3 Assumptions and model**: Uniform partitioning, based on the group's computational study and Hasan-Karimi's proof that equal segments are likely tightest (p. 13). Only one variable of each bilinear term is partitioned (p. 13). Pooling classes as in Table 1 (p. 4); pool-pool cycles excluded by the algorithm in the generalized class (p. 4); minimum-flow semicontinuity via binaries (p. 13). No specialised branching for the logarithmic encoding, unlike Vielma-Nemhauser (p. 23). The binaries of the linear scheme are not declared SOS1 in the implementation (p. 17).
- **D4 Analysis and proof devices**: No theorems. The equivalence of both MILPs to Disjunctive Program (6) is asserted ("exactly represent", p. 16) and illustrated with worked activations (N_P = 4, x = x^L + 2.6a; N_P = 5, x = x^L + 3.6a; Figs. 6-9, pp. 17-20), not proved. A redundancy argument shows that the segment-bound constraint (8) follows from the relaxation inequalities by subtracting (10d) from (10a) and (10c) from (10b) (p. 18); the same holds for (11) after (14) (p. 21). Size accounting gives closed-form variable and constraint counts per scheme (Tables 4-5, pp. 16, 23). That accounting also explains why N_P = 2^{n-1}+1 is larger than N_P = 2^n (p. 29).
  - Transferable: show that a "selection" constraint is implied by the envelope inequalities (by pairwise subtraction) and drop it from the model (p. 18).
- **D5 Numerical experiments**: 25 pooling problems from the literature, with known optima (Table 3, p. 9: 14 standard, 5 generalized, 6 extended from S025). Each is solved with both schemes at N_P ∈ {3,4,5,6,8,12,16} inside the full Algorithm 1, the only difference being the bilinear relaxation (pp. 22-23). Tolerances: 1e-6 for standard and 1e-3 for generalized and extended problems. The two largest EPA problems get 1e-2 because they do not converge at 1e-3 within 7200 s, which is stated (p. 29). Hardware: 4-core 2.27 GHz Xeon E5520, CPLEX 12.1 (four threads), SNOPT 5.3 (p. 23); online-service users are warned about timing variability (p. 23). Win counting treats times within 10% of the best as ties (Table 8 note, p. 28; p. 29). Results: logarithmic wins at N_P ≥ 8 (N_P = 8: 21 vs 11 wins; N_P = 16: 21 vs 4), linear wins at small N_P (N_P = 3: 23 vs 10; N_P = 5: 21 vs 8), tie at N_P = 4 (16 vs 16). But the best partition level overall is small: N_P = 4 is best on 20 of 25 problems and N_P = 3 on 15 (Table 8, p. 28). Failures listed: three non-converged runs (Meyer 15 logarithmic at N_P = 5 and 12; Adhya 3 linear at N_P = 16) (p. 30). The logarithmic scheme had numerical difficulty on Meyer 10, Meyer 15 and EPA Large R1 (p. 29). Not done: no competing global solver, no independent feasibility check. In Table 6, the logarithmic size rows for EPA Small and Med look internally inconsistent (e.g. Small: total equations 155 < piecewise-part equations 819) (p. 26), and the paper does not comment on it.
  - Transferable: a protocol for testing a parameter and a formulation: problems × parameter grid × formulations, measured inside the full algorithm; count wins with a 10%-tie rule both per formulation and per parameter level, and list every non-converged run (Table 8, pp. 28-30).
- **D6 Literature positioning**: Generous survey of pooling, generalized pooling and QCQP algorithms (pp. 3-7), naming who was first ("the first to rigorously solve the pooling problem to global optimality", p. 4). The relation to Vielma-Nemhauser is spelled out as "consistent elements" vs differences (p. 19). Li et al. are criticised precisely, by citing a third party (Vielma et al. 2010b), as "not sharp" (pp. 6-7). The results are framed as extending Vielma's evidence from isolated MILPs to a full global solver: "This observation suggests a robustness to the claims of Vielma et al." (p. 29). The evaluation is contrasted with prior work "that isolates the performance of a single MILP" (p. 23).
- **D7 Writing and rhetoric**: Twofold purpose stated at the start of §5 (p. 22). The core judging principle is stated before the results (p. 23), and the verdict comes after a balanced reading of the evidence, ending in a decision ("Therefore, we will continue using the linear relaxation scheme", p. 30). Hedged scope for the novelty: "we conjecture that problem classes requiring finer partitioning would benefit" (p. 31). Practical voice for users: a desktop client, preloaded test suite, a large-instance warning, and an invitation to contact Floudas for very large instances (pp. 30-31). The abstract contains a slip: binaries "depends logarithmically on the number of binary variables" where segments is meant (p. 1).
- **D8 Contribution and limits**: Contributions: a new formulation (logarithmic piecewise relaxation of bilinear terms), an evaluation inside the full solver, and software (APOGEE, free, with GUI and test suite; pp. 1, 30-31). Limits stated specifically: the novelty loses at the partition levels that work best for pooling (pp. 29-31); numerical difficulty on three large instances (p. 29); two EPA instances not solved to 1e-3 (p. 29). Future direction: classes needing finer partitioning (p. 31). Robustness claim on the parameter: "guessing the right partition is not a crucial element of our process" (p. 30).

**Method links**:
- Method 4 (evidence ✅): the defining source. The relaxations are judged inside the APOGEE algorithm, not at an isolated root (p. 23). The verdict is split by regime (log better for N_P ≥ 8, linear for small N_P; p. 29). Stability decides the default against her own novelty after numerical trouble on three large instances (pp. 29-30). The novelty survives as a conjecture for other classes (p. 31).
- Method 2 (evidence ✅): a parameter family (N_P from 1 = McCormick up to 16) is swept on 25 problems with both encodings, and a robustness claim for the parameter is made from the sweep (p. 30). Partial, as SKILL.md notes: there is no rule for choosing N_P beyond the statement that APOGEE currently uses N_P = 4 (p. 30).
- Method 1 (evidence ✅, weak): Algorithm 2 turns a structural count (bilinear terms in p vs q, size of variable sets) into an automatic formulation and partition choice (p. 25). This is a small precursor of the detection layer, not a validated detector.
- Method 5 (variant ⚠): a large documented test set with known optima, exact hardware and versions, a tie rule and listed failures (pp. 9, 23, 28-30). No competitor solvers and no independent verification yet; the Table 6 anomaly is unexplained (p. 26).

**Transferable techniques**:
- Logarithmic (base-2) encoding of the active partition in a piecewise McCormick relaxation, with logarithmically many continuous variables too (pp. 18-22).
- When a constraint becomes implied by others, prove it by pairwise subtraction and remove it (p. 18).
- Explain a performance anomaly by model size: ⌈log2 5⌉ = ⌈log2 8⌉, so N_P = 5 carries the cost of N_P = 8 plus an extra cut (p. 29).
- 10%-tie win counting over a problems × parameter × formulation grid inside the full solver (pp. 28-29).
- Release the solver together with the full test suite preloaded in a GUI so readers can rerun and modify instances (pp. 30-31).
